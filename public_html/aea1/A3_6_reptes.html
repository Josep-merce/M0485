Joc d'endevinar un número

Bucles, salts, aleatoris i excepcions alhora

Aquests dos reptes combinen tot el que has treballat a l'A3. Abans de programar, dissenya l'algorisme en paper i decideix quins bucles, quines sentències de salt i quines excepcions necessites.

Repte 1 Joc d'endevinar un número Avançat

El programa genera un número secret entre 1 i 50. El jugador té 6 intents per endevinar-lo. Després de cada intent, el programa diu si el secret és més gran o més petit.

  • Genera el secret amb Random.
  • Llegeix cada intent com a text amb sc.nextLine() i converteix-lo amb Integer.parseInt(), com a l'A3.4. Si l'usuari escriu text, salta una NumberFormatException: avisa'l i no comptis l'intent (fes servir try-catch i continue).
  • Surt del bucle amb break quan encerti.
  • Al final, indica en quants intents ho ha aconseguit o quin era el número.
✅ Solució
import java.util.Random; import java.util.Scanner; public class JocEndevinar { public static void main(String[] args) { final int MAX_INTENTS = 6; Random aleatori = new Random(); Scanner sc = new Scanner(System.in); int secret = aleatori.nextInt(50) + 1; int intents = 0; boolean encertat = false; System.out.println("He pensat un número entre 1 i 50."); while (intents < MAX_INTENTS) { System.out.print("Intent " + (intents + 1) + ": "); int proposta; try { proposta = Integer.parseInt(sc.nextLine()); } catch (NumberFormatException e) { System.out.println("Això no és un número. No compta com a intent."); continue; } intents++; if (proposta == secret) { encertat = true; break; } else if (proposta < secret) { System.out.println("Més gran!"); } else { System.out.println("Més petit!"); } } if (encertat) { System.out.println("Encertat en " + intents + " intents!"); } else { System.out.println("Has esgotat els intents. Era el " + secret + "."); } sc.close(); } }
✔ Què es valora
  • Un text incorrecte no consumeix intent.
  • break i continue s'utilitzen amb sentit.
  • Estratègia recomanada per provar-lo: mostra temporalment el secret per pantalla mentre depures.
🖥️ Exemple d'execució
He pensat un número entre 1 i 50.
Intent 1: 25
Més gran!
Intent 2: quaranta
Això no és un número. No compta com a intent.
Intent 2: 40
Més petit!
Intent 3: 33
Més gran!
Intent 4: 36
Encertat en 4 intents!

El número secret canvia a cada execució (en aquest exemple era el 36).

Calculadora robusta

Un programa que no s'atura mai per un error

Repte 2 Calculadora robusta Avançat

Crea una calculadora d'enters que funcioni en bucle: demana dos números i una operació (+, -, *, /, %) i mostra el resultat. Quan l'usuari escriu fi com a primer número, el programa acaba i mostra quantes operacions s'han fet correctament.

  • Llegeix totes les dades com a text amb sc.nextLine().
  • Fes servir un switch per a l'operació; si l'operador no existeix, llança una excepció pròpia OperacioDesconegudaException.
  • Captura NumberFormatException, ArithmeticException (divisió per zero) i la teva excepció, amb un missatge diferent per a cadascuna.
  • Un error no ha d'aturar la calculadora: s'informa i es torna a començar.
✅ Solució
import java.util.Scanner; /* * Calculadora d'enters que funciona en bucle fins que l'usuari escriu "fi". * Cap error d'entrada atura el programa: es captura, s'informa i es torna a començar. */ // Excepció pròpia: es llança quan l'operació no és cap de les cinc admeses class OperacioDesconegudaException extends Exception { public OperacioDesconegudaException(String missatge) { super(missatge); } } public class CalculadoraRobusta { public static void main(String[] args) { Scanner sc = new Scanner(System.in); int correctes = 0; // comptador d'operacions fetes sense error while (true) { // bucle infinit: només se'n surt amb el break de "fi" // Es llegeix com a text perquè pot ser un número o la paraula "fi" System.out.print("Primer número (o 'fi'): "); String text1 = sc.nextLine(); if (text1.equalsIgnoreCase("fi")) { break; // única sortida del bucle } try { // parseInt llança NumberFormatException si el text no és un enter int a = Integer.parseInt(text1); System.out.print("Operació (+ - * / %): "); String op = sc.nextLine(); System.out.print("Segon número: "); int b = Integer.parseInt(sc.nextLine()); // El switch calcula el resultat; si l'operació no existeix, llança l'excepció pròpia int resultat = switch (op) { case "+" -> a + b; case "-" -> a - b; case "*" -> a * b; case "/" -> a / b; // ArithmeticException si b == 0 case "%" -> a % b; default -> throw new OperacioDesconegudaException("Operació desconeguda: " + op); }; System.out.println(a + " " + op + " " + b + " = " + resultat); correctes++; // només s'arriba aquí si no hi ha hagut cap error } catch (NumberFormatException e) { // algun número no era un enter System.out.println("Error: cal escriure números enters."); } catch (ArithmeticException e) { // divisió o mòdul per zero System.out.println("Error: no es pot dividir per zero."); } catch (OperacioDesconegudaException e) { // operació no admesa System.out.println("Error: " + e.getMessage()); } } // Resum final, després d'escriure "fi" System.out.println("Operacions correctes: " + correctes); sc.close(); } }
✔ Què es valora
  • Cap entrada incorrecta atura el programa.
  • Hi ha un catch específic per a cada tipus d'error.
  • L'excepció pròpia es llança des del default del switch.
  • El codi està comentat i és llegible.
🖥️ Exemple d'execució

Operació (+ - * / %): %
Segon número: 5
17 % 5 = 2
Primer número (o 'fi'): 8
Operació (+ - * / %): /
Segon número: 0
Error: no es pot dividir per zero.
Primer número (o 'fi'): 8
Operació (+ - * / %): ^
Segon número: 2
Error: Operació desconeguda: ^
Primer número (o 'fi'): dotze
Error: cal escriure números enters.
Primer número (o 'fi'): fi
Operacions correctes: 1
