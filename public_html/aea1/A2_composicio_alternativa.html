1. Què és la composició alternativa

Fins ara els programes executaven totes les instruccions una rere l'altra (composició seqüencial). La composició alternativa permet que el programa prengui decisions: segons si una condició és certa o falsa, executa unes instruccions o unes altres.

La condició sempre és una expressió booleana, és a dir, una expressió que dona true o false, construïda amb els operadors relacionals (> < == != >= <=) i lògics (&& || !) que vam veure a l'A1.

SI nota >= 5 LLAVORS ESCRIURE "Aprovat" SINÓ ESCRIURE "Suspès" FI SI
EstructuraQuan usar-laCamins possibles

2. Alternativa simple: if

El bloc entre claus només s'executa si la condició és true. Si és false, el programa se'l salta i continua.

BàsicAplicar un descompte si la compra supera un mínim
public class Descompte { public static void main(String[] args) { final double COMPRA_MINIMA = 100.0; final double DESCOMPTE = 0.10; double preu = 120.0; // Només les compres de 100 € o més tenen descompte if (preu >= COMPRA_MINIMA) { preu = preu - preu * DESCOMPTE; System.out.println("S'ha aplicat un descompte del 10 %"); } System.out.println("Preu final: " + preu + " €"); } }
🖥️ Sortida per consola
S'ha aplicat un descompte del 10 %
Preu final: 108.0 €
⚠️ Errors típics amb if: posar un punt i coma just després de la condició, if (preu >= 100);, fa que el bloc s'executi sempre. I si oblides les claus { }, només la primera instrucció queda dins de l'if. Posa sempre claus.

3. Alternativa doble: if / else

Amb else indiquem què cal fer quan la condició és false. Sempre s'executa un i només un dels dos blocs.

BàsicControl d'accés per edat
public class ControlAcces { public static void main(String[] args) { int edat = 16; if (edat >= 18) { System.out.println("Accés permès."); } else { System.out.println("Accés denegat: cal ser major d'edat."); } } }
🖥️ Sortida per consola
Accés denegat: cal ser major d'edat.
BàsicParell o senar
public class ParellSenar { public static void main(String[] args) { int numero = 17; // Un número és parell si el residu de dividir-lo entre 2 és 0 if (numero % 2 == 0) { System.out.println(numero + " és parell"); } else { System.out.println(numero + " és senar"); } } }

4. Alternativa múltiple: if / else if / else

Quan hi ha més de dues opcions encadenem condicions amb else if. Java les comprova de dalt a baix i executa el bloc de la primera que sigui certa; la resta ja no es comproven. L'else final recull tots els casos que no han complert cap condició.

MitjàQualificació d'una nota
public class Qualificacio { public static void main(String[] args) { double nota = 7.4; String qualificacio; if (nota < 0 || nota > 10) { qualificacio = "Nota incorrecta"; } else if (nota >= 9) { qualificacio = "Excel·lent"; } else if (nota >= 7) { qualificacio = "Notable"; } else if (nota >= 6) { qualificacio = "Bé"; } else if (nota >= 5) { qualificacio = "Suficient"; } else { qualificacio = "Insuficient"; } System.out.println("Nota " + nota + ": " + qualificacio); } }
🖥️ Sortida per consola
Nota 7.4: Notable
💡 Per què no cal escriure nota >= 7 && nota < 9? Si el programa arriba a else if (nota >= 7) és perquè la condició anterior (nota >= 9) ha estat falsa, és a dir, ja sabem que nota < 9. Per això l'ordre de les condicions és important: si posessis primer nota >= 5, un 9.5 donaria "Suficient".
MitjàValor positiu, negatiu o zero
public class Signe { public static void main(String[] args) { int valor = -5; if (valor > 0) { System.out.println(valor + " és positiu"); } else if (valor < 0) { System.out.println(valor + " és negatiu"); } else { System.out.println("El valor és zero"); } } }

5. Alternatives niades

Una alternativa pot contenir-ne una altra dins. Ho fem quan una decisió depèn d'una decisió anterior: per exemple, primer validem les dades i, només si són correctes, fem el càlcul.

AvançatReserva d'hotel amb validació i tarifes
public class ReservaHotel { public static void main(String[] args) { final double TARIFA_SENSE_MAR = 150.50; final double TARIFA_AMB_MAR = 190.50; String client = "Anna Garcia"; int nits = 5; boolean vistesAlMar = true; if (nits <= 0) { System.out.println("Error: el nombre de nits ha de ser positiu."); } else { double preuNit; if (vistesAlMar) { preuNit = TARIFA_AMB_MAR; } else { preuNit = TARIFA_SENSE_MAR; } double total = nits * preuNit; System.out.println("Client: " + client); System.out.println("Nits: " + nits + " a " + preuNit + " €/nit"); System.out.println("Total: " + total + " €"); } } }
🖥️ Sortida per consola
Client: Anna Garcia
Nits: 5 a 190.5 €/nit
Total: 952.5 €
MitjàNiar o combinar condicions: dues solucions equivalents
public class CarnetConduir { public static void main(String[] args) { int edat = 19; boolean teCarnet = true; // Opció 1: if niats if (edat >= 18) { if (teCarnet) { System.out.println("Pot conduir"); } else { System.out.println("Ha de treure's el carnet"); } } else { System.out.println("Encara és menor d'edat"); } // Opció 2: condició combinada (només si no cal distingir el motiu) if (edat >= 18 && teCarnet) { System.out.println("Pot conduir"); } } }
💡 Si cada cas necessita un missatge diferent, fes servir if niats. Si només t'interessa saber si es compleixen totes les condicions alhora, una condició amb && és més curta i clara. Evita niar més de 2 o 3 nivells: el codi es fa difícil de llegir.

6. Comparar textos

Els valors de tipus String no es comparen amb ==. Cal fer servir els mètodes equals() o equalsIgnoreCase().

ExpressióRetorna true quan…
text.equals("sí")el text és exactament "sí" (distingeix majúscules)
text.equalsIgnoreCase("sí")el text és "sí", "SÍ", "Sí"… (no distingeix majúscules)
text.isEmpty()el text és buit ("")
MitjàValidar una resposta de l'usuari
public class Resposta { public static void main(String[] args) { String resposta = "SI"; if (resposta.equalsIgnoreCase("si")) { System.out.println("Has acceptat les condicions."); } else if (resposta.equalsIgnoreCase("no")) { System.out.println("Has rebutjat les condicions."); } else { System.out.println("Resposta no vàlida: " + resposta); } } }
⚠️ Per què no ==? Amb textos, == comprova si les dues variables apunten al mateix objecte a la memòria, no si el contingut és igual. De vegades sembla que funciona i d'altres no. Entendràs el motiu quan estudiem els objectes a l'AEA2; de moment, recorda: textos → equals.

7. L'operador ternari

L'operador condició ? valorSiCert : valorSiFals és una forma abreujada d'if / else quan només volem triar entre dos valors.

BàsicTriar un valor amb el ternari
public class Ternari { public static void main(String[] args) { int a = 12; int b = 30; int major = (a > b) ? a : b; System.out.println("El major és " + major); double nota = 4.5; String resultat = (nota >= 5) ? "Aprovat" : "Suspès"; System.out.println(resultat); } }
💡 Usa el ternari només per a casos senzills. Si has de fer diverses instruccions o encadenar condicions, un if / else és molt més llegible.

8. La sentència switch

switch compara una sola expressió amb una llista de valors concrets (case) i executa el codi del que coincideix. Funciona amb int, char, String i altres tipus, però no amb double ni boolean. El default recull els valors que no coincideixen amb cap cas.

BàsicNom del dia de la setmana
public class DiaSetmana { public static void main(String[] args) { int dia = 3; switch (dia) { case 1: System.out.println("Dilluns"); break; case 2: System.out.println("Dimarts"); break; case 3: System.out.println("Dimecres"); break; case 4: System.out.println("Dijous"); break; case 5: System.out.println("Divendres"); break; case 6: case 7: System.out.println("Cap de setmana"); break; default: System.out.println("Dia no vàlid"); } } }
🖥️ Sortida per consola
Dimecres
⚠️ No oblidis el break. Sense break, Java continua executant els case següents sense comprovar-los (fall-through). Només l'ometem a propòsit per agrupar casos, com el 6 i el 7 de l'exemple.
MitjàCalculadora amb switch sobre un char
public class Calculadora { public static void main(String[] args) { double a = 10.0; double b = 4.0; char operador = '/'; switch (operador) { case '+': System.out.println(a + " + " + b + " = " + (a + b)); break; case '-': System.out.println(a + " - " + b + " = " + (a - b)); break; case '*': System.out.println(a + " * " + b + " = " + (a * b)); break; case '/': if (b != 0) { System.out.println(a + " / " + b + " = " + (a / b)); } else { System.out.println("Error: divisió per zero"); } break; default: System.out.println("Operador desconegut: " + operador); } } }

9. switch amb fletxa (Java 14+)

Les versions modernes de Java permeten una sintaxi més curta amb ->. Té dos avantatges: no cal break (no hi ha fall-through) i el switch pot retornar un valor que guardem en una variable.

MitjàEstació de l'any amb switch com a expressió
public class EstacioAny { public static void main(String[] args) { int mes = 7; String estacio = switch (mes) { case 12, 1, 2 -> "Hivern"; case 3, 4, 5 -> "Primavera"; case 6, 7, 8 -> "Estiu"; case 9, 10, 11 -> "Tardor"; default -> "Mes no vàlid"; }; System.out.println("Mes " + mes + ": " + estacio); } }
🖥️ Sortida per consola
Mes 7: Estiu
Mitjàswitch amb String i blocs d'instruccions
public class MenuCafeteria { public static void main(String[] args) { String producte = "entrepà"; int quantitat = 2; double preu = switch (producte) { case "cafè" -> 1.30; case "suc" -> 2.10; case "entrepà" -> { System.out.println("(Entrepà del dia: truita)"); yield 3.50; // yield retorna el valor quan el cas té un bloc { } } default -> 0.0; }; if (preu == 0.0) { System.out.println("Producte no disponible: " + producte); } else { System.out.println(quantitat + " x " + producte + " = " + (quantitat * preu) + " €"); } } }

11. Exercicis pràctics

Exercicis ordenats de menys a més dificultat. Escriu primer l'algorisme en pseudocodi, programa'l i prova tots els camins canviant els valors de les variables. La sortida esperada correspon als valors indicats a l'enunciat.

Ex. 1 Parell o senar amb operació Bàsic

Si un número enter és parell, multiplica'l per 2 i suma-li 3. Si és senar, multiplica'l per 3 i resta-li 4. Mostra l'operació feta i el resultat.

  • Declara int numero = 7; i prova també amb un número parell.
  • Usa if / else i l'operador %.
🖥️ Sortida esperada
7 és senar: 7 * 3 - 4 = 17
Bàsic CA: 3.1 · 3.5
✅ Solució
public class ParellSenarOperacio { public static void main(String[] args) { int numero = 7; int resultat; if (numero % 2 == 0) { resultat = numero * 2 + 3; System.out.println(numero + " és parell: " + numero + " * 2 + 3 = " + resultat); } else { resultat = numero * 3 - 4; System.out.println(numero + " és senar: " + numero + " * 3 - 4 = " + resultat); } } }
✔ Què es valora
  • La condició de parell és numero % 2 == 0.
  • S'ha provat amb un parell i amb un senar.
Ex. 2 El més gran de tres números Bàsic

Donats tres números enters, mostra quin és el més gran.

  • Declara int a = 14, b = 27, c = 9;
  • Resol-ho amb if / else if / else i operadors lògics.
  • Prova què passa si dos números són iguals i són els més grans (per exemple 27, 27, 9).
  • Ampliació: resol-ho també amb dos operadors ternaris.
🖥️ Sortida esperada
El major de 14, 27 i 9 és 27
Amb ternaris: 27
Bàsic CA: 3.1 · 3.5 · 3.6
✅ Solució
public class MajorDeTres { public static void main(String[] args) { int a = 14; int b = 27; int c = 9; int major; // Fem servir >= perquè els empats també funcionin if (a >= b && a >= c) { major = a; } else if (b >= c) { major = b; // aquí ja sabem que a no és el major } else { major = c; } System.out.println("El major de " + a + ", " + b + " i " + c + " és " + major); // Ampliació amb ternaris int majorAB = (a > b) ? a : b; int majorTernari = (majorAB > c) ? majorAB : c; System.out.println("Amb ternaris: " + majorTernari); } }
✔ Què es valora
  • Els empats donen un resultat correcte (per això >= en lloc de >).
  • No hi ha comparacions innecessàries a l'else if.
Ex. 3 Preu de l'entrada al museu Bàsic

L'entrada general d'un museu costa 12 €. Els menors de 6 anys entren gratis, de 6 a 17 anys paguen la meitat i els de 65 o més tenen un 40 % de descompte.

  • Declara int edat = 70; i el preu general com a constant.
  • Calcula el preu amb una alternativa múltiple.
  • Prova els valors límit: 5, 6, 17, 18, 64 i 65.
🖥️ Sortida esperada
Edat: 70 anys → preu: 7.2 €
Bàsic CA: 3.1 · 3.5 · 3.6
✅ Solució
public class EntradaMuseu { public static void main(String[] args) { final double PREU_GENERAL = 12.0; final double DESCOMPTE_GENT_GRAN = 0.40; int edat = 70; double preu; if (edat < 6) { preu = 0; } else if (edat <= 17) { preu = PREU_GENERAL / 2; } else if (edat >= 65) { preu = PREU_GENERAL - PREU_GENERAL * DESCOMPTE_GENT_GRAN; } else { preu = PREU_GENERAL; } // 12 - 4.8 dona 7.199999999999999: arrodonim a 2 decimals preu = Math.round(preu * 100) / 100.0; System.out.println("Edat: " + edat + " anys → preu: " + preu + " €"); } }
✔ Què es valora
  • Els límits (6, 17, 65) estan ben tractats: s'han provat els valors frontera.
  • El preu general i el descompte són constants, i el resultat s'arrodoneix.
Ex. 4 Índex de massa corporal Mitjà

Calcula l'IMC (pes / alçada²) d'una persona i mostra'n la classificació: menys de 18.5 → pes baix; de 18.5 a menys de 25 → normal; de 25 a menys de 30 → sobrepès; 30 o més → obesitat.

  • Declara double pes = 82; (kg) i double alcada = 1.75; (m).
  • Valida primer que pes i alçada siguin positius; si no, mostra un error.
  • Arrodoneix l'IMC a 2 decimals abans de mostrar-lo.
🖥️ Sortida esperada
IMC: 26.78 (Sobrepès)
Mitjà CA: 3.1 · 3.5 · 3.6 · 3.7
✅ Solució
public class CalculIMC { public static void main(String[] args) { double pes = 82; double alcada = 1.75; // Validem les dades abans de calcular per evitar divisions per zero if (pes <= 0 || alcada <= 0) { System.out.println("Error: el pes i l'alçada han de ser positius."); } else { double imc = pes / (alcada * alcada); imc = Math.round(imc * 100) / 100.0; String categoria; if (imc < 18.5) { categoria = "Pes baix"; } else if (imc < 25) { categoria = "Normal"; } else if (imc < 30) { categoria = "Sobrepès"; } else { categoria = "Obesitat"; } System.out.println("IMC: " + imc + " (" + categoria + ")"); } } }
✔ Què es valora
  • La validació es fa abans del càlcul.
  • Els parèntesis de alcada * alcada són necessaris.
  • Les condicions aprofiten l'ordre de l'else if.
Ex. 5 Dies que té un mes Mitjà

Donat un mes (1–12) i un any, mostra quants dies té aquell mes. Febrer té 29 dies els anys de traspàs.

  • Declara int mes = 2; i int any = 2028;

  • Per al febrer, reutilitza l'expressió de l'any de traspàs de l'A1.

🖥️ Sortida esperada
El mes 2 de 2028 té 29 dies
Mitjà CA: 3.1 · 3.5
✅ Solució
public class DiesMes { public static void main(String[] args) { int mes = 2; int any = 2028; int dies; switch (mes) { case 1, 3, 5, 7, 8, 10, 12 -> dies = 31; case 4, 6, 9, 11 -> dies = 30; case 2 -> { boolean traspas = (any % 4 == 0 && any % 100 != 0) || any % 400 == 0; dies = traspas ? 29 : 28; } default -> dies = 0; } if (dies == 0) { System.out.println("Mes no vàlid: " + mes); } else { System.out.println("El mes " + mes + " de " + any + " té " + dies + " dies"); } } }

Ex. 6 Menú de conversió d'unitats Mitjà

Un programa rep una opció en text i una quantitat, i fa la conversió corresponent: "km-milles" (× 0.621371), "milles-km" (× 1.609344), "kg-lliures" (× 2.20462).

  • Declara String opcio = "milles-km"; i double quantitat = 26.2;
  • Usa un switch sobre el String.
  • Si l'opció no existeix, mostra "Opció desconeguda".
  • Arrodoneix el resultat a 2 decimals.
🖥️ Sortida esperada
26.2 milles = 42.16 km
Mitjà CA: 3.1 · 3.5
✅ Solució
public class ConversorUnitats { public static void main(String[] args) { final double KM_A_MILLES = 0.621371; final double MILLES_A_KM = 1.609344; final double KG_A_LLIURES = 2.20462; String opcio = "milles-km"; double quantitat = 26.2; switch (opcio) { case "km-milles" -> { double r = Math.round(quantitat * KM_A_MILLES * 100) / 100.0; System.out.println(quantitat + " km = " + r + " milles"); } case "milles-km" -> { double r = Math.round(quantitat * MILLES_A_KM * 100) / 100.0; System.out.println(quantitat + " milles = " + r + " km"); } case "kg-lliures" -> { double r = Math.round(quantitat * KG_A_LLIURES * 100) / 100.0; System.out.println(quantitat + " kg = " + r + " lliures"); } default -> System.out.println("Opció desconeguda: " + opcio); } } }
✔ Què es valora
  • Els factors de conversió són constants.
  • El switch té un default per a opcions no vàlides.

Ex. 8 Equació de segon grau Avançat

Resol l'equació ax² + bx + c = 0 i indica si té dues solucions, una o cap solució real.

  • Declara double a = 1, b = -3, c = 2;
  • Si a == 0 no és de segon grau: mostra un missatge (ampliació: resol-la com a equació de primer grau si b != 0).
  • Calcula el discriminant d = b² − 4ac. Si d > 0 hi ha dues solucions; si d == 0, una; si d < 0, cap de real.
  • Solucions: x = (−b ± √d) / 2a. Fes servir Math.sqrt().

Avançat CA: 3.1 · 3.5 · 3.6
✅ Solució
public class EquacioSegonGrau { public static void main(String[] args) { double a = 1; double b = -3; double c = 2; if (a == 0) { // No és de segon grau: bx + c = 0 if (b != 0) { System.out.println("Equació de primer grau. x = " + (-c / b)); } else { System.out.println("No és una equació vàlida."); } } else { double d = b * b - 4 * a * c; if (d > 0) { double x1 = (-b + Math.sqrt(d)) / (2 * a); double x2 = (-b - Math.sqrt(d)) / (2 * a); System.out.println("Dues solucions: x1 = " + x1 + ", x2 = " + x2); } else if (d == 0) { double x = -b / (2 * a); System.out.println("Una solució: x = " + x); } else { System.out.println("No té solucions reals (d = " + d + ")"); } } } }
✔ Què es valora
  • Es controla el cas a == 0 abans de dividir.
  • Els parèntesis de (2 * a) són correctes: sense ells es dividiria per 2 i es multiplicaria per a.
  • Proves suggerides: (1, 2, 1) → una solució; (1, 0, 4) → cap.
Ex. 9 Validar una data Avançat

Comprova si una data (dia, mes, any) és correcta. Si ho és, mostra-la en format dd/mm/aaaa i digues si és l'últim dia del mes.

  • Declara int dia = 29, mes = 2, any = 2027;
  • Una data és vàlida si any > 0, mes entre 1 i 12 i dia entre 1 i els dies d'aquell mes (reaprofita l'exercici 5).
  • Per mostrar 05 en lloc de 5, fes servir l'operador ternari: (dia < 10 ? "0" : "") + dia.
  • Prova: 29/2/2027 (no vàlida), 29/2/2028 (vàlida i últim dia), 31/4/2026 (no vàlida), 5/1/2026.
🖥️ Sortida esperada
La data 29/2/2027 no és vàlida.
Avançat CA: 3.1 · 3.5 · 3.6 · 3.7
✅ Solució
public class ValidarData { public static void main(String[] args) { int dia = 29; int mes = 2; int any = 2027; // 1. Calculem quants dies té el mes (0 si el mes no és vàlid) int diesMes = switch (mes) { case 1, 3, 5, 7, 8, 10, 12 -> 31; case 4, 6, 9, 11 -> 30; case 2 -> ((any % 4 == 0 && any % 100 != 0) || any % 400 == 0) ? 29 : 28; default -> 0; }; // 2. La data és vàlida si l'any és positiu, el mes existeix i el dia és dins del mes boolean valida = any > 0 && diesMes > 0 && dia >= 1 && dia <= diesMes; if (valida) { String dd = (dia < 10 ? "0" : "") + dia; String mm = (mes < 10 ? "0" : "") + mes; System.out.println("Data correcta: " + dd + "/" + mm + "/" + any); if (dia == diesMes) { System.out.println("És l'últim dia del mes."); } } else { System.out.println("La data " + dia + "/" + mes + "/" + any + " no és vàlida."); } } }
✔ Què es valora

Ex. 10 Factura de la llum per trams Avançat

Una companyia elèctrica cobra el consum per trams: els primers 100 kWh a 0,15 €/kWh, de 101 a 300 kWh a 0,20 €/kWh i a partir de 301 kWh a 0,28 €/kWh. A més, hi ha una quota fixa de 8 €. Si la factura supera els 60 €, s'aplica un recàrrec del 5 %.

  • Declara int consum = 350; (kWh). Els preus i la quota són constants.
  • Cada tram només s'aplica als kWh que hi cauen: 350 kWh = 100 × 0,15 + 200 × 0,20 + 50 × 0,28.
  • Mostra el cost de l'energia, la quota, el recàrrec (si n'hi ha) i el total arrodonit a 2 decimals.
  • Prova també amb 80, 100, 300 i 301 kWh.
🖥️ Sortida esperada
Consum: 350 kWh
Energia: 69.0 €
Quota fixa: 8.0 €
Recàrrec 5 %: 3.85 €
TOTAL: 80.85 €
Avançat CA: 3.1 · 3.5 · 3.6 · 3.7
✅ Solució
public class FacturaLlum { public static void main(String[] args) { final double PREU_TRAM1 = 0.15; // primers 100 kWh final double PREU_TRAM2 = 0.20; // de 101 a 300 kWh final double PREU_TRAM3 = 0.28; // a partir de 301 kWh final double QUOTA_FIXA = 8.0; final double LIMIT_RECARREC = 60.0; final double RECARREC = 0.05; int consum = 350; double energia; // Cada tram només s'aplica als kWh que hi cauen if (consum <= 100) { energia = consum * PREU_TRAM1; } else if (consum <= 300) { energia = 100 * PREU_TRAM1 + (consum - 100) * PREU_TRAM2; } else { energia = 100 * PREU_TRAM1 + 200 * PREU_TRAM2 + (consum - 300) * PREU_TRAM3; } energia = Math.round(energia * 100) / 100.0; double subtotal = energia + QUOTA_FIXA; double recarrec = 0; if (subtotal > LIMIT_RECARREC) { recarrec = Math.round(subtotal * RECARREC * 100) / 100.0; } double total = Math.round((subtotal + recarrec) * 100) / 100.0; System.out.println("Consum: " + consum + " kWh"); System.out.println("Energia: " + energia + " €"); System.out.println("Quota fixa: " + QUOTA_FIXA + " €"); if (recarrec > 0) { System.out.println("Recàrrec 5 %: " + recarrec + " €"); } System.out.println("TOTAL: " + total + " €"); } }
✔ Què es valora
  • El càlcul per trams és correcte (no s'aplica el preu més car a tot el consum).
  • El recàrrec només apareix quan correspon.
  • Tots els valors fixos són constants documentades.
