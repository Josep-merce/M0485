Pràctica guiada per posar en joc bucles imbricats, comptadors i variables que controlen altres bucles. Abans de programar, dibuixa les figures en paper quadriculat i busca la relació entre el número de fila i les posicions dels asteriscos.

1. Pas previ: el diamant

Pas previ El diamant de mida n Mitjà

Dibuixa un diamant buit de mida n per a qualsevol valor de n. El valor s'ha de demanar a l'usuari.

  • El diamant té 2n − 1 files i 2n − 1 columnes.
  • Pensa cada fila segons la seva distància d a la punta: a la meitat superior d creix de 0 a n − 1 i a la inferior decreix.
  • A cada fila hi ha n − 1 − d espais, un asterisc i, si d > 0, 2d − 1 espais i un altre asterisc.
  • Exemple d'execució amb n = 4 (a sota de la targeta en tens un altre amb n = 3):
🖥️ Exemple d'execució
Introdueix la mida del diamant: 4
   *
  * *
 *   *
*     *
 *   *
  * *
   *
Mitjà CA: 3.2 · 3.5 · 3.6
✅ Solució
import java.util.Scanner; public class Diamant { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.print("Introdueix la mida del diamant: "); int n = Integer.parseInt(sc.nextLine()); // El diamant té 2n - 1 files for (int fila = 0; fila < 2 * n - 1; fila++) { // Distància a la punta: creix fins a la fila central i després decreix int d = (fila < n) ? fila : 2 * n - 2 - fila; for (int e = 0; e < n - 1 - d; e++) { // espais de l'esquerra System.out.print(" "); } System.out.print("*"); if (d > 0) { // les puntes només tenen un asterisc for (int e = 0; e < 2 * d - 1; e++) { // espais interiors System.out.print(" "); } System.out.print("*"); } System.out.println(); } sc.close(); } }
✔ Què es valora
  • El nombre de files i els espais depenen només de n i de la fila.
  • Les puntes (d = 0) tenen un sol asterisc.
  • Prova-ho amb n = 1, 2, 3 i 4.

2. Exercici pràctic: diamants per nivells

Pt1 Diamants concatenats per nivells Avançat

Genera un patró de diamants concatenats verticalment, on cada nivell duplica el nombre de diamants del nivell anterior (1, 2, 4, 8…). Si només hi ha un nivell, el resultat és el del pas previ. El programa ha de demanar la mida del diamant i el nombre de nivells.

  • Reaprofita el codi del pas previ: ara cada fila d'un nivell repeteix el mateix tros de diamant tantes vegades com diamants té el nivell.
  • Els diamants d'una mateixa fila se separen amb un espai, de manera que cada diamant ocupa 2n columnes (2n − 1 del diamant + 1 de separació).
  • Fes servir una variable diamants que comenci a 1 i es multipliqui per 2 en acabar cada nivell.
  • Estructura: bucle de nivells → bucle de files → bucle de diamants → bucles d'espais i asteriscos.
  • Exemple d'execució amb mida 4 i 2 nivells (a sota de la targeta en tens un altre amb mida 3 i 3 nivells):
🖥️ Exemple d'execució
Introdueix la mida del diamant: 4
Introdueix el nombre de nivells: 2

✅ Solució
import java.util.Scanner; public class DiamantsNivells { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.print("Introdueix la mida del diamant: "); int n = Integer.parseInt(sc.nextLine()); System.out.print("Introdueix el nombre de nivells: "); int nivells = Integer.parseInt(sc.nextLine()); int diamants = 1; // diamants del nivell actual for (int nivell = 1; nivell <= nivells; nivell++) { for (int fila = 0; fila < 2 * n - 1; fila++) { int d = (fila < n) ? fila : 2 * n - 2 - fila; // Repetim el tros de diamant d'aquesta fila per a cada diamant del nivell for (int k = 1; k <= diamants; k++) { for (int e = 0; e < n - 1 - d; e++) { // espais de l'esquerra System.out.print(" "); } System.out.print("*"); if (d > 0) { for (int e = 0; e < 2 * d - 1; e++) { // espais interiors System.out.print(" "); } System.out.print("*"); } // Si no és l'últim diamant: espais de la dreta + 1 de separació if (k < diamants) { for (int e = 0; e < n - 1 - d + 1; e++) { System.out.print(" "); } } } System.out.println(); } diamants *= 2; // el nivell següent en té el doble } sc.close(); } }
✔ Què es valora
  • El pas previ s'ha reutilitzat sense duplicar la lògica del diamant.
  • El nombre de diamants es dobla a cada nivell.
  • La separació entre diamants és d'un sol espai.
  • El codi està sagnat i comentat: amb quatre bucles imbricats, és imprescindible.
