La composició iterativa i el bucle while

Repetir mentre es compleixi una condició

La composició iterativa (o bucle) permet repetir un bloc d'instruccions mentre es compleixi una condició. Cada repetició s'anomena iteració. Sense bucles, per mostrar els números de l'1 al 1000 hauríem d'escriure mil instruccions.

El bucle while

while (condició) { cos }: mentre la condició sigui true, s'executa el cos. Si d'entrada és false, el cos no s'executa cap vegada. És el bucle per als casos en què no sabem quantes voltes farà. En passar-lo de PSeInt a Java, l'actualització n <- n + 10 s'escriu n = n + 10; (o n += 10;), i dels operadors de comparació, <= i >= no canvien però <> passa a ser !=.

Quants anys calen per doblar uns estalvis?
public class DoblarEstalvis { public static void main(String[] args) { final double INTERES_ANUAL = 0.10; // 10 % anual double inicial = 1000.0; double saldo = inicial; // 1. inicialització int anys = 0; // No sabem quantes voltes farà: per això fem servir while while (saldo < 2 * inicial) { // 2. condició saldo = saldo * (1 + INTERES_ANUAL); // 3. actualització anys++; double euros = Math.round(saldo * 100) / 100.0; System.out.println("Any " + anys + ": " + euros + " €"); } System.out.println("Calen " + anys + " anys per doblar-los."); } }

Com funciona

Els comentaris numerats marquen les parts de control de tot bucle while: la inicialització (saldo comença valent 1000), la condició que es comprova abans de cada volta i l'actualització dins del cos, que fa créixer el saldo un 10 %. Sense l'actualització, la condició no canviaria mai i el bucle seria infinit.

No sabem d'entrada quantes voltes farà: depèn de quan el saldo arribi al doble. Per això és un while i no un for. A cada volta anys++ compta un any més i es mostra el saldo arrodonit a dos decimals.

Si la condició fos false des del principi (per exemple, amb un saldo inicial que ja fos el doble), el cos no s'executaria cap vegada i el programa diria que calen 0 anys.

⚠️ Bucle infinitSi oblides l'actualització, la condició no deixarà mai de ser certa i el programa no s'acabarà. A NetBeans, atura'l amb el botó quadrat vermell de la finestra Output.

El bucle do-while

Primer fa, després pregunta

do { cos } while (condició);: primer executa el cos i després comprova la condició. Per tant, el cos s'executa com a mínim una vegada. Fixa't en el punt i coma final.

Comptar xifres fins que l'usuari vulgui parar
import java.util.Scanner; public class ComptarXifres { public static void main(String[] args) { Scanner sc = new Scanner(System.in); String resposta; // Bucle extern: es repeteix fins que l'usuari no diu "s" do { System.out.print("Número: "); int numero = sc.nextInt(); sc.nextLine(); // recull el salt de línia que deixa nextInt() int n = numero; int xifres = 0; // Bucle intern: el 0 també té 1 xifra do { xifres++; n = n / 10; // traiem l'última xifra } while (n != 0); System.out.println("Té " + xifres + " xifra/es"); System.out.print("Un altre? (s/n): "); resposta = sc.nextLine(); } while (resposta.equals("s")); System.out.println("Fins aviat."); sc.close(); } }
🖥️ Exemple d'execució
Número: 2024
Té 4 xifra/es
Un altre? (s/n): s
Número: 0
Té 1 xifra/es
Un altre? (s/n): n
Fins aviat.
Com funciona

El do-while extern fa la típica estructura de menú: primer demana un número i el tracta, i després pregunta si se'n vol un altre. Com que la pregunta es fa al final, el programa sempre s'executa com a mínim una vegada.

El do-while intern compta les xifres: a cada volta en suma una i treu l'última amb n / 10, fins que n val 0. Amb un while normal, el número 0 no entraria mai al bucle i diria que té 0 xifres; amb el do-while en surt 1, que és correcte.

Després del sc.nextInt() hi ha un sc.nextLine(); de més: el nextInt() deixa el salt de línia sense llegir i, si no el recollíssim, la resposta s/n seria un text buit (és un dels errors típics de l'A1.2).

La condició resposta.equals("s") compara textos: amb String no es fa servir ==. Qualsevol resposta diferent de s fa sortir del bucle.

El bucle for

Quan sabem quantes voltes farà

El for reuneix en una sola línia les tres parts de control del bucle. És la millor opció quan sabem quantes iteracions farem.

📌 Sintaxifor (inicialització; condició; actualització) { cos }
La inicialització s'executa un sol cop. La condició es comprova abans de cada volta. L'actualització s'executa al final de cada volta.
Taula de multiplicar, endavant i cap enrere
public class TaulaMultiplicar { public static void main(String[] args) { int taula = 7; // D'1 a 10, d'1 en 1 for (int i = 1; i <= 10; i++) { System.out.println(taula + " x " + i + " = " + taula * i); } // De 10 a 2, cap enrere i de 2 en 2 System.out.print("Cap enrere:"); for (int i = 10; i >= 2; i -= 2) { System.out.print(" " + taula * i); } System.out.println(); } }

Com funciona

El primer for és el cas més habitual: i va d'1 a 10 sumant 1 a cada volta (i++), i a cada volta es mostra una línia de la taula. Sabem que farà exactament 10 voltes.

El segon for canvia les tres parts: comença a 10, continua mentre i >= 2 i resta 2 a cada volta (i -= 2). Així recorre 10, 8, 6, 4 i 2, i mostra els productes en una sola línia amb print. El println() final només fa el salt de línia.

Totes dues i es poden dir igual perquè cadascuna només existeix dins del seu for.

💡 Àmbit de la variable del forLa i declarada dins del for només existeix dins del bucle. Si la fas servir després, el compilador donarà l'error cannot find symbol. Per això podem tornar a declarar int i al segon bucle.

Un mòbil comença amb la bateria al 100 % i cada hora d'ús en gasta un 15 %. Quan arriba al 20 % o menys, s'activa el mode estalvi. Aquest algorisme mostra la càrrega que queda cada hora i quantes hores han passat. Tradueix-lo a Java a la classe Bateria.

Algoritmo Bateria Definir bateria, hores Como Entero bateria <- 100 hores <- 0 Mientras bateria > 20 Hacer bateria <- bateria - 15 hores <- hores + 1 Escribir "Hora ", hores, ": ", bateria, " %" FinMientras Escribir "Mode estalvi activat després de ", hores, " hores." FinAlgoritmo
  • Marca amb un comentari la inicialització, la condició i l'actualització del bucle.
  • Mientras → while; bateria <- bateria - 15 → bateria -= 15; i hores <- hores + 1 → hores++;.
  • Per què és un while i no un for? Pensa si sabem d'entrada quantes voltes farà.

Hora 2: 70 %
Hora 3: 55 %
Hora 4: 40 %
Hora 5: 25 %

✅ Solució
// Simula com es descarrega la bateria d'un mòbil hora a hora public class Bateria { public static void main(String[] args) { int bateria = 100; // inicialització (percentatge) int hores = 0; // No sabem quantes hores durarà: per això fem servir while while (bateria > 20) { // condició bateria -= 15; // actualització: gasta un 15 % cada hora hores++; System.out.println("Hora " + hores + ": " + bateria + " %"); } System.out.println("Mode estalvi activat després de " + hores + " hores."); } }
✔ Què es valora
  • Les variables bateria i hores s'inicialitzen abans del bucle.
  • La condició del while és la mateixa que la del Mientras.
  • L'actualització és dins del cos, i per això el bucle s'acaba.
  • La sortida coincideix amb l'exemple, espais inclosos.

Un joc amaga el número secret 37. L'usuari va dient números i el programa li respon si ha d'anar més amunt o més avall, fins que l'encerta. Al final diu quants intents ha necessitat. Com que sempre cal demanar almenys un número, l'algorisme fa servir un Repetir. Tradueix-lo a Java a la classe Endevina.

Algoritmo Endevina Definir secret, intent, intents Como Entero secret <- 37 intents <- 0 Repetir Escribir Sin Saltar "Digues un número (1-100): " Leer intent intents <- intents + 1 Si intent < secret Entonces Escribir "Més amunt!" SiNo Si intent > secret Entonces Escribir "Més avall!" FinSi FinSi Hasta Que intent = secret Escribir "Encertat en ", intents, " intents!" FinAlgoritmo
  • Llegeix els números amb Scanner seguint el patró de la nota de dalt (Leer intent → intent = sc.nextInt();), i declara el secret com a constant final.
  • Repetir … Hasta Que intent = secret → do { … } while (intent != secret);: cal negar la condició.
  • El SiNo amb un Si a dins es pot escriure en Java com a else if.

✅ Solució
import java.util.Scanner; // Joc d'endevinar un número secret: es repeteix fins que l'usuari l'encerta public class Endevina { public static void main(String[] args) { final int SECRET = 37; Scanner sc = new Scanner(System.in); int intent; int intents = 0; // Sempre cal demanar almenys un número: per això és un do-while do { System.out.print("Digues un número (1-100): "); intent = sc.nextInt(); intents++; if (intent < SECRET) { System.out.println("Més amunt!"); } else if (intent > SECRET) { System.out.println("Més avall!"); } } while (intent != SECRET); // Hasta Que intent = secret, negat System.out.println("Encertat en " + intents + " intents!"); sc.close(); } }
✔ Què es valora
  • Es fa servir un do-while amb el ; final.
  • La condició està negada correctament (intent != SECRET).
  • El comptador d'intents s'inicialitza a 0 abans del bucle i augmenta a cada volta.
  • La variable intent es declara fora del bucle perquè la condició la pugui fer servir.

Demana per teclat un número i mostra la seva taula de multiplicar de l'1 al 10 amb una capçalera i, al final, la suma de tots els resultats.

  • Fes servir un for i una variable acumuladora.
  • Format de cada línia: 6 x 3 = 18.

import java.util.Scanner; public class TaulaAmbSuma { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.print("Número de la taula: "); int taula = sc.nextInt(); int suma = 0; System.out.println("--- Taula del " + taula + " ---"); for (int i = 1; i <= 10; i++) { int resultat = taula * i; System.out.println(taula + " x " + i + " = " + resultat); suma += resultat; } System.out.println("Suma de resultats: " + suma); sc.close(); } }
✔ Què es valora

  • L'acumulador s'inicialitza a 0 fora del bucle.
  • El número es demana per teclat amb sc.nextInt() i l'Scanner es tanca al final.
Pràctica 2 Suma i factorial Bàsic

Demana per teclat un enter n i calcula la suma dels números de l'1 fins a n i el factorial de n (n! = 1 × 2 × … × n).

  • Llegeix n amb Scanner i sc.nextInt().
  • Fes-ho en un sol bucle for.
  • El factorial creix molt de pressa: fes servir long. Prova amb n = 20 i n = 21: què passa amb el 21?
🖥️ Exemple d'execució
Valor de n: 10
Suma de 1 a 10: 55
10! = 3628800
Bàsic CA: 3.2 · 3.5 · 3.6
✅ Solució
import java.util.Scanner; public class SumaFactorial { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.print("Valor de n: "); int n = sc.nextInt(); int suma = 0; // acumulador de la suma: comença a 0 long factorial = 1; // acumulador del producte: comença a 1! for (int i = 1; i <= n; i++) { suma += i; factorial *= i; } System.out.println("Suma de 1 a " + n + ": " + suma); System.out.println(n + "! = " + factorial); // Amb n = 21 el resultat surt negatiu: desbordament del long // (21! és més gran que Long.MAX_VALUE) sc.close(); } }
✔ Què es valora
  • L'acumulador del producte s'inicialitza a 1 (si fos 0, el resultat sempre seria 0).
  • Detecta i explica el desbordament amb n = 21.
  • El valor de n es demana per teclat amb sc.nextInt() i l'Scanner es tanca al final.
Pràctica 3 Validació de PIN amb 3 intents Mitjà

Un caixer demana el PIN (el correcte és 1234). L'usuari té com a màxim 3 intents. Si l'encerta, mostra "Accés concedit"; si esgota els intents, "Targeta bloquejada".

  • Fes servir Scanner i sc.nextLine() per llegir el PIN com a text.
  • Usa un do-while: el PIN sempre es demana almenys un cop.
  • Després de cada error, indica quants intents queden.
  • Les constants PIN_CORRECTE i MAX_INTENTS han de ser final.
🖥️ Exemple d'execució
Introdueix el PIN: 1111
PIN incorrecte. Et queden 2 intents.
Introdueix el PIN: 1234
Accés concedit.
Mitjà CA: 3.2 · 3.5 · 3.6
✅ Solució
import java.util.Scanner; public class ValidacioPin { public static void main(String[] args) { final String PIN_CORRECTE = "1234"; final int MAX_INTENTS = 3; Scanner sc = new Scanner(System.in); int intents = 0; boolean accedit = false; do { System.out.print("Introdueix el PIN: "); String pin = sc.nextLine(); intents++; if (pin.equals(PIN_CORRECTE)) { accedit = true; } else if (intents < MAX_INTENTS) { int queden = MAX_INTENTS - intents; System.out.println("PIN incorrecte. Et queden " + queden + (queden == 1 ? " intent." : " intents.")); } } while (!accedit && intents < MAX_INTENTS); if (accedit) { System.out.println("Accés concedit."); } else { System.out.println("PIN incorrecte. Targeta bloquejada."); } sc.close(); } }
✔ Què es valora
  • La condició del do-while combina les dues maneres d'acabar (encert i intents esgotats).
  • Els textos es comparen amb equals.
  • Prova-ho també fallant tres vegades.
