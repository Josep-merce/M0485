Com es construeix un programa

Primer es pensa, després es programa

Un programa és una seqüència d'instruccions que un ordinador executa per resoldre un problema. Abans d'escriure codi cal entendre bé el problema i dissenyar-ne la solució: primer es pensa, després es programa.

1AnàlisiQuè ens demanen? Quines dades tenim (entrada) i quin resultat volem (sortida)?
2Disseny de l'algorismeEscrivim els passos en pseudocodi o amb un diagrama, amb paper i llapis, sense pensar encara en Java.
3CodificacióTraduïm l'algorisme al llenguatge de programació (Java) dins de l'entorn de desenvolupament.
4CompilacióEl compilador revisa que el codi estigui ben escrit i el tradueix a un format executable.
5Prova i depuracióExecutem el programa amb diferents valors i comprovem que el resultat és correcte. Si no ho és, busquem l'error.

Exemple: calcular l'àrea i el perímetre d'un rectangle

Primer escrivim l'algorisme en pseudocodi (llenguatge natural estructurat) amb PSeInt i després el traduïm a Java. Aquest tipus d'algorisme, en què les instruccions s'executen una rere l'altra de dalt a baix, s'anomena composició seqüencial.

BàsicDe l'algorisme al codi Java
PSeInt
Algoritmo Rectangle // Declaració de variables Definir base, altura, area, perimetre Como Entero // Dades d'entrada base <- 8 altura <- 5 // Càlculs area <- base * altura perimetre <- 2 * (base + altura) // Sortida Escribir "Àrea: ", area Escribir "Perímetre: ", perimetre FinAlgoritmo
Java
// public: la classe és accessible des de qualsevol lloc // class: declara la classe, el "contenidor" del programa // El nom ha de coincidir amb el del fitxer: Rectangle.java public class Rectangle { // main: punt d'entrada; és el primer que s'executa // public: es pot cridar des de fora; així Java el troba // static: el mètode és de la classe, no d'un objecte // void: no retorna cap resultat // String[] args: arguments que es passen en executar-lo public static void main(String[] args) { // Dades d'entrada int base = 8; int altura = 5; // Càlculs int area = base * altura; int perimetre = 2 * (base + altura); // Sortida // println: escriu per pantalla i salta de línia // El + uneix el text entre cometes amb la variable System.out.println("Àrea: " + area); System.out.println("Perímetre: " + perimetre); } }
🖥️ Sortida per consola
Àrea: 40
Perímetre: 26
Com funciona

El programa té les mateixes tres parts que el pseudocodi: dades d'entrada (base i altura), càlculs i sortida. Les línies que comencen per // són comentaris i Java les ignora: aquí expliquen cada paraula de la capçalera.

Les instruccions s'executen en ordre, de dalt a baix: primer es guarden les dades, després es calculen area i perimetre (que fan servir aquestes dades) i finalment es mostren.

Estructura d'un programa Java

Els blocs que sempre hi són

Tot programa Java està format per uns blocs que sempre apareixen en el mateix ordre. Identificar-los és el primer pas per llegir i entendre qualsevol codi.

MitjàEls blocs d'un programa, comentats
// ① Importacions: classes d'altres paquets que farem servir (opcional) import java.time.LocalDate; // ② Declaració de la classe: el nom ha de coincidir amb el del fitxer public class Estructura { // ③ Mètode main: punt d'entrada. L'execució sempre comença aquí public static void main(String[] args) { // ④ Declaració de variables String nom = "Laia"; int any = LocalDate.now().getYear(); // ⑤ Instruccions: cadascuna acaba amb punt i coma System.out.println("Hola, " + nom + "!"); System.out.println("Som a l'any " + any); } // ← fi del mètode main } // ← fi de la classe
🖥️ Sortida per consola
Hola, Laia!
Som a l'any 2026

L'any surt de la data de l'ordinador: canvia segons quan executis el programa.

Com funciona

L'import ① permet fer servir LocalDate, una classe que serveix per treballar amb dates. La classe ② conté tot el programa i el seu nom coincideix amb el del fitxer, Estructura.java. Dins, el main ③ és on comença l'execució.

Les variables ④ guarden les dades, i les instruccions ⑤ fan la feina; totes acaben en ;. Cada { obre un bloc que es tanca amb el seu }: el primer que es tanca és el del main i el darrer, el de la classe.

BlocObligatori?Funció
package nom.paquet;Sí (a Maven)Indica el paquet (carpeta) de la classe. Ha de ser la primera instrucció i coincidir amb les carpetes de src/main/java (ho has vist a A1.0).
importNoPermet usar classes de llibreries de Java (java.time, java.util…).
public class Nom { }SíConté tot el programa. El fitxer s'ha de dir exactament Nom.java (majúscules incloses).
public static void main(String[] args)Sí (per executar)Punt d'inici. Java executa les instruccions del main de dalt a baix.
Claus { }SíDelimiten blocs de codi. Cada { ha de tenir el seu }.
InstruccionsSíOrdres que fa el programa. Totes acaben en ;.
👀 Fixa't-hi

D'on surt LocalDate? És una classe de la biblioteca estàndard de Java i ve inclosa amb el JDK. No cal descarregar ni afegir res al projecte.

No cal crear un projecte nou per provar l'exemple: crea la classe Estructura al projecte AEA1_A1, deixa la línia package que escriu NetBeans i enganxa el codi a sota (a partir de l'import).

⚠️ Errors típics
  • Majúscules i minúscules. Java les distingeix: system.out.println, string o Main no funcionen.
  • Punt i coma oblidat al final d'una instrucció: ';' expected.
  • Claus desaparellades: si en falta una de tancament, reached end of file while parsing. Sagnar bé el codi (Alt+Maj+F a NetBeans) ajuda a veure-ho.

Mostrar resultats: print i println

La sortida per pantalla

Per mostrar informació per la consola fem servir System.out. Hi ha dues variants: amb salt de línia i sense.

InstruccióQuè fa
System.out.println(x)Mostra x i fa un salt de línia.
System.out.print(x)Mostra x sense saltar de línia.
System.out.println()Només salta de línia (deixa una línia en blanc si ja n'estàvem a l'inici).
"\n" dins un textSalt de línia dins d'una cadena.
"\t" dins un textTabulació.
Bàsicprint i println
public class PrintPrintln { public static void main(String[] args) { System.out.print("Carregant"); System.out.print("."); System.out.print("."); System.out.println("."); // escriu el darrer punt i salta de línia System.out.println("Fet!"); System.out.println(); // línia en blanc System.out.println("Fitxers: " + 3); } }

Fet!

Com funciona

Cada print escriu just on s'ha quedat l'anterior, per això Carregant i els tres punts surten a la mateixa línia. El println(".") escriu el darrer punt i després salta de línia.

El println() buit no escriu res: només salta de línia. Com que ja érem a l'inici d'una línia, deixa una línia en blanc. Amb + podem unir un text i un número en una sola sortida.

Comentaris

Explicar el codi a les persones

Els comentaris són text que el compilador ignora. Serveixen per explicar el codi a les persones: companys, professorat o tu mateix d'aquí a uns mesos. Un bon comentari explica el per què, no el que ja es veu llegint el codi. En Java n'hi ha de dos tipus:

  • Comentari d'una línia //: tot el que hi ha a la dreta de les dues barres fins al final de la línia s'ignora. Pot ocupar una línia sencera o anar al final d'una instrucció.
  • Comentari de diverses línies /* … */: tot el que hi ha entre /* i */ s'ignora, encara que ocupi moltes línies. Serveix per explicar un bloc de codi o per desactivar codi temporalment.
Els dos tipus de comentaris en un programa
// Programa que calcula el preu final d'un article public class CalcularPreu { public static void main(String[] args) { /* Primer apliquem un descompte del 10 % i després hi afegim el 21 % d'IVA */ double preuBase = 40.0; double descompte = preuBase * 0.10; double preuFinal = (preuBase - descompte) * 1.21; System.out.println("Preu final: " + preuFinal + " €"); // 43.56 } }
🖥️ Sortida per consola
Preu final: 43.56 €
Com funciona

La primera línia és un comentari d'una línia // que diu què fa el programa. El comentari /* … */ és de diverses línies: explica la fórmula abans de fer-la, de manera que qui llegeixi el codi entén per què es multiplica per 1.21.

L'últim comentari és un // al final d'una línia de codi: la instrucció de l'esquerra s'executa normalment i el text de la dreta s'ignora. Cap dels comentaris apareix a la sortida.

✅ Bones pràctiques

Bon comentari vs mal comentari: // multipliquem per 1.8 no aporta res (ja es veu al codi). // convertim de Celsius a Fahrenheit sí que ajuda. Comença cada programa amb un comentari que digui què fa.

A NetBeans, Ctrl+/ comenta o descomenta les línies seleccionades.

✍️ Ara tu · Exercici 4Celsius a Fahrenheit, ben comentatAvançat
1 · Llegeix l'algorisme→2 · Escriu-lo en Java→3 · Executa i compara

Tradueix l'algorisme a Java i documenta'l: aquest cop el pseudocodi no porta cap comentari i els has d'afegir tu. Crea la classe Temperatura.

Algoritmo Temperatura Definir celsius, fahrenheit Como Entero celsius <- 25 fahrenheit <- celsius * 9 / 5 + 32 Escribir celsius, " °C són ", fahrenheit, " °F" FinAlgoritmo
✅ Solució
/* * Converteix una temperatura de graus Celsius a graus Fahrenheit. * Fórmula: F = C * 9 / 5 + 32 */ public class Temperatura { public static void main(String[] args) { // Temperatura d'un dia d'estiu, en graus Celsius int celsius = 25; // Primer multipliquem per 9 i després dividim per 5: // així la divisió entre enters dona el resultat exacte int fahrenheit = celsius * 9 / 5 + 32; System.out.println(celsius + " °C són " + fahrenheit + " °F"); } }
✔ Què es valora
  • Hi ha un comentari de bloc inicial amb la finalitat del programa i la fórmula.
  • Els comentaris expliquen el significat de les dades i el perquè del càlcul; no n'hi ha cap del tipus // multipliquem per 9.
  • La traducció és correcta i la sortida coincideix amb l'esperada.
  • Per què l'ordre importa? Amb enters, 9 / 5 dona 1 (es perden els decimals) i el resultat seria 57. Fent primer 25 * 9 = 225 i després 225 / 5 = 45, el resultat és exacte. Ho veurem amb detall a l'A1.3.
  • Comença el programa amb un comentari de bloc /* … */ que digui què fa el programa i quina fórmula fa servir.
  • Afegeix un comentari de línia que expliqui què representa el valor 25.
  • Afegeix un comentari que expliqui per què el càlcul es fa en aquest ordre (primer * 9, després / 5). Recorda: un bon comentari diu el perquè, no repeteix el codi.
  • Prova'l amb 30 °C: ha de sortir 86 °F.
🖥️ Sortida esperada
25 °C són 77 °F
