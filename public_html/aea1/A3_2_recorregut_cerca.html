Esquema de recorregut

Tractar tots els elements

Molts algorismes iteratius segueixen un de dos esquemes. Reconèixer-los t'ajudarà a dissenyar la solució abans de programar.

Estadístiques de les xifres d'un número
public class EstadistiquesXifres { public static void main(String[] args) { int numero = 528174; int n = numero; int suma = 0; // acumulador int parelles = 0; // comptador int maxim = 0; // màxim: cap xifra és menor que 0 // Recorregut de totes les xifres, de dreta a esquerra while (n > 0) { int xifra = n % 10; // última xifra suma += xifra; if (xifra % 2 == 0) { parelles++; } if (xifra > maxim) { maxim = xifra; } n = n / 10; // la traiem } System.out.println("Número: " + numero); System.out.println("Suma de les xifres: " + suma); System.out.println("Xifres parelles: " + parelles); System.out.println("Xifra més gran: " + maxim); } }
🖥️ Sortida per consola
Número: 528174
Suma de les xifres: 27
Xifres parelles: 3
Xifra més gran: 8
Com funciona

És un recorregut: es tracten totes les xifres de 528174, de dreta a esquerra. n % 10 dona l'última xifra i n / 10 la treu; quan n arriba a 0, ja no en queden.

Dins del bucle hi ha els tres esquemes de la taula: un acumulador (suma), un comptador que només augmenta si es compleix una condició (parelles, per a les xifres 2, 4 i 8) i un màxim que s'actualitza quan apareix una xifra més gran.

Totes tres variables s'inicialitzen abans del bucle. El màxim pot començar a 0 perquè cap xifra és més petita que 0.

Esquema de cerca

Aturar-se quan es troba

trobat ← fals MENTRE hi hagi elements I NO trobat FER SI l'element compleix la condició LLAVORS trobat ← cert SINÓ passar al següent element FI MENTRE SI trobat LLAVORS ... SINÓ ... FI SI
El divisor més petit d'un número
public class CercaDivisor { public static void main(String[] args) { int numero = 391; int divisor = 2; boolean trobat = false; // Busquem el primer divisor entre 2 i numero - 1 while (divisor < numero && !trobat) { if (numero % divisor == 0) { trobat = true; // l'hem trobat: el bucle s'aturarà } else { divisor++; } } if (trobat) { System.out.println("El divisor més petit de " + numero + " és " + divisor); } else { System.out.println(numero + " no té divisors: és primer"); } } }

Seqüències amb valor sentinella

Dades que arriben una a una

Sovint les dades arriben una a una i no sabem quantes n'hi haurà. Llavors es fa servir un valor sentinella: un valor especial (per exemple -1) que indica que la seqüència s'ha acabat i que no s'ha de tractar com una dada més. L'esquema fa una lectura avançada: es llegeix el primer valor abans del bucle i el següent al final de cada iteració.

LLEGIR x ← lectura avançada MENTRE x ≠ -1 FER tractar x ← sumar, comptar, comparar… LLEGIR x ← llegim el següent al final FI MENTRE
Seqüència amb sentinella: quantitat, suma, màxim i múltiples de 5
import java.util.Scanner; public class SequenciaSentinella { public static void main(String[] args) { final int SENTINELLA = -1; Scanner sc = new Scanner(System.in); int quantitat = 0; int suma = 0; int maxim = Integer.MIN_VALUE; // tot valor serà més gran boolean multiple5 = false; // encara no n'hem vist cap System.out.print("Número (-1 per acabar): "); int x = Integer.parseInt(sc.nextLine()); // lectura avançada while (x != SENTINELLA) { quantitat++; suma += x; if (x > maxim) { maxim = x; } if (x % 5 == 0) { multiple5 = true; } System.out.print("Número (-1 per acabar): "); x = Integer.parseInt(sc.nextLine()); // següent valor } if (quantitat == 0) { System.out.println("No s'ha introduït cap número."); } else { System.out.println("Quantitat: " + quantitat + " · Suma: " + suma + " · Màxim: " + maxim); System.out.println("Algun múltiple de 5? " + multiple5); } sc.close(); } }

Com funciona

El programa segueix l'esquema de la lectura avançada: llegeix el primer número abans del bucle i el següent al final de cada volta. Així, quan arriba el -1, la condició del while és falsa i el sentinella no es tracta mai com una dada.

Dins del bucle es comptabilitza cada número (quantitat), s'acumula (suma) i es compara amb el màxim, que comença a Integer.MIN_VALUE perquè el primer número ja el superi. La variable booleana multiple5 comença a false i passa a true quan apareix un múltiple de 5; un cop és true, ja no torna a canviar.

Com que calen la suma i el màxim, s'han de llegir tots els números. Si només volguéssim saber si hi ha algun múltiple de 5, seria una cerca: afegiríem && !multiple5 a la condició per parar tan aviat com el trobem. Si el primer valor ja és el -1, el bucle no fa cap volta i el programa avisa que no s'ha introduït cap número.

⚠️ Errors típics amb sentinellesTractar el -1 com si fos una dada (per exemple, sumar-lo), o oblidar la lectura del final del bucle (el programa es queda en un bucle infinit amb el primer valor).

Pràctica 1 Anàlisi de les xifres d'un número Mitjà

Donat un número enter positiu de qualsevol longitud, calcula quantes xifres té, la suma de les xifres, quantes són parells i el número invertit.

  • Declara long numero = 90417263L;
  • Fes un recorregut amb while extraient l'última xifra (% 10) i eliminant-la (/ 10).
  • Per invertir: invertit = invertit * 10 + xifra.
  • Fes la taula de traça de les tres primeres iteracions.

✅ Solució
public class AnalisiXifres { public static void main(String[] args) { long numero = 90417263L; long n = numero; int quantitat = 0; int suma = 0; int parells = 0; long invertit = 0; while (n > 0) { int xifra = (int) (n % 10); quantitat++; suma += xifra; if (xifra % 2 == 0) { parells++; } invertit = invertit * 10 + xifra; n = n / 10; } System.out.println("Número: " + numero); System.out.println("Xifres: " + quantitat); System.out.println("Suma: " + suma); System.out.println("Xifres parells: " + parells); System.out.println("Invertit: " + invertit); } }
✔ Què es valora
  • Es treballa sobre una còpia (n) per no perdre el número original.
  • El casting (int) és necessari perquè n % 10 és long.
  • Hi ha la taula de traça.

Volem conèixer tots els divisors del número 36: quins són, quants n'hi ha i quant sumen. Cal provar tots els números de l'1 al 36, així que és un recorregut amb un comptador i un acumulador. Tradueix l'algorisme a Java a la classe Divisors.

Algoritmo Divisors Definir numero, i, quantitat, suma Como Entero numero <- 36 quantitat <- 0 suma <- 0 Escribir Sin Saltar "Divisors de ", numero, ":" Para i <- 1 Hasta numero Hacer Si numero MOD i = 0 Entonces Escribir Sin Saltar " ", i quantitat <- quantitat + 1 suma <- suma + i FinSi FinPara Escribir "" Escribir "Quantitat: ", quantitat Escribir "Suma: ", suma FinAlgoritmo
  • Indica amb un comentari quina variable és el comptador i quina l'acumulador.
  • numero MOD i = 0 → numero % i == 0; Escribir Sin Saltar → System.out.print.
  • Escribir "" només acaba la línia dels divisors: en Java és System.out.println();.
🖥️ Exemple d'execució

✅ Solució
// Recorregut de l'1 al número: mostra, compta i suma tots els divisors public class Divisors { public static void main(String[] args) { int numero = 36; int quantitat = 0; // comptador int suma = 0; // acumulador System.out.print("Divisors de " + numero + ":"); for (int i = 1; i <= numero; i++) { if (numero % i == 0) { System.out.print(" " + i); quantitat++; suma += i; } } System.out.println(); System.out.println("Quantitat: " + quantitat); System.out.println("Suma: " + suma); } }
✔ Què es valora
  • El comptador i l'acumulador s'inicialitzen a 0 fora del bucle.
  • La condició de divisor es tradueix a numero % i == 0, amb el doble ==.
  • El bucle arriba fins al final: és un recorregut.
  • Els divisors surten a la mateixa línia i la sortida coincideix amb l'exemple.

Un professor va introduint les notes d'un examen una a una i acaba amb el sentinella -1. Només vol saber quina és la primera nota suspesa (menys de 5) i en quina posició és: quan la troba, ja no cal llegir-ne més. És una cerca sobre una seqüència amb sentinella. Tradueix l'algorisme a Java a la classe PrimerSuspens.

Algoritmo PrimerSuspens Definir nota, posicio Como Entero Definir trobat Como Logico posicio <- 0 trobat <- Falso Escribir Sin Saltar "Nota (-1 per acabar): " Leer nota Mientras nota <> -1 Y NO trobat Hacer posicio <- posicio + 1 Si nota < 5 Entonces trobat <- Verdadero SiNo Escribir Sin Saltar "Nota (-1 per acabar): " Leer nota FinSi FinMientras Si trobat Entonces Escribir "Primer suspens: nota ", nota, " a la posició ", posicio SiNo Escribir "Cap suspens en ", posicio, " notes." FinSi FinAlgoritmo
  • Fes servir Scanner amb la lectura avançada i declara el sentinella com a constant final.
  • nota <> -1 Y NO trobat → nota != SENTINELLA && !trobat; Logico → boolean.
  • Prova-ho també sense cap suspens (per exemple 7, 6 i -1): ha de dir Cap suspens en 2 notes.

import java.util.Scanner; // Cerca la primera nota suspesa d'una seqüència acabada en -1 public class PrimerSuspens { public static void main(String[] args) { final int SENTINELLA = -1; Scanner sc = new Scanner(System.in); int posicio = 0; boolean trobat = false; System.out.print("Nota (-1 per acabar): "); int nota = Integer.parseInt(sc.nextLine()); // lectura avançada // Dues maneres d'acabar: arriba el sentinella o trobem un suspens while (nota != SENTINELLA && !trobat) { posicio++; if (nota < 5) { trobat = true; // no llegim més notes } else { System.out.print("Nota (-1 per acabar): "); nota = Integer.parseInt(sc.nextLine()); // següent nota } } if (trobat) { System.out.println("Primer suspens: nota " + nota + " a la posició " + posicio); } else { System.out.println("Cap suspens en " + posicio + " notes."); } sc.close(); } }
✔ Què es valora
  • Hi ha una lectura abans del bucle i una altra quan la nota no és un suspens.
  • La condició del while té les dues maneres d'acabar: arriba el sentinella o s'ha trobat el suspens.
  • La variable trobat és boolean i comença a false.
  • El -1 no es compta com una nota.
