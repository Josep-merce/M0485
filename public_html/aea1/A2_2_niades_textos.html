Alternatives niades

Una decisió dins d'una altra

Una alternativa pot contenir-ne una altra a dins. Ho fem quan una decisió depèn d'una decisió anterior: per exemple, primer validem les dades i, només si són correctes, fem el càlcul.

Algoritmo ReservaHotel Definir nits Como Entero Definir vistesAlMar Como Logico Definir preuNit, total Como Real nits <- 5 vistesAlMar <- Verdadero Si nits <= 0 Entonces Escribir "Error: el nombre de nits ha de ser positiu." SiNo Si vistesAlMar Entonces preuNit <- 190.50 SiNo preuNit <- 150.50 FinSi total <- nits * preuNit Escribir "Total: ", total, " €" FinSi FinAlgoritmo
Reserva d'hotel: niar o combinar condicions
public class ReservaHotel { public static void main(String[] args) { final double TARIFA_SENSE_MAR = 150.50; final double TARIFA_AMB_MAR = 190.50; int nits = 5; boolean vistesAlMar = true; // Niats: cada cas necessita una resposta diferent if (nits <= 0) { System.out.println("Error: el nombre de nits ha de ser positiu."); } else { double preuNit; if (vistesAlMar) { preuNit = TARIFA_AMB_MAR; } else { preuNit = TARIFA_SENSE_MAR; } double total = nits * preuNit; System.out.println("Nits: " + nits + " a " + preuNit + " €/nit"); System.out.println("Total: " + total + " €"); } // Combinada: només importa si es compleixen totes dues if (nits >= 5 && vistesAlMar) { System.out.println("Regal: esmorzar a la terrassa!"); } } }
🖥️ Sortida per consola
Nits: 5 a 190.5 €/nit
Total: 952.5 €
Regal: esmorzar a la terrassa!
Com funciona

L'if exterior valida les dades. L'if interior només s'arriba a avaluar quan les nits són correctes, i tria la tarifa. Aquí cal niar perquè cada cas té una resposta diferent: un missatge d'error o el càlcul del preu.

L'últim if combina dues condicions amb &&: el regal només depèn que es compleixin totes dues alhora i, si no es compleixen, no cal dir res. Es podria escriure amb dos if niats, però seria més llarg sense aportar res.

Fixa't que vistesAlMar ja és un boolean: no cal escriure vistesAlMar == true.

Per endur-se un llibre cal ser soci i no tenir ja el màxim de llibres en préstec. Cada cas dona un missatge diferent, per això l'algorisme fa servir Si niats. Classe Prestec.

Algoritmo Prestec Definir esSoci Como Logico Definir llibresPrestats Como Entero esSoci <- Verdadero llibresPrestats <- 3 Si esSoci Entonces Si llibresPrestats < 3 Entonces Escribir "Pots endur-te el llibre." SiNo Escribir "Ja tens 3 llibres: retorna'n un abans." FinSi SiNo Escribir "Cal fer-se soci per endur-se llibres." FinSi FinAlgoritmo
✅ Solució
public class Prestec { public static void main(String[] args) { final int MAX_LLIBRES = 3; boolean esSoci = true; int llibresPrestats = 3; if (esSoci) { if (llibresPrestats < MAX_LLIBRES) { System.out.println("Pots endur-te el llibre."); } else { System.out.println("Ja tens " + MAX_LLIBRES + " llibres: retorna'n un abans."); } } else { System.out.println("Cal fer-se soci per endur-se llibres."); } } }
✔ Què es valora
  • L'estructura niada és la mateixa que al pseudocodi.
  • El límit és una constant i també s'usa al missatge.
  • S'han provat els tres camins.
  • Converteix el màxim de llibres en una constant MAX_LLIBRES.
  • Respecta la sagnia: l'if interior va un nivell més a dins.
  • Prova els tres camins: soci amb 1 llibre, soci amb 3 llibres i no soci.

Ja tens 3 llibres: retorna'n un abans.

Comparar textos

equals, no ==

A PSeInt els textos es comparen amb =. A Java, els valors de tipus String no es comparen amb ==: cal fer servir els mètodes equals() o equalsIgnoreCase().

ExpressióRetorna true quan…
text.equals("sí")el text és exactament "sí" (distingeix majúscules)
text.equalsIgnoreCase("sí")el text és "sí", "SÍ", "Sí"… (no distingeix majúscules)
text.isEmpty()el text és buit ("")
MitjàValidar una resposta de l'usuari
public class Resposta { public static void main(String[] args) { String resposta = "SI"; if (resposta.equalsIgnoreCase("si")) { System.out.println("Has acceptat les condicions."); } else if (resposta.equalsIgnoreCase("no")) { System.out.println("Has rebutjat les condicions."); } else { System.out.println("Resposta no vàlida: " + resposta); } } }
🖥️ Sortida per consola
Has acceptat les condicions.
Com funciona

Amb equalsIgnoreCase, "SI", "si" i "Si" són la mateixa resposta. Si la resposta no és cap de les dues, l'else final la marca com a no vàlida.

⚠️ Errors típics

Per què no ==? Amb textos, == comprova si les dues variables apunten al mateix objecte a la memòria, no si el contingut és igual. De vegades sembla que funciona i d'altres no. Entendràs el motiu quan estudiem els objectes a l'AEA2; de moment, recorda: textos → equals.

Un programa comprova l'usuari i la contrasenya. L'usuari no distingeix majúscules, però la contrasenya sí. Tradueix-lo a la classe Login.

Algoritmo Login Definir usuari, contrasenya Como Cadena usuari <- "Admin" contrasenya <- "daw2026" Si contrasenya = "" Entonces Escribir "Has d'escriure la contrasenya." SiNo Si Minusculas(usuari) = "admin" Y contrasenya = "daw2026" Entonces Escribir "Benvingut, ", usuari SiNo Escribir "Usuari o contrasenya incorrectes." FinSi FinSi FinAlgoritmo
✅ Solució
public class Login { public static void main(String[] args) { String usuari = "Admin"; String contrasenya = "daw2026"; if (contrasenya.isEmpty()) { System.out.println("Has d'escriure la contrasenya."); } else if (usuari.equalsIgnoreCase("admin") && contrasenya.equals("daw2026")) { // L'usuari no distingeix majúscules; la contrasenya sí System.out.println("Benvingut, " + usuari); } else { System.out.println("Usuari o contrasenya incorrectes."); } } }
✔ Què es valora
  • No hi ha cap == entre textos.
  • S'ha triat bé entre equals i equalsIgnoreCase.
  • La contrasenya buida es comprova primer.
  • Cada = entre textos es converteix en equals o equalsIgnoreCase, segons si importen les majúscules.
  • El Si dins del SiNo es pot escriure com un else if.
  • Prova: "ADMIN" / "daw2026" (entra), "admin" / "DAW2026" (no entra) i contrasenya buida.
💡 Pista
Minusculas(usuari) = "admin" vol dir "l'usuari és admin sense mirar majúscules". A Java és exactament usuari.equalsIgnoreCase("admin").
🖥️ Sortida esperada
Benvingut, Admin

Demo 1Niar o combinar?Mitjà

Per a cada situació, tria si cal if niats o n'hi ha prou amb una condició amb &&.

1. Si és major d'edat i té carnet, mostrar "Pot conduir". Si no, no cal dir res.
Només hi ha un missatge: n'hi ha prou amb if (edat >= 18 && teCarnet).
2. Missatges diferents si és menor d'edat i si és major però no té carnet.
Cada motiu té el seu missatge: cal saber quina condició ha fallat.
3. Validar que les dades són correctes i, només llavors, fer el càlcul; si no, mostrar un error.
El càlcul va dins de la branca de dades correctes, que pot tenir les seves pròpies decisions.
4. Descompte si és soci i la compra supera 50 €.
Una sola acció quan es compleixen les dues condicions.
Demo 2true o false?Bàsic

Tenim String a = "Hola";. Tria què val cada expressió.

1. a.equals("hola")
equals distingeix majúscules: "Hola" i "hola" no són iguals.
2. a.equalsIgnoreCase("HOLA")
No mira majúscules ni minúscules.
3. a.isEmpty()
"Hola" té 4 caràcters.
4. "".isEmpty()
El text buit no té cap caràcter.
5. !a.equals("Adeu")
a.equals("Adeu") és false i ! l'inverteix.
