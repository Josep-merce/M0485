Conversió implícita i explícita (casting)

Quan Java canvia el tipus tot sol i quan l'hem de forçar

Sovint cal passar un valor d'un tipus a un altre. Hi ha tres situacions: la conversió implícita (automàtica), la explícita (casting) i la conversió entre text i números.

TipusCal escriure res?Pot perdre informació?PSeInt
Implícita (de petit a gran)No, Java la fa solaNoEntero → Real: automàtic
Explícita / casting (de gran a petit)Sí: (tipus) valorSí: decimals o desbordamentTRUNC(x) (com (int) x) · REDON(x) (com Math.round(x))
Text ↔ númeroSí: Integer.parseInt(), String.valueOf()…Pot fallar si el text no és un númeroConvertirANumero(t) · ConvertirATexto(n)

Per passar d'un tipus gran a un de més petit cal indicar-ho escrivint el tipus de destinació entre parèntesis: (int) 9.99. Amb això diem al compilador «ja sé que puc perdre informació».

Conversions automàtiques i casting
public class Conversions { public static void main(String[] args) { // Conversió implícita: Java la fa sola int alumnes = 30; double mitjana = 7.5; double suma = alumnes * mitjana; // alumnes es converteix a double long gran = alumnes; // int → long, automàtic char lletra = 'A'; int codi = lletra; // char → int: codi Unicode System.out.println(suma); // 225.0 System.out.println(gran); // 30 System.out.println(codi); // 65 // Conversió explícita (casting): cal indicar-la double preu = 19.99; int preuEnter = (int) preu; // cal indicar (int) System.out.println(preuEnter); // 19 → trunca long arrodonit = Math.round(preu); System.out.println(arrodonit); // 20 → arrodoneix int valor = 130; byte petit = (byte) valor; // byte només arriba a 127 System.out.println(petit); // -126 → desbordament! // Mitjana decimal a partir de dos enters int punts = 17; int partides = 2; double malament = punts / partides; // 8.0 double be = (double) punts / partides; // 8.5 System.out.println("Malament: " + malament); System.out.println("Bé: " + be); } }

Com funciona

Quan en una operació es barregen un int i un double, Java converteix l'int a double abans d'operar: per això suma és 225.0. Guardar un int en un long també és automàtic, perquè un long és més gran i no es perd res.

Un char és, per dins, un número: el codi Unicode del caràcter. Guardat en un int, 'A' es mostra com a 65.

En canvi, (int) 19.99 no arrodoneix: talla els decimals i queda 19. Si volem arrodonir, fem servir Math.round, que dona 20.

Un byte només arriba a 127. En forçar-hi 130, el valor «dona la volta» pel costat negatiu i surt −126: és un desbordament, i Java no avisa.

A malament, 17 / 2 es fa entre enters i dona 8; després es guarda en un double i passa a ser 8.0, però els decimals ja s'han perdut. A be, el casting converteix punts a double abans de dividir, i la divisió ja és decimal.

👀 Fixa't-hi

Sentit de la conversió implícita: byte → short → int → long → float → double. En sentit contrari cal fer casting.

Els decimals no sempre són exactes. Els tipus double i float guarden els números en binari i alguns valors no es poden representar exactament: 0.1 + 0.2 dona 0.30000000000000004. Per això arrodonim els imports amb Math.round(x * 100) / 100.0.

⚠️ Errors típics

El casting trunca: (int) 9.99 dona 9. Per arrodonir usa Math.round(). I compte amb l'ordre: (double) (17 / 2) dona 8.0 perquè la divisió entera es fa abans del casting.

Conversió entre text i números

Quan un número arriba com a text

Un text com "42" no és un número: no es pot sumar ni multiplicar. Per operar-hi cal convertir-lo, i a l'inrevés, de vegades volem un número com a text.

ConversióCom es faExempleResultatPSeInt

String → doubleDouble.parseDouble(text)Double.parseDouble("3.5")3.5ConvertirANumero(text)
String → booleanBoolean.parseBoolean(text)Boolean.parseBoolean("true")true—
número → StringString.valueOf(n)String.valueOf(42)"42"ConvertirATexto(n)
número → Stringconcatenar amb """" + 3.5"3.5"—

public class TextANumero { public static void main(String[] args) { String textQuantitat = "3"; String textPreu = "12.5"; // "3" + "12.5" seria "312.5": cal convertir-los abans d'operar int quantitat = Integer.parseInt(textQuantitat); double preu = Double.parseDouble(textPreu); double total = quantitat * preu; String missatge = "Total: " + String.valueOf(total); System.out.println(textQuantitat + textPreu); // 312.5 (concatenació) System.out.println(missatge); // Total: 37.5 } }
🖥️ Sortida per consola
312.5
Total: 37.5
Com funciona

Si sumem els dos textos tal com estan, el + els enganxa i surt 312.5, que sembla un número però no ho és. Integer.parseInt i Double.parseDouble llegeixen el text i en treuen el número, i amb aquests ja es pot multiplicar.

String.valueOf fa el camí contrari: converteix el resultat a text.

👀 Fixa't-hi

Si el text no representa un número (per exemple Integer.parseInt("hola")), el programa s'atura amb una NumberFormatException. A l'A3 aprendrem a controlar aquests errors amb try-catch.

📚 Per saber-ne més · classes envoltants (wrapper)

Cada tipus primitiu té una classe associada amb utilitats. Les fem servir per consultar límits (com a A1.2) i per convertir text a número.

Com que són classes, el nom comença en majúscula. També hi ha Long, Byte, Short i Float.

3

Composició seqüencial d'instruccions

Dades → procés → sortida

La composició seqüencial és l'estructura més simple: les instruccions s'executen una rere l'altra, de dalt a baix, cadascuna una sola vegada. Tots els programes que hem fet fins ara són seqüencials. Tenen sempre tres parts: dades d'entrada → procés → sortida.

ALGORISME PreuAmbIva DADES: preu = 25, IVA = 0.21 ← entrada CÀLCUL: total ← preu × (1 + IVA) ← procés ESCRIURE "Total: ", total ← sortida FI ALGORISME

L'ordre de les instruccions importa

En un algorisme seqüencial, cada instrucció fa servir els valors que han deixat les anteriors. Si canviem l'ordre, el resultat canvia. L'exemple clàssic és intercanviar el valor de dues variables: cal una variable auxiliar.

PreuAmbIva amb un intercanvi de preus
public class PreuAmbIva { public static void main(String[] args) { // Dades d'entrada: les etiquetes s'han intercanviat! final double IVA = 0.21; double samarreta = 9; // hauria de valer 25 double gorra = 25; // hauria de valer 9 System.out.println("Abans: samarreta = " + samarreta + ", gorra = " + gorra); // Procés 1: intercanviem els preus amb una variable auxiliar double aux = samarreta; // guardem el preu de la samarreta samarreta = gorra; // la samarreta rep el de la gorra gorra = aux; // la gorra rep l'original // Procés 2: ara sí, calculem amb el preu correcte double total = samarreta * (1 + IVA); // Sortida System.out.println("Després: samarreta = " + samarreta + ", gorra = " + gorra); System.out.println("Samarreta amb IVA: " + total); } }
🖥️ Sortida per consola
Abans:   samarreta = 9.0, gorra = 25.0
Després: samarreta = 25.0, gorra = 9.0
Samarreta amb IVA: 30.25
Com funciona

El programa segueix les tres parts del pseudocodi en el mateix ordre: dades d'entrada (l'IVA i els preus), procés (corregir els preus i calcular el total) i sortida. No pren cap decisió ni repeteix res: s'executa de dalt a baix una sola vegada.

Per intercanviar els preus cal una variable auxiliar. Si fem directament samarreta = gorra;, el 9 que hi havia es perd per sempre, i gorra = samarreta; hi tornaria a posar un 25. Per això primer el guardem a aux: és com intercanviar el contingut de dos gots, cal un tercer got.

L'ordre també importa entre els dos processos: si calculéssim total abans de l'intercanvi, faríem servir el preu equivocat (9) i el resultat seria incorrecte.

✅ Bones pràctiques

Abans de programar, escriu en paper les tres parts (dades, procés i sortida) i en quin ordre s'han de calcular els valors: un valor només es pot fer servir després d'haver-lo calculat.

Sortida per pantalla i seqüències d'escapament

Caràcters especials dins dels textos

print i println accepten qualsevol expressió i la converteixen automàticament a text. Cada instrucció escriu just on s'ha quedat l'anterior. Dins d'un text, la contrabarra \ introdueix una seqüència d'escapament: un caràcter especial que no es pot escriure directament.

Bàsicprint, println i seqüències d'escapament
public class SortidaPantalla { public static void main(String[] args) { System.out.print("Hola "); System.out.print("a tothom"); System.out.println(); // només salta de línia System.out.println("Producte\tPreu"); System.out.println("Llibreta\t2.4 €"); System.out.println("Diu: \"Aprendre Java és divertit\""); System.out.println("Ruta: C:\\Usuaris\\alumne"); System.out.println("Línia 1\nLínia 2"); System.out.println(3 + 4); // expressió numèrica: 7 System.out.println('a'); // caràcter } }
🖥️ Sortida per consola
Hola a tothom
Producte	Preu
Llibreta	2.4 €
Diu: "Aprendre Java és divertit"
Ruta: C:\Usuaris\alumne
Línia 1
Línia 2
7

Com funciona

\t insereix una tabulació (per això Preu i 2.4 € surten alineats), \" permet posar cometes dins d'un text sense tancar-lo, \\ escriu una sola contrabarra i \n salta de línia enmig del text.

Les dues últimes línies mostren que println també accepta expressions (calcula 3 + 4 i mostra 7) i caràcters.

Una ruta de Windows escrita tal qual, "C:\nous", no fa el que esperes: \n és un salt de línia! Cal doblar la contrabarra: "C:\\nous".

Un grup d'amics fa una marató de tres pel·lícules que duren 135, 142 i 97 minuts. Aquest algorisme calcula quant dura en total, en hores i minuts, en hores amb decimals i quina és la durada mitjana. Tradueix-lo a Java a la classe Marato.

Algoritmo Marato Definir peli1, peli2, peli3, total, hores, minuts, mitjana Como Entero Definir horesDecimals Como Real peli1 <- 135 peli2 <- 142 peli3 <- 97 total <- peli1 + peli2 + peli3 hores <- TRUNC(total / 60) minuts <- total MOD 60 horesDecimals <- REDON(total / 60 * 100) / 100 mitjana <- REDON(total / 3) Escribir "Total: ", total, " min" Escribir "Temps: ", hores, " h ", minuts, " min" Escribir "En hores: ", horesDecimals, " h" Escribir "Mitjana per pel·lícula: ", mitjana, " min" FinAlgoritmo
  • TRUNC(total / 60) → com que total i 60 són int, total / 60 ja és una divisió entera; MOD → %.
  • A PSeInt / sempre dona decimals; a Java converteix total a double abans de dividir.
  • REDON → Math.round, que retorna un long. Per a dos decimals: Math.round(x * 100) / 100.0.
🖥️ Exemple d'execució
Total: 374 min
Temps: 6 h 14 min
En hores: 6.23 h
Mitjana per pel·lícula: 125 min
✅ Solució
/* * Calcula quant dura una marató de tres pel·lícules * en minuts, en hores i minuts i en hores decimals. */ public class Marato { public static void main(String[] args) { // Dades d'entrada: durada de cada pel·lícula en minuts int peli1 = 135; int peli2 = 142; int peli3 = 97; // Procés int total = peli1 + peli2 + peli3; int hores = total / 60; // divisió entera: com TRUNC int minuts = total % 60; // (double) abans de dividir; arrodonim a 2 decimals double horesDecimals = Math.round((double) total / 60 * 100) / 100.0; long mitjana = Math.round((double) total / 3); // Math.round retorna long // Sortida System.out.println("Total: " + total + " min"); System.out.println("Temps: " + hores + " h " + minuts + " min"); System.out.println("En hores: " + horesDecimals + " h"); System.out.println("Mitjana per pel·lícula: " + mitjana + " min"); } }
✔ Què es valora
  • Les hores i els minuts surten de la divisió entera i del residu, sense casting.
  • El casting a double es fa abans de dividir: (double) (total / 60) donaria 6.0.
  • L'arrodoniment a dos decimals divideix per 100.0, no per 100.
  • mitjana és long (o es converteix amb (int)), perquè Math.round retorna un long.

Una botiga en línia rep les comandes des d'un formulari web, i totes les dades arriben com a text. Aquest algorisme converteix les dades, calcula el subtotal, l'IVA del 21 % i el total arrodonits a cèntims, i els punts de fidelitat (un per cada euro sencer). Tradueix-lo a Java a la classe Comanda.

Algoritmo Comanda Definir producte, textQuantitat, textPreu Como Caracter Definir quantitat, punts Como Entero Definir preu, subtotal, iva, total Como Real producte <- "Samarreta" textQuantitat <- "3" textPreu <- "12.95" quantitat <- ConvertirANumero(textQuantitat) preu <- ConvertirANumero(textPreu) subtotal <- REDON(quantitat * preu * 100) / 100 iva <- REDON(subtotal * 0.21 * 100) / 100 total <- REDON((subtotal + iva) * 100) / 100 punts <- TRUNC(total) Escribir 'Comanda: "', producte, '" x ', quantitat Escribir "Subtotal: ", subtotal, " €" Escribir "IVA (21 %): ", iva, " €" Escribir "" Escribir "Total: ", total, " €" Escribir "Punts de fidelitat: ", punts FinAlgoritmo
  • ConvertirANumero → Integer.parseInt per a la quantitat i Double.parseDouble per al preu.
  • TRUNC(total) → (int) total.
  • A Java el text va sempre entre cometes dobles: posa les cometes de Samarreta amb \", i fes la línia en blanc i el total amb un sol println que comenci amb \n.
🖥️ Exemple d'execució
Comanda: "Samarreta" x 3
Subtotal: 38.85 €
IVA (21 %): 8.16 €

Total: 47.01 €

✅ Solució
/* * Calcula l'import d'una comanda feta amb un formulari web. * Les dades arriben com a text i cal convertir-les abans d'operar. */ public class Comanda { public static void main(String[] args) { // Dades d'entrada: tot arriba com a text String producte = "Samarreta"; String textQuantitat = "3"; String textPreu = "12.95"; // Conversió de text a número int quantitat = Integer.parseInt(textQuantitat); double preu = Double.parseDouble(textPreu); // Procés: arrodonim els imports a 2 decimals double subtotal = Math.round(quantitat * preu * 100) / 100.0; double iva = Math.round(subtotal * 0.21 * 100) / 100.0; double total = Math.round((subtotal + iva) * 100) / 100.0; int punts = (int) total; // el casting trunca els decimals // Sortida: \" posa cometes dins del text i \n salta de línia System.out.println("Comanda: \"" + producte + "\" x " + quantitat); System.out.println("Subtotal: " + subtotal + " €"); System.out.println("IVA (21 %): " + iva + " €"); System.out.println("\nTotal: " + total + " €"); System.out.println("Punts de fidelitat: " + punts); } }
✔ Què es valora
  • Els càlculs es fan amb les variables convertides, no amb els textos.
  • Els imports s'arrodoneixen a cèntims amb Math.round(x * 100) / 100.0: sense arrodonir, 3 * 12.95 dona 38.849999999999994.
  • Els punts surten d'un casting a int, que trunca els decimals.
  • Les cometes interiors s'escriuen amb \" i la línia en blanc amb \n.
