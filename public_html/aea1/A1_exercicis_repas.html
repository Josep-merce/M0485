Ex. 1Cercle: àrea i circumferènciaBàsic

Calcula l'àrea i la longitud de la circumferència d'un cercle de radi 5.

  • Declara double radi = 5;
  • Usa la constant Math.PI. Àrea = π · r²; circumferència = 2 · π · r.
  • Mostra els dos resultats arrodonits a 2 decimals (mira l'exemple Obtenir una mitjana decimal a partir d'enters d'A1.4, secció 2).
🖥️ Sortida esperada
Radi: 5.0
Àrea: 78.54
Circumferència: 31.42
BàsicCA: 1.5 · 1.7 · 1.8
✅ Solució
public class Cercle { public static void main(String[] args) { double radi = 5; double area = Math.PI * radi * radi; double circumferencia = 2 * Math.PI * radi; // Arrodonim a 2 decimals area = Math.round(area * 100) / 100.0; circumferencia = Math.round(circumferencia * 100) / 100.0; System.out.println("Radi: " + radi); System.out.println("Àrea: " + area); System.out.println("Circumferència: " + circumferencia); } }
✔ Què es valora
  • Fa servir Math.PI en lloc de 3.14.
  • L'arrodoniment divideix per 100.0 (decimal) i no per 100.
Ex. 2Les edats de la famíliaMitjà

Una família té 6 membres: dos germans (Joan i Marta), els dos pares i els dos avis materns. Sabem que:

  • L'avi té sis vegades l'edat de la Marta.
  • L'àvia té la suma de les edats dels pares menys l'edat de la Marta.
  • L'edat del Joan és el residu (mòdul) de dividir l'edat del pare entre la de la Marta.
  • L'edat de la mare és el triple de l'edat de la Marta més l'edat del Joan.
  • L'edat del pare és el resultat de multiplicar per 6 la divisió entera entre l'edat de l'avi i la de la Marta.
  • La Marta té 10 anys.
  • Calcula i mostra totes les edats. Pensa en quin ordre has de fer els càlculs: no és el mateix ordre de l'enunciat.
🖥️ Sortida esperada
Marta: 10 anys
Joan: 6 anys
Pare: 36 anys
Mare: 36 anys
Avi: 60 anys
Àvia: 62 anys
MitjàCA: 1.5 · 1.7
✅ Solució
public class EdatsFamilia { public static void main(String[] args) { // Només coneixem l'edat de la Marta: la resta depèn d'altres edats, // així que cal calcular-les en l'ordre en què es necessiten int marta = 10; int avi = 6 * marta; // 60 int pare = 6 * (avi / marta); // 36 (necessita l'avi) int joan = pare % marta; // 6 (necessita el pare) int mare = 3 * marta + joan; // 36 (necessita el Joan) int avia = pare + mare - marta; // 62 (necessita pare i mare) System.out.println("Marta: " + marta + " anys"); System.out.println("Joan: " + joan + " anys"); System.out.println("Pare: " + pare + " anys"); System.out.println("Mare: " + mare + " anys"); System.out.println("Avi: " + avi + " anys"); System.out.println("Àvia: " + avia + " anys"); } }
✔ Què es valora
  • Els càlculs segueixen l'ordre de dependències (avi → pare → Joan → mare → àvia).
  • Es fan servir la divisió entera / i el residu % com demana l'enunciat.
Ex. 3Les xifres d'un númeroAvançat

Donat un número de 4 xifres, mostra cadascuna de les xifres per separat, la seva suma i el número escrit al revés.

  • Declara int numero = 2745;
  • Obtén les unitats, desenes, centenes i milers combinant / i % amb 10, 100 i 1000.
  • Calcula la suma de les xifres i el número invertit (5472) com a enter, no com a text.
🖥️ Sortida esperada
Milers: 2, centenes: 7, desenes: 4, unitats: 5
Suma de xifres: 18
Invertit: 5472
AvançatCA: 1.5 · 1.7
✅ Solució
public class XifresNumero { public static void main(String[] args) { int numero = 2745; int unitats = numero % 10; // 5 int desenes = numero / 10 % 10; // 4 int centenes = numero / 100 % 10; // 7 int milers = numero / 1000; // 2 int suma = unitats + desenes + centenes + milers; int invertit = unitats * 1000 + desenes * 100 + centenes * 10 + milers; System.out.println("Milers: " + milers + ", centenes: " + centenes + ", desenes: " + desenes + ", unitats: " + unitats); System.out.println("Suma de xifres: " + suma); System.out.println("Invertit: " + invertit); } }
✔ Què es valora
  • Entén que numero / 10 % 10 s'avalua d'esquerra a dreta: primer / i després %.
  • El número invertit es construeix amb operacions aritmètiques.
Ex. 4Caixer automàtic: bitllets i monedesAvançat

Un caixer ha de lliurar 187 €. Calcula quants bitllets de 50, 20, 10 i 5 € i quantes monedes de 2 i 1 € cal donar, fent servir el mínim nombre de peces.

  • Declara int import = 187; (pista: import és paraula reservada, tria un altre nom!).
  • Per a cada valor: quantes peces = restant / valor; restant = restant % valor.
  • Mostra només el resultat final de cada tipus de peça.
🖥️ Sortida esperada
Import: 187 €
Bitllets de 50: 3
Bitllets de 20: 1
Bitllets de 10: 1
Bitllets de 5: 1
Monedes de 2: 1
Monedes d'1: 0
AvançatCA: 1.4 · 1.5 · 1.7
✅ Solució
public class Caixer { public static void main(String[] args) { int quantitat = 187; // "import" és una paraula reservada de Java int restant = quantitat; int b50 = restant / 50; restant = restant % 50; int b20 = restant / 20; restant = restant % 20; int b10 = restant / 10; restant = restant % 10; int b5 = restant / 5; restant = restant % 5; int m2 = restant / 2; restant = restant % 2; int m1 = restant; System.out.println("Import: " + quantitat + " €"); System.out.println("Bitllets de 50: " + b50); System.out.println("Bitllets de 20: " + b20); System.out.println("Bitllets de 10: " + b10); System.out.println("Bitllets de 5: " + b5); System.out.println("Monedes de 2: " + m2); System.out.println("Monedes d'1: " + m1); } }
✔ Què es valora
  • Reutilitza la variable restant en cada pas.
  • Detecta que import no es pot usar com a nom de variable.
Ex. 5Troba i corregeix els errorsAvançat

El programa següent hauria de calcular el preu d'una entrada de cinema amb un 15 % de descompte, però té errors de compilació i de lògica. Copia'l a NetBeans, localitza'ls i corregeix-los.

  • public class entradaCinema {
      public static void main(String[] args) {
        final double DESCOMPTE = 15;
        int preu = 8.50;
        String sala = '3';
        double preuFinal = preu - preu * DESCOMPTE
        DESCOMPTE = 20;
        System.out.println("Sala " + sala + ": " + preufinal + " €");
      }
    }
  • Hi ha 6 errors (de compilació i de lògica) i 1 mala pràctica de nomenclatura. Per a cadascun, afegeix un comentari explicant què passava.
  • Compte: el compilador de vegades mostra primer només l'error del punt i coma. Quan el corregeixes, apareixen els altres. Corregeix-los un a un.
  • Recorda: el nom del fitxer ha de coincidir amb el de la classe.
🖥️ Sortida esperada
Sala 3: 7.23 €
AvançatCA: 1.3 · 1.4 · 1.5 · 1.6 · 1.8 · 1.9
✅ Solució
// 1. Mala pràctica: el nom de la classe comença en majúscula (fitxer EntradaCinema.java) public class EntradaCinema { public static void main(String[] args) { // 2. El descompte és un percentatge: 15 % = 0.15 (error de lògica) final double DESCOMPTE = 0.15; // 3. Un preu amb decimals ha de ser double, no int double preu = 8.50; // 4. Un String va entre cometes dobles String sala = "3"; // 5. Faltava el punt i coma double preuFinal = preu - preu * DESCOMPTE; preuFinal = Math.round(preuFinal * 100) / 100.0; // 6. Eliminada la línia DESCOMPTE = 20; → una constant no es pot reassignar // 7. preufinal → preuFinal (Java distingeix majúscules i minúscules) System.out.println("Sala " + sala + ": " + preuFinal + " €"); } }
✔ Què es valora
  • Distingeix errors de compilació (sintaxi, tipus) d'errors de lògica (el 15 en lloc de 0.15).
  • Cada correcció està justificada amb un comentari.
