Operadors aritmètics

Fer càlculs amb números

Un operador és un símbol que fa una operació sobre un o més valors (operands). Una expressió és una combinació d'operands i operadors que produeix un resultat. Aquestes són les famílies d'operadors que veurem en aquesta subpàgina:

public class OperadorsAritmetics { public static void main(String[] args) { int a = 10; int b = 3; System.out.println(a + b); // 13 suma System.out.println(a - b); // 7 resta System.out.println(a * b); // 30 multiplicació System.out.println(a / b); // 3 divisió ENTERA System.out.println(a % b); // 1 residu de 10 / 3 System.out.println(10.0 / b); // 3.3333333333333335 // Divisió entera i residu en parella: minuts a hores int minutsTotals = 137; int hores = minutsTotals / 60; // 2 int minuts = minutsTotals % 60; // 17 System.out.println(minutsTotals + " minuts = " + hores + " h " + minuts + " min"); // El residu també diu si un número és parell int numero = 14; boolean esParell = numero % 2 == 0; System.out.println(numero + " és parell: " + esParell); } }

Com funciona

Suma, resta i multiplicació funcionen com a matemàtiques. La divisió a / b dona 3 perquè els dos operands són enters: Java fa una divisió entera i descarta els decimals. L'operador % dona el residu d'aquesta divisió: 10 = 3 · 3 + 1. Amb 10.0, que és decimal, la divisió també ho és; l'últim dígit (…35) surt perquè els decimals es guarden en binari i no sempre són exactes.

La divisió entera i el residu treballen en parella: 137 / 60 diu quantes hores senceres hi caben (2) i 137 % 60 quants minuts sobren (17). És la mateixa idea que farem servir per descompondre segons o per donar canvi.

Un número és parell quan el residu de dividir-lo entre 2 és 0. numero % 2 == 0 fa primer el residu i després la comparació, i el resultat (true) es guarda en un boolean.

⚠️ Errors típics

Divisió entera: si els dos operands són enters, / descarta els decimals: 10 / 3 dona 3. Perquè doni 3.333… cal que almenys un sigui decimal: 10.0 / 3. Compte, perquè a PSeInt 7 / 2 sempre dona 3.5.

Potència: Java no té l'operador ^ de PSeInt per elevar. 2 ^ 3 compila, però no calcula cap potència (dona 1): s'escriu Math.pow(2, 3) (secció 5).

Increment, decrement i assignació composta

Dreceres per modificar variables

Modificar una variable a partir del seu propi valor és tan habitual que Java té operadors abreujats: a++ suma 1, a-- resta 1 i a += 5 és el mateix que a = a + 5.

Operadors abreujats: puntuació i vides d'un joc
public class AssignacioComposta { public static void main(String[] args) { int punts = 100; int vides = 3; // Assignació composta: operar i guardar en un sol pas punts += 50; // punts = punts + 50 → 150 punts -= 30; // punts = punts - 30 → 120 punts *= 2; // punts = punts * 2 → 240 punts /= 4; // punts = punts / 4 → 60 punts %= 7; // punts = punts % 7 → 4 System.out.println("Punts finals: " + punts); // Post-increment: primer assigna (3), després incrementa int resultat = vides++; System.out.println(resultat + " " + vides); // 3 4 // Pre-increment: primer incrementa (5), després assigna resultat = ++vides; System.out.println(resultat + " " + vides); // 5 5 } }
🖥️ Sortida per consola
Punts finals: 4
3 4
5 5
Com funciona

Cada operador compost agafa el valor actual de punts, hi fa l'operació i hi guarda el resultat. Les instruccions s'executen en ordre, de manera que cada línia parteix del valor que ha deixat l'anterior: 100 → 150 → 120 → 240 → 60 → 4.

Amb ++ totes dues formes sumen 1 a vides; la diferència és quin valor fa servir l'expressió. Amb vides++ (darrere) primer s'usa el valor antic (3) i després s'incrementa; amb ++vides (davant) primer s'incrementa i després s'usa el valor nou (5).

Quan vides++ va sol en una línia (vides++;), no hi ha cap diferència. Només importa si el fem servir dins d'una altra expressió.

✅ Bones pràctiques

Fes servir ++ i -- en una línia pròpia (comptador++;). Posar-los dins d'expressions més llargues fa el codi difícil de llegir i és una font d'errors.

Operadors relacionals i lògics

Comparar valors i combinar condicions

Els operadors relacionals comparen dos valors i sempre retornen un boolean. Els operadors lògics combinen valors boolean i permeten expressar condicions compostes com «té compte i la contrasenya és correcta». Són la base de les decisions que prendrem a l'A2.

==igualels dos valors són iguals=
!=diferentels dos valors són diferents<>
> · <més gran · més petitel valor de l'esquerra és més gran (més petit) que el de la dreta> · < (iguals)
>= · <=més gran o igual · més petit o igualcom l'anterior, o bé són iguals>= · <= (iguals)
&&I (AND)els dos operands són trueY (o &)
||O (OR)almenys un operand és trueO (o |)
!NO (NOT)l'operand és false (l'inverteix)NO (o ~)
Comparar valors i combinar condicions
public class Condicions { public static void main(String[] args) { // Relacionals: comparen dos valors i donen un boolean int edat = 17; double nota = 4.8; System.out.println(edat >= 18); // false System.out.println(nota < 5.0); // true System.out.println(nota == 5.0); // false System.out.println(edat != 18); // true // Lògics: combinen condicions d'accés a una plataforma boolean teCompte = true; boolean contrasenyaOk = false; boolean estaBloquejat = false; int intentsFallits = 2; // Entra si té compte, contrasenya bona i no està bloquejat boolean potEntrar = teCompte && contrasenyaOk && !estaBloquejat; System.out.println("Pot entrar: " + potEntrar); // false // Avís si la contrasenya falla o porta 2 intents fallits boolean mostrarAvis = !contrasenyaOk || intentsFallits >= 2; System.out.println("Mostrar avís: " + mostrarAvis); // true // Els anys de traspàs la plataforma regala un mes gratis int any = 2024; boolean esTraspas = (any % 4 == 0 && any % 100 != 0) || any % 400 == 0; System.out.println(any + " és de traspàs: " + esTraspas); } }

Com funciona

Cada comparació relacional és una pregunta que té resposta de sí o no: l'edat és més gran o igual que 18? No, per tant false. El resultat es pot mostrar directament o guardar en una variable boolean.

== pregunta si dos valors són iguals i != si són diferents.

Amb && cal que totes les condicions es compleixin: com que contrasenyaOk és false, potEntrar és false. !estaBloquejat inverteix el valor: «no està bloquejat» és true. Amb || n'hi ha prou que se'n compleixi una: la contrasenya és incorrecta, per tant mostrarAvis ja és true.

L'última expressió tradueix la regla del calendari: un any és de traspàs si és divisible per 4 i no per 100, o bé si és divisible per 400. Per a 2024, el parèntesi dona true && true, i amb això ja n'hi ha prou: true || false és true.

Els parèntesis agrupen la primera condició i fan l'expressió més fàcil de llegir. Prova-ho amb 1900 (false) i amb 2000 (true).

⚠️ Errors típics

No confonguis == amb =: edat == 18 pregunta si val 18 i retorna true o false. edat = 18 assigna el valor 18. Compte: a PSeInt = serveix per comparar; a Java = és l'assignació. Per comparar textos (String) no s'usa == sinó .equals(), com veurem a l'A2.

Concatenació de cadenes

Unir textos amb +

Quan un dels dos operands del + és un String, el + deixa de sumar i uneix (concatena): l'altre valor es converteix a text i s'hi enganxa.

MitjàLa trampa de l'ordre: suma o concatenació?
public class OrdreConcatenacio { public static void main(String[] args) { int a = 5; int b = 3; System.out.println("Resultat: " + a + b); // Resultat: 53 ← s'enganxen com a text! System.out.println("Resultat: " + (a + b)); // Resultat: 8 ← correcte System.out.println(a + b + " és la suma"); // 8 és la suma (s'avalua d'esquerra a dreta) } }
🖥️ Sortida per consola
Resultat: 53
Resultat: 8
8 és la suma
Com funciona

Els + s'avaluen d'esquerra a dreta. A la primera línia, "Resultat: " + a ja és un text, i en afegir-hi b s'enganxa un 3: surt 53. Els parèntesis de la segona línia obliguen a sumar primer.

A la tercera, a + b són dos enters i se sumen (8) abans de trobar el text.

✅ Bones pràctiques

Quan vulguis mostrar el resultat d'un càlcul dins d'un text, posa el càlcul entre parèntesis: "Total: " + (preu * quantitat).

Precedència d'operadors

Quina operació es fa primer

Quan una expressió té diversos operadors, Java segueix un ordre fix, com a matemàtiques. De més a menys prioritat: ! i ++ -- → * / % → + - → < > <= >= → == != → && → || → = += -=… Els operadors del mateix nivell s'avaluen d'esquerra a dreta.

MitjàLa precedència en acció
public class Precedencia { public static void main(String[] args) { System.out.println(2 + 3 * 4); // * abans que + System.out.println((2 + 3) * 4); // el parèntesi primer System.out.println(20 - 8 - 2); // d'esquerra a dreta System.out.println(20 / 4 * 2); // d'esquerra a dreta System.out.println(7 + 10 % 4); // % abans que + System.out.println(3 + 4 > 6 && 2 * 5 == 10); } }
🖥️ Sortida per consola
14
20
10
10
9
true
Com funciona

A 2 + 3 * 4 es multiplica primer (12) i després se suma: 14. Els parèntesis canvien l'ordre: (2 + 3) * 4 = 20. Quan els operadors tenen la mateixa prioritat, es va d'esquerra a dreta: 20 - 8 - 2 = 10 i 20 / 4 * 2 = 10.

A la darrera línia es fan primer els càlculs (7 i 10), després les comparacions (true i true) i finalment el &&.

✅ Bones pràctiques

Quan tinguis dubtes, fes servir parèntesis: no costen res i fan el codi més clar per a qui el llegeix.

Una granja ha recollit 250 ous i els posa en capses de 12. Aquest algorisme calcula quantes capses queden plenes, quants ous sobren i quants en faltarien per omplir una capsa més. Tradueix-lo a Java a la classe Ous.

Algoritmo Ous Definir ous, ousPerCapsa, capses, sobrants Como Entero ous <- 250 ousPerCapsa <- 12 capses <- trunc(ous / ousPerCapsa) sobrants <- ous MOD ousPerCapsa Escribir "Ous recollits: ", ous Escribir "Capses plenes: ", capses Escribir "Ous que sobren: ", sobrants Escribir "Ous per a una capsa més: ", ousPerCapsa - sobrants FinAlgoritmo
  • trunc(ous / ousPerCapsa) → ous / ousPerCapsa: entre dos int, Java ja fa la divisió entera.
  • MOD → %.
  • Les comes d'Escribir passen a ser +. Si dins del text hi ha un càlcul, posa'l entre parèntesis.
🖥️ Exemple d'execució
Ous recollits: 250
Capses plenes: 20
Ous que sobren: 10
Ous per a una capsa més: 2
✅ Solució
// Calcula quantes capses d'ous es poden omplir i quants ous sobren public class Ous { public static void main(String[] args) { int ous = 250; int ousPerCapsa = 12; int capses = ous / ousPerCapsa; // divisió entera: capses plenes int sobrants = ous % ousPerCapsa; // residu: ous que no omplen cap capsa System.out.println("Ous recollits: " + ous); System.out.println("Capses plenes: " + capses); System.out.println("Ous que sobren: " + sobrants); System.out.println("Ous per a una capsa més: " + (ousPerCapsa - sobrants)); } }
✔ Què es valora
  • Fa servir / entre enters per obtenir les capses plenes, sense cap trunc.
  • Fa servir % per obtenir els ous que sobren.
  • (ousPerCapsa - sobrants) va entre parèntesis: sense, el programa no compila, perquè - no es pot aplicar a un text.
  • La sortida coincideix amb l'exemple.

Un alumne té tres notes i ha assistit al 75 % de les classes. Aquest algorisme calcula la mitjana, la mostra arrodonida i diu si aprova (mitjana ≥ 5) i si té beca (mitjana ≥ 7 i assistència ≥ 80 %). Tradueix-lo a Java a la classe Beca.

Algoritmo Beca Definir nota1, nota2, nota3, mitjana Como Real Definir assistencia Como Entero Definir aprovat, teBeca Como Logico nota1 <- 6.5 nota2 <- 8 nota3 <- 7.25 assistencia <- 75 mitjana <- (nota1 + nota2 + nota3) / 3 aprovat <- mitjana >= 5 teBeca <- mitjana >= 7 Y assistencia >= 80 Escribir "Mitjana: ", mitjana Escribir "Nota arrodonida: ", redon(mitjana) Escribir "Aprovat: ", aprovat Escribir "Té beca: ", teBeca FinAlgoritmo
  • Y → &&; redon(x) → Math.round(x).
  • Guarda les comparacions en variables boolean: aprovat i teBeca.
  • Mantén els parèntesis de la mitjana: sense ells, només es dividiria nota3 entre 3.

✅ Solució
// Calcula la mitjana d'un alumne i comprova si aprova i si té beca public class Beca { public static void main(String[] args) { double nota1 = 6.5; double nota2 = 8; double nota3 = 7.25; int assistencia = 75; // percentatge de classes // Sense parèntesis només es dividiria nota3 entre 3 double mitjana = (nota1 + nota2 + nota3) / 3; boolean aprovat = mitjana >= 5; boolean teBeca = mitjana >= 7 && assistencia >= 80; System.out.println("Mitjana: " + mitjana); System.out.println("Nota arrodonida: " + Math.round(mitjana)); System.out.println("Aprovat: " + aprovat); System.out.println("Té beca: " + teBeca); } }
✔ Què es valora
  • La mitjana fa servir parèntesis: (nota1 + nota2 + nota3) / 3.
  • teBeca combina dues comparacions amb &&: com que l'assistència és 75, és false encara que la mitjana passi de 7.
  • Math.round(mitjana) en lloc de redon.
  • Els resultats lògics es guarden en variables boolean, no s'escriuen a mà.
