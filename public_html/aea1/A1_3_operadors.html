Operadors aritmètics

Fer càlculs amb números

Un operador és un símbol que fa una operació sobre un o més valors (operands). Una expressió és una combinació d'operands i operadors que produeix un resultat. Aquestes són les famílies d'operadors que veurem en aquesta subpàgina:

Relacionals== != > < >= <=5 > 3true
Lògics&& || !true && falsefalse

Operadors aritmètics i divisió entera
public class OperadorsAritmetics { public static void main(String[] args) { int a = 10; int b = 3; System.out.println(a + b); // 13 suma System.out.println(a - b); // 7 resta System.out.println(a * b); // 30 multiplicació System.out.println(a / b); // 3 divisió ENTERA System.out.println(a % b); // 1 residu de 10 / 3 System.out.println(10.0 / b); // 3.3333333333333335 // Divisió entera i residu en parella: minuts a hores int minutsTotals = 137; int hores = minutsTotals / 60; // 2 int minuts = minutsTotals % 60; // 17 System.out.println(minutsTotals + " minuts = " + hores + " h " + minuts + " min"); // El residu també diu si un número és parell int numero = 14; boolean esParell = numero % 2 == 0; System.out.println(numero + " és parell: " + esParell); } }

Com funciona

Suma, resta i multiplicació funcionen com a matemàtiques. La divisió a / b dona 3 perquè els dos operands són enters: Java fa una divisió entera i descarta els decimals. L'operador % dona el residu d'aquesta divisió: 10 = 3 · 3 + 1. Amb 10.0, que és decimal, la divisió també ho és; l'últim dígit (…35) surt perquè els decimals es guarden en binari i no sempre són exactes.

La divisió entera i el residu treballen en parella: 137 / 60 diu quantes hores senceres hi caben (2) i 137 % 60 quants minuts sobren (17). És la mateixa idea que farem servir per descompondre segons o per donar canvi.

Un número és parell quan el residu de dividir-lo entre 2 és 0. numero % 2 == 0 fa primer el residu i després la comparació, i el resultat (true) es guarda en un boolean.

⚠️ Errors típics

Divisió entera: si els dos operands són enters, / descarta els decimals: 10 / 3 dona 3. Perquè doni 3.333… cal que almenys un sigui decimal: 10.0 / 3.

Un cronòmetre marca 4.000 segons. Tradueix l'algorisme que els descompon en hores, minuts i segons. Crea la classe Cronometre.

Algoritmo Cronometre Definir segonsTotals, hores, resta, minuts, segons Como Entero segonsTotals <- 4000 hores <- trunc(segonsTotals / 3600) resta <- segonsTotals MOD 3600 minuts <- trunc(resta / 60) segons <- resta MOD 60 Escribir segonsTotals, " s = ", hores, " h ", minuts, " min ", segons, " s" FinAlgoritmo

// Descompon una quantitat de segons en hores, minuts i segons public class Cronometre { public static void main(String[] args) { final int SEGONS_HORA = 3600; final int SEGONS_MINUT = 60; int segonsTotals = 4000; // Divisió entera: quantes hores senceres hi caben int hores = segonsTotals / SEGONS_HORA; // Residu: els segons que sobren després de treure les hores int resta = segonsTotals % SEGONS_HORA; int minuts = resta / SEGONS_MINUT; int segons = resta % SEGONS_MINUT; System.out.println(segonsTotals + " s = " + hores + " h " + minuts + " min " + segons + " s"); } }

  • Fa servir % per obtenir el que sobra després de treure les hores.
  • No hi ha números màgics: 3600 i 60 són constants.
  • A PSeInt / sempre dona decimals i per això cal trunc. A Java, què passa quan divideixes dos int? Necessites el trunc?
  • MOD → %.
  • No deixis números màgics: declara 3600 i 60 com a constants (SEGONS_HORA i SEGONS_MINUT), com vas aprendre a l'A1.2.
  • Prova-ho també amb 7322: ha de sortir 2 h 2 min 2 s.

Increment, decrement i assignació composta

Dreceres per modificar variables

Modificar una variable a partir del seu propi valor és tan habitual que Java té operadors abreujats: a++ suma 1, a-- resta 1 i a += 5 és el mateix que a = a + 5.

Operadors abreujats: puntuació i vides d'un joc
public class AssignacioComposta { public static void main(String[] args) { int punts = 100; int vides = 3; // Assignació composta: operar i guardar en un sol pas punts += 50; // punts = punts + 50 → 150 punts -= 30; // punts = punts - 30 → 120 punts *= 2; // punts = punts * 2 → 240 punts /= 4; // punts = punts / 4 → 60 punts %= 7; // punts = punts % 7 → 4 System.out.println("Punts finals: " + punts); // Post-increment: primer assigna (3), després incrementa int resultat = vides++; System.out.println(resultat + " " + vides); // 3 4 // Pre-increment: primer incrementa (5), després assigna resultat = ++vides; System.out.println(resultat + " " + vides); // 5 5 } }
🖥️ Sortida per consola
Punts finals: 4
3 4
5 5
Com funciona

Cada operador compost agafa el valor actual de punts, hi fa l'operació i hi guarda el resultat. Les instruccions s'executen en ordre, de manera que cada línia parteix del valor que ha deixat l'anterior: 100 → 150 → 120 → 240 → 60 → 4.

Amb ++ totes dues formes sumen 1 a vides; la diferència és quin valor fa servir l'expressió. Amb vides++ (darrere) primer s'usa el valor antic (3) i després s'incrementa; amb ++vides (davant) primer s'incrementa i després s'usa el valor nou (5).

Quan vides++ va sol en una línia (vides++;), no hi ha cap diferència. Només importa si el fem servir dins d'una altra expressió.

✅ Bones pràctiques

Fes servir ++ i -- en una línia pròpia (comptador++;). Posar-los dins d'expressions més llargues fa el codi difícil de llegir i és una font d'errors.

PSeIntJava

total <- total + preutotal += preu;

Operadors relacionals

Comparar valors

Comparen dos valors i sempre retornen un boolean. Són la base de les decisions que prendrem a l'A2.

BàsicComparar valors
public class Comparacions { public static void main(String[] args) { int edat = 17; double nota = 4.8; System.out.println(edat >= 18); // false System.out.println(nota < 5.0); // true System.out.println(nota == 5.0); // false System.out.println(edat != 18); // true } }
🖥️ Sortida per consola
false
true
false
true
Com funciona

Cada comparació és una pregunta que té resposta de sí o no: l'edat és més gran o igual que 18? No, per tant false. El resultat es pot mostrar directament o guardar en una variable boolean.

== pregunta si dos valors són iguals i != si són diferents.

⚠️ Errors típics

No confonguis == amb =: edat == 18 pregunta si val 18 i retorna true o false. edat = 18 assigna el valor 18. Per comparar textos (String) no s'usa == sinó .equals(), com veurem a l'A2.

Compte: a PSeInt = serveix per comparar; a Java = és l'assignació.

Operadors lògics

Combinar condicions

Els operadors lògics combinen valors boolean. Permeten expressar condicions compostes com «té compte i la contrasenya és correcta».

OperadorNomRetorna true quan…
&&I (AND)els dos operands són true
||O (OR)almenys un operand és true
!NO (NOT)l'operand és false (l'inverteix)
Condicions d'accés a una plataforma
public class AccesPlataforma { public static void main(String[] args) { boolean teCompte = true; boolean contrasenyaOk = false; boolean estaBloquejat = false; int intentsFallits = 2; // Entra si té compte, contrasenya bona i no està bloquejat boolean potEntrar = teCompte && contrasenyaOk && !estaBloquejat; System.out.println("Pot entrar: " + potEntrar); // false // Avís si la contrasenya falla o porta 2 intents fallits boolean mostrarAvis = !contrasenyaOk || intentsFallits >= 2; System.out.println("Mostrar avís: " + mostrarAvis); // true // Els anys de traspàs la plataforma regala un mes gratis int any = 2024; boolean esTraspas = (any % 4 == 0 && any % 100 != 0) || any % 400 == 0; System.out.println(any + " és de traspàs: " + esTraspas); } }
🖥️ Sortida per consola
Pot entrar: false
Mostrar avís: true
2024 és de traspàs: true
Com funciona

Amb && cal que totes les condicions es compleixin: com que contrasenyaOk és false, potEntrar és false. !estaBloquejat inverteix el valor: «no està bloquejat» és true. Amb || n'hi ha prou que se'n compleixi una: la contrasenya és incorrecta, per tant mostrarAvis ja és true.

L'última expressió tradueix la regla del calendari: un any és de traspàs si és divisible per 4 i no per 100, o bé si és divisible per 400. Per a 2024, el parèntesi dona true && true, i amb això ja n'hi ha prou: true || false és true.

Els parèntesis agrupen la primera condició i fan l'expressió més fàcil de llegir. Prova-ho amb 1900 (false) i amb 2000 (true).

Concatenació de cadenes

Unir textos amb +

Quan un dels dos operands del + és un String, el + deixa de sumar i uneix (concatena): l'altre valor es converteix a text i s'hi enganxa.

MitjàLa trampa de l'ordre: suma o concatenació?
public class OrdreConcatenacio { public static void main(String[] args) { int a = 5; int b = 3; System.out.println("Resultat: " + a + b); // Resultat: 53 ← s'enganxen com a text! System.out.println("Resultat: " + (a + b)); // Resultat: 8 ← correcte System.out.println(a + b + " és la suma"); // 8 és la suma (s'avalua d'esquerra a dreta) } }
🖥️ Sortida per consola
Resultat: 53
Resultat: 8
8 és la suma
Com funciona

Els + s'avaluen d'esquerra a dreta. A la primera línia, "Resultat: " + a ja és un text, i en afegir-hi b s'enganxa un 3: surt 53. Els parèntesis de la segona línia obliguen a sumar primer.

A la tercera, a + b són dos enters i se sumen (8) abans de trobar el text.

✅ Bones pràctiques

Quan vulguis mostrar el resultat d'un càlcul dins d'un text, posa el càlcul entre parèntesis: "Total: " + (preu * quantitat).

Precedència d'operadors

Quina operació es fa primer

Quan una expressió té diversos operadors, Java segueix un ordre fix, com a matemàtiques. De més a menys prioritat: ! i ++ -- → * / % → + - → < > <= >= → == != → && → || → = += -=… Els operadors del mateix nivell s'avaluen d'esquerra a dreta.

MitjàLa precedència en acció
public class Precedencia { public static void main(String[] args) { System.out.println(2 + 3 * 4); // * abans que + System.out.println((2 + 3) * 4); // el parèntesi primer System.out.println(20 - 8 - 2); // d'esquerra a dreta System.out.println(20 / 4 * 2); // d'esquerra a dreta System.out.println(7 + 10 % 4); // % abans que + System.out.println(3 + 4 > 6 && 2 * 5 == 10); } }
🖥️ Sortida per consola
14
20
10
10
9
true
Com funciona

A 2 + 3 * 4 es multiplica primer (12) i després se suma: 14. Els parèntesis canvien l'ordre: (2 + 3) * 4 = 20. Quan els operadors tenen la mateixa prioritat, es va d'esquerra a dreta: 20 - 8 - 2 = 10 i 20 / 4 * 2 = 10.

A la darrera línia es fan primer els càlculs (7 i 10), després les comparacions (true i true) i finalment el &&.

✅ Bones pràctiques

Quan tinguis dubtes, fes servir parèntesis: no costen res i fan el codi més clar per a qui el llegeix.

✍️ Ara tu · Exercici 5Quina pizza surt més a compte?Avançat
1 · Llegeix l'algorisme→2 · Escriu-lo en Java→3 · Executa i compara

Una pizza gran de 40 cm costa 16 € i una de mitjana de 30 cm en costa 10. Tradueix l'algorisme que calcula quants cm² de pizza dona cada euro. Crea la classe Pizza.

Algoritmo Pizza Definir diametreGran, diametreMitjana Como Entero Definir preuGran, preuMitjana Como Real Definir areaGran, areaMitjana, cm2EuroGran, cm2EuroMitjana Como Real diametreGran <- 40 preuGran <- 16 diametreMitjana <- 30 preuMitjana <- 10 areaGran <- PI * (diametreGran / 2) ^ 2 areaMitjana <- PI * (diametreMitjana / 2) ^ 2 cm2EuroGran <- areaGran / preuGran cm2EuroMitjana <- areaMitjana / preuMitjana Escribir "Pizza gran: ", redon(areaGran), " cm², ", redon(cm2EuroGran), " cm² per euro" Escribir "Pizza mitjana: ", redon(areaMitjana), " cm², ", redon(cm2EuroMitjana), " cm² per euro" Escribir "La gran surt més a compte: ", cm2EuroGran > cm2EuroMitjana FinAlgoritmo
✅ Solució
// Compara quina pizza surt més a compte segons els cm² que dona per euro public class Pizza { public static void main(String[] args) { int diametreGran = 40; double preuGran = 16; int diametreMitjana = 30; double preuMitjana = 10; // Àrea del cercle: π · r², i el radi és la meitat del diàmetre double areaGran = Math.PI * Math.pow(diametreGran / 2, 2); double areaMitjana = Math.PI * Math.pow(diametreMitjana / 2, 2); double cm2EuroGran = areaGran / preuGran; double cm2EuroMitjana = areaMitjana / preuMitjana; System.out.println("Pizza gran: " + Math.round(areaGran) + " cm², " + Math.round(cm2EuroGran) + " cm² per euro"); System.out.println("Pizza mitjana: " + Math.round(areaMitjana) + " cm², " + Math.round(cm2EuroMitjana) + " cm² per euro"); System.out.println("La gran surt més a compte: " + (cm2EuroGran > cm2EuroMitjana)); } }
✔ Què es valora
  • Math.PI, Math.pow(..., 2) i Math.round(...) en lloc de PI, ^ i redon.
  • La comparació va entre parèntesis: sense ells, Java intentaria fer primer text + cm2EuroGran i després comparar un String amb un número, i no compila.
  • diametreGran / 2 és una divisió entera, però aquí no perd res perquè els diàmetres són parells.
  • Fes servir la taula De PSeInt a Java de la classe Math: PI, ^ i redon.
  • A PSeInt, ^ té més prioritat que *. A Java, com que és una crida a Math.pow, l'ordre queda clar sol.
  • A la darrera línia, la comparació ha d'anar entre parèntesis. Per què?

a) Volem saber si una persona té exactament 18 anys.

🔎 L'error
actual++ és un post-increment: primer dona el valor antic (5) a seguent i després incrementa actual. A més, modifica actual, que no volíem tocar. El més clar és actual + 1.
