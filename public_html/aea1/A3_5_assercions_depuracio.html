Assercions

Comprovar el que hauria de ser sempre cert

Una asserció (assert condició : "missatge";) comprova una condició que, si el codi és correcte, hauria de ser sempre certa. Si és falsa, el programa s'atura amb un AssertionError. Serveixen per detectar errors de programació durant el desenvolupament.

⚠️ Les assercions estan desactivades per defectePer activar-les al projecte Maven de NetBeans: clic dret al projecte → Properties → Run → VM Options → escriu -ea (s'aplica tant a Run Project com a Run File). Des de la terminal: mvn compile i després java -ea -cp target/classes daw.aea1_a3.AssercioMitjana.
MitjàAssercions per verificar un càlcul
public class AssercioMitjana { public static void main(String[] args) { int suma = 0; int quantitat = 0; for (int nota = 4; nota <= 9; nota++) { suma += nota; quantitat++; } // Precondició: abans de dividir, hi ha d'haver almenys una nota assert quantitat > 0 : "No hi ha notes: quantitat = " + quantitat; double mitjana = (double) suma / quantitat; // Postcondició: una mitjana de notes sempre és entre 0 i 10 assert mitjana >= 0 && mitjana <= 10 : "Mitjana fora de rang: " + mitjana; System.out.println("Mitjana: " + mitjana); } }

💡 Assercions o excepcions?Les assercions detecten errors del programador (coses que no haurien de passar mai). Les excepcions tracten errors de l'usuari o de l'entorn (dades incorrectes, fitxers que no existeixen). No facis servir mai assert per validar dades de l'usuari: en producció les assercions estan desactivades.
✍️ Ara tu · Exercici 1 MCD i mcm amb assercions Avançat

Calcula el màxim comú divisor (MCD) de dos números amb l'algorisme d'Euclides i, a partir d'aquest, el mínim comú múltiple: mcm(a, b) = a · b / MCD(a, b).

  • Declara int a = 48, b = 180;
  • Si algun número no és positiu, llança una IllegalArgumentException i captura-la.
  • Afegeix dues assercions de postcondició: el MCD divideix a i b; el mcm és múltiple de a i de b.
  • Executa-ho amb -ea i comprova que no salta cap asserció. Després, introdueix a propòsit un error al càlcul i observa l'AssertionError.
🖥️ Sortida esperada
MCD(48, 180) = 12
mcm(48, 180) = 720
Avançat CA: 3.2 · 3.4 · 3.6 · 3.9
✅ Solució
public class MCDiMCM { public static void main(String[] args) { int a = 48; int b = 180; try { if (a <= 0 || b <= 0) { throw new IllegalArgumentException("Els dos números han de ser positius."); } // Algorisme d'Euclides int x = a; int y = b; while (y != 0) { int residu = x % y; x = y; y = residu; } int mcd = x; // Dividim abans de multiplicar per evitar desbordaments amb números grans int mcm = a / mcd * b; // Postcondicions assert a % mcd == 0 && b % mcd == 0 : "El MCD no divideix els dos números"; assert mcm % a == 0 && mcm % b == 0 : "El mcm no és múltiple dels dos números"; System.out.println("MCD(" + a + ", " + b + ") = " + mcd); System.out.println("mcm(" + a + ", " + b + ") = " + mcm); } catch (IllegalArgumentException e) { System.out.println("Error: " + e.getMessage()); } } }
✔ Què es valora
  • L'algorisme d'Euclides està ben implementat (la condició de sortida és y != 0).
  • Les assercions verifiquen el resultat, no les dades d'entrada (aquestes es validen amb una excepció).
  • Es comprova que les assercions funcionen provocant un error.

1 · Executa'l→2 · Depura'l→3 · Corregeix i prova

Aquest programa hauria de calcular la mitjana dels múltiples de 3 entre 1 i 30 (n'hi ha 10, sumen 165 i la mitjana és 16.5). Però mostra Múltiples: 9 · Suma: 135 i Mitjana: 15.0. Troba els dos errors fent servir el depurador.

public class MitjanaMultiples3 { public static void main(String[] args) { int suma = 0; int comptador = 0; for (int i = 1; i < 30; i++) { if (i % 3 == 0) { suma += i; comptador++; } } double mitjana = suma / comptador; System.out.println("Múltiples: " + comptador + " · Suma: " + suma); System.out.println("Mitjana: " + mitjana); } }
  • Posa un breakpoint a la línia suma += i; i depura el fitxer (Ctrl+Maj+F5).
  • Avança amb F5 i mira a la finestra Variables quins valors pren i. Quin múltiple falta?
  • Posa un altre breakpoint a la línia de la mitjana i observa el valor de suma / comptador.
  • Corregeix els dos errors i comprova que la sortida és la correcta.
💡 Pista
Un error és en la condició del for; l'altre, en el tipus de la divisió.
🖥️ Sortida esperada
Múltiples: 10 · Suma: 165
Mitjana: 16.5
MitjàCA: 3.6
✅ Solució
// Mitjana dels múltiples de 3 entre 1 i 30 (versió corregida) public class MitjanaMultiples3 { public static void main(String[] args) { int suma = 0; int comptador = 0; for (int i = 1; i <= 30; i++) { // error 1: era i < 30 i deixava fora el 30 if (i % 3 == 0) { suma += i; comptador++; } } double mitjana = (double) suma / comptador; // error 2: sense (double) la divisió era entera System.out.println("Múltiples: " + comptador + " · Suma: " + suma); System.out.println("Mitjana: " + mitjana); } }
✔ Què es valora
  • Es detecta que el 30 no entra al bucle (i < 30 en lloc de i <= 30).
  • Es detecta la divisió entera i es corregeix amb (double).
  • S'ha fet servir el depurador i no només la sortida per consola.

/** * Calcula el màxim comú divisor (MCD) de dos números positius * amb l'algorisme d'Euclides. * * @author Departament d'Informàtica * @version 1.0 */ public class MCDEuclides { public static void main(String[] args) { int a = 84; int b = 36; // Les dades han de ser positives: si no, l'algorisme no acabaria if (a <= 0 || b <= 0) { System.out.println("Els números han de ser positius."); return; } int x = a; int y = b; // Euclides: mcd(x, y) = mcd(y, x % y). Acabem quan el residu és 0 while (y != 0) { int residu = x % y; x = y; y = residu; } // Postcondició: el MCD divideix els dos números assert a % x == 0 && b % x == 0 : "Error en el càlcul del MCD"; System.out.println("MCD(" + a + ", " + b + ") = " + x); } }

Aquest programa funciona, però costa d'entendre: no té comentaris i una variable es diu s. Copia'l a la classe NombrePerfecte i documenta'l.

public class NombrePerfecte { public static void main(String[] args) { int numero = 28; int s = 0; for (int d = 1; d <= numero / 2; d++) { if (numero % d == 0) { s += d; } } if (s == numero) { System.out.println(numero + " és perfecte"); } else { System.out.println(numero + " no és perfecte (suma dels divisors: " + s + ")"); } } }
  • Afegeix un comentari Javadoc (/** … */) a la classe que expliqui què és un número perfecte, amb @author i @version.
  • Canvia el nom de la variable s per un de més clar.
  • Afegeix un comentari a sobre del bucle i un altre a sobre de l'if que expliquin per què, no què.
  • Prova amb 6, 28 i 12: quins són perfectes?
💡 Pista
Un bon comentari respon preguntes que el codi no respon: per què el bucle arriba només fins a numero / 2?

/** * Comprova si un número és perfecte: un número és perfecte si és igual * a la suma dels seus divisors propis (tots menys ell mateix). * Exemple: 28 = 1 + 2 + 4 + 7 + 14. * * @author Nom i cognoms de l'alumne * @version 1.0 */ public class NombrePerfecte { public static void main(String[] args) { int numero = 28; // Recorregut: sumem tots els divisors propis (de 1 a numero / 2, // perquè cap divisor propi pot ser més gran que la meitat) int sumaDivisors = 0; for (int d = 1; d <= numero / 2; d++) { if (numero % d == 0) { sumaDivisors += d; } } // És perfecte si la suma dels divisors coincideix amb el número if (sumaDivisors == numero) { System.out.println(numero + " és perfecte"); } else { System.out.println(numero + " no és perfecte (suma dels divisors: " + sumaDivisors + ")"); } } }
✔ Què es valora
  • La classe té Javadoc amb descripció, @author i @version.
  • Els noms de les variables expliquen què guarden.
  • Els comentaris expliquen decisions (el límit numero / 2), no repeteixen el codi.
  • 6 i 28 són perfectes; 12 no (la suma dels seus divisors és 16).
