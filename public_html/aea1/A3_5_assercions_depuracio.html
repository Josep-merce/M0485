Assercions

Comprovar el que hauria de ser sempre cert

Una asserció (assert condició : "missatge";) comprova una condició que, si el codi és correcte, hauria de ser sempre certa. Si és falsa, el programa s'atura amb un AssertionError. Serveixen per detectar errors de programació durant el desenvolupament.

⚠️ Les assercions estan desactivades per defectePer activar-les al projecte Maven de NetBeans: clic dret al projecte → Properties → Run → VM Options → escriu -ea (s'aplica tant a Run Project com a Run File). Des de la terminal: mvn compile i després java -ea -cp target/classes daw.aea1_a3.AssercioMitjana.
MitjàAssercions per verificar un càlcul
public class AssercioMitjana { public static void main(String[] args) { int suma = 0; int quantitat = 0; for (int nota = 4; nota <= 9; nota++) { suma += nota; quantitat++; } // Precondició: abans de dividir, hi ha d'haver almenys una nota assert quantitat > 0 : "No hi ha notes: quantitat = " + quantitat; double mitjana = (double) suma / quantitat; // Postcondició: una mitjana de notes sempre és entre 0 i 10 assert mitjana >= 0 && mitjana <= 10 : "Mitjana fora de rang: " + mitjana; System.out.println("Mitjana: " + mitjana); } }
🖥️ Sortida per consola
Mitjana: 6.5

Si per error escrivíssim suma += nota * 10;, la mitjana seria 65.0 i, amb -ea activat, el programa s'aturaria mostrant:

💡 Assercions o excepcions?Les assercions detecten errors del programador (coses que no haurien de passar mai). Les excepcions tracten errors de l'usuari o de l'entorn (dades incorrectes, fitxers que no existeixen). No facis servir mai assert per validar dades de l'usuari: en producció les assercions estan desactivades.

/** * Calcula els temps de pas d'un corredor de marató que manté un ritme constant: * el temps acumulat a cada punt de control (cada 5 km) i el temps d'arribada. * * @author Departament d'Informàtica * @version 1.0 */ public class TempsMarato { public static void main(String[] args) { // Distància en metres i ritme en segons per km: amb enters evitem els decimals final int DISTANCIA_METRES = 42195; int ritme = 300; // 5 min/km // Amb un ritme de 0 o negatiu els temps no tindrien sentit if (ritme <= 0) { System.out.println("El ritme ha de ser positiu."); return; } // Punts de control cada 5 km; el darrer és el 40 perquè la meta no cau en un múltiple de 5 for (int km = 5; km <= 40; km += 5) { int temps = km * ritme; // segons des de la sortida int h = temps / 3600; int min = temps % 3600 / 60; int s = temps % 60; // Minuts i segons sempre amb dues xifres: 0:05:00 i no 0:5:0 System.out.println("Km " + km + ": " + h + ":" + (min < 10 ? "0" : "") + min + ":" + (s < 10 ? "0" : "") + s); } // Temps d'arribada: la divisió entera descarta les fraccions de segon int tempsFinal = DISTANCIA_METRES * ritme / 1000; // Postcondició: la marató fa entre 42 i 43 km, per tant el temps // d'arribada ha d'estar entre 42 i 43 vegades el ritme assert tempsFinal >= 42 * ritme && tempsFinal < 43 * ritme : "Temps final incorrecte: " + tempsFinal; int h = tempsFinal / 3600; int min = tempsFinal % 3600 / 60; int s = tempsFinal % 60; System.out.println("Meta (42,195 km): " + h + ":" + (min < 10 ? "0" : "") + min + ":" + (s < 10 ? "0" : "") + s); } }

Aquest programa suma les xifres d'un número. Abans d'executar-lo, segueix-lo amb paper i llapis. Després, afegeix-hi una asserció de postcondició que comprovi el resultat: un número i la suma de les seves xifres sempre donen el mateix residu en dividir-los entre 9 (3759 % 9 = 6 i 24 % 9 = 6). Copia'l a la classe SumaXifres.

public class SumaXifres { public static void main(String[] args) { int numero = 3759; int suma = 0; int n = numero; while (n > 0) { suma += n % 10; n = n / 10; } System.out.println("Suma de xifres de " + numero + ": " + suma); } }
  • Fes una taula amb una fila inicial i una fila per iteració, amb n a l'inici, n % 10, suma i n al final.
  • Afegeix, després del bucle, assert condició : "missatge"; amb la propietat del residu entre 9.
  • Executa-ho amb -ea: no ha de saltar l'asserció. Després canvia n % 10 per n % 100 i observa l'AssertionError.

// Suma les xifres d'un número i comprova el resultat amb una asserció public class SumaXifres { public static void main(String[] args) { int numero = 3759; int suma = 0; int n = numero; while (n > 0) { suma += n % 10; // afegim l'última xifra n = n / 10; // i la traiem del número } // Postcondició: un número i la suma de les seves xifres // donen el mateix residu en dividir-los entre 9 assert suma % 9 == numero % 9 : "Suma incorrecta: " + suma; System.out.println("Suma de xifres de " + numero + ": " + suma); } }
✔ Què es valora
  • La taula té una fila per iteració i els valors són correctes.
  • S'identifica quan la condició n > 0 deixa de complir-se.
  • L'asserció és després del bucle i comprova el resultat, no les dades d'entrada.
  • El resultat de la traça coincideix amb el de l'execució.

Aquest programa hauria de sumar els 10 primers números senars (1 + 3 + 5 + … + 19). Aquesta suma sempre val n²: amb n = 10, ha de donar 100. Però mostra Suma dels 10 primers senars: 45. Copia'l a la classe SumaSenars, troba els dos errors amb el depurador i deixa'l ben documentat.

public class SumaSenars { public static void main(String[] args) { int n = 10; int suma = 0; int senar = 1; for (int i = 1; i < n; i++) { suma += senar; senar += 1; } System.out.println("Suma dels " + n + " primers senars: " + suma); } }
  • Afegeix una asserció de postcondició suma == n * n i executa-ho amb -ea: ha de saltar l'AssertionError.
  • Posa un breakpoint a la línia suma += senar;, avança amb F5 i mira a la finestra Variables quins valors prenen i i senar.
  • Corregeix els dos errors i afegeix un comentari Javadoc a la classe i comentaris que expliquin per què, no què.
🖥️ Exemple d'execució
Suma dels 10 primers senars: 100
✅ Solució
/** * Suma els n primers números senars (1 + 3 + 5 + ...). * El resultat ha de ser sempre n * n: amb n = 10, 100. * * @author Nom i cognoms de l'alumne * @version 1.0 */ public class SumaSenars { public static void main(String[] args) { int n = 10; int suma = 0; int senar = 1; // Una volta per cada senar: i va d'1 a n, totes dues incloses for (int i = 1; i <= n; i++) { // error 1: era i < n i faltava una volta suma += senar; senar += 2; // error 2: era += 1 i sumava també els parells } // Postcondició: la suma dels n primers senars és n² assert suma == n * n : "S'esperava " + (n * n) + " i la suma és " + suma; System.out.println("Suma dels " + n + " primers senars: " + suma); } }
✔ Què es valora
  • Es detecta que el bucle fa una volta de menys (i < n en lloc de i <= n).
  • Es detecta que senar ha d'augmentar de 2 en 2.
  • L'asserció verifica el resultat i ja no salta amb el codi corregit.
  • La classe té Javadoc i els comentaris expliquen decisions, no repeteixen el codi.
