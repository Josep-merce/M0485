1

Què és la composició alternativa

Programes que prenen decisions

Fins ara els programes executaven totes les instruccions una rere l'altra (composició seqüencial). La composició alternativa permet que el programa prengui decisions: segons si una condició és certa o falsa, executa unes instruccions o unes altres.

A PSeInt ja ho has fet amb Si … Entonces … SiNo … FinSi:

Algoritmo Aprovat Definir nota Como Real nota <- 6.5 Si nota >= 5 Entonces Escribir "Aprovat" SiNo Escribir "Suspès" FinSi FinAlgoritmo

La condició sempre és una expressió booleana: una expressió que val true o false, feta amb els operadors relacionals (> < == != >= <=) i lògics (&& || !) que vas veure a l'A1.

BàsicUna condició és un valor boolean
public class Condicions { public static void main(String[] args) { double nota = 6.5; int edat = 15; // Cada condició es calcula i dona true o false boolean aprovat = nota >= 5; boolean menor = edat < 18; System.out.println("Aprovat? " + aprovat); System.out.println("Menor d'edat? " + menor); System.out.println("Aprovat i menor? " + (aprovat && menor)); } }
🖥️ Sortida per consola
Aprovat? true
Menor d'edat? true
Aprovat i menor? true
Com funciona

Abans de decidir res, Java avalua la condició i obté true o false. Una estructura alternativa només mira aquest resultat per triar quin camí segueix.

⚠️ Errors típics

Un sol = assigna, dos == comparen. A PSeInt = serveix per comparar, però a Java if (nota = 5) no compila. La condició ha de ser nota == 5.

2

Alternativa simple: if

Fer alguna cosa només si…

La forma més senzilla és l'alternativa simple: el bloc entre claus només s'executa si la condició és true. Si és false, el programa se'l salta i continua.

Algoritmo Descompte Definir preu Como Real preu <- 120 Si preu >= 100 Entonces preu <- preu - preu * 0.10 Escribir "S'ha aplicat un descompte del 10 %" FinSi Escribir "Preu final: ", preu, " €" FinAlgoritmo
BàsicAplicar un descompte si la compra supera un mínim
public class Descompte { public static void main(String[] args) { final double COMPRA_MINIMA = 100.0; final double DESCOMPTE = 0.10; double preu = 120.0; // Només les compres de 100 € o més tenen descompte if (preu >= COMPRA_MINIMA) { preu = preu - preu * DESCOMPTE; System.out.println("S'ha aplicat un descompte del 10 %"); } System.out.println("Preu final: " + preu + " €"); } }
🖥️ Sortida per consola
S'ha aplicat un descompte del 10 %
Preu final: 108.0 €
Com funciona

Amb preu = 120 la condició és certa i s'apliquen les dues instruccions del bloc. Canvia el preu a 80: el bloc se salta i només es mostra el preu final, sense canvis.

Les constants COMPRA_MINIMA i DESCOMPTE eviten "números màgics" dins de la condició.

⚠️ Errors típics
  • Punt i coma després de la condició. if (preu >= 100); tanca l'if en aquell punt i el bloc s'executa sempre.
  • Claus oblidades. Sense { }, només la primera instrucció queda dins de l'if. Posa sempre claus, encara que només hi hagi una línia.
3

Alternativa doble: if / else

O una cosa o l'altra

Amb else indiquem què cal fer quan la condició és false. Sempre s'executa un i només un dels dos blocs.

Algoritmo ParellSenar Definir numero Como Entero numero <- 17 Si numero MOD 2 = 0 Entonces Escribir numero, " és parell" SiNo Escribir numero, " és senar" FinSi FinAlgoritmo
Parell o senar i control d'accés
public class ParellSenar { public static void main(String[] args) { int numero = 17; int edat = 16; // Un número és parell si el residu de dividir-lo entre 2 és 0 if (numero % 2 == 0) { System.out.println(numero + " és parell"); } else { System.out.println(numero + " és senar"); } // Accés: o és major d'edat o no ho és if (edat >= 18) { System.out.println("Accés permès."); } else { System.out.println("Accés denegat: cal ser major d'edat."); } } }
🖥️ Sortida per consola
17 és senar
Accés denegat: cal ser major d'edat.
Com funciona

El residu numero % 2 només pot ser 0 o 1. Si és 0 el número és parell; en qualsevol altre cas entra a l'else. No cal escriure cap condició a l'else: és "tota la resta".

La segona decisió segueix el mateix patró amb una comparació: si edat >= 18 és cert es mostra "Accés permès."; si és fals, com passa amb 16 anys, s'executa el bloc de l'else. En cada if / else s'executa sempre un i només un dels dos missatges.

🔁 De PSeInt a Java
PSeIntJava
numero MOD 2numero % 2
Si … SiNo … FinSiif (…) { … } else { … }
4

Alternativa múltiple: else if

Diversos casos, un sol camí

Quan hi ha més de dues opcions encadenem condicions amb else if. Java les comprova de dalt a baix i executa el bloc de la primera que sigui certa; la resta ja no es comproven. L'else final recull tots els altres casos.

PSeInt no té else if: s'escriu posant un Si dins del SiNo. A Java es pot fer igual, però és més clar "aplanar-ho" amb else if:

Algoritmo Signe Definir valor Como Entero valor <- -5 Si valor > 0 Entonces Escribir valor, " és positiu" SiNo Si valor < 0 Entonces Escribir valor, " és negatiu" SiNo Escribir "El valor és zero" FinSi FinSi FinAlgoritmo
Signe d'un valor i qualificació d'una nota
public class Qualificacio { public static void main(String[] args) { int valor = -5; double nota = 7.4; // Tres casos: el Si niat de PSeInt aplanat amb else if if (valor > 0) { System.out.println(valor + " és positiu"); } else if (valor < 0) { System.out.println(valor + " és negatiu"); } else { System.out.println("El valor és zero"); } // Molts casos: de la condició més restrictiva a la menys String qualificacio; if (nota < 0 || nota > 10) { qualificacio = "Nota incorrecta"; } else if (nota >= 9) { qualificacio = "Excel·lent"; } else if (nota >= 7) { qualificacio = "Notable"; } else if (nota >= 6) { qualificacio = "Bé"; } else if (nota >= 5) { qualificacio = "Suficient"; } else { qualificacio = "Insuficient"; } System.out.println("Nota " + nota + ": " + qualificacio); } }
🖥️ Sortida per consola
-5 és negatiu
Nota 7.4: Notable
Com funciona

El primer bloc és la traducció del pseudocodi: el Si que hi havia dins del SiNo s'ha convertit en un else if. Amb −5, la primera condició és falsa, la segona és certa i ja no es comprova res més.

El segon bloc encadena més casos. Primer descarta les notes fora de rang amb ||. Si el programa arriba a else if (nota >= 7) és perquè nota >= 9 ha estat fals: ja sabem que nota < 9. Per això no cal escriure nota >= 7 && nota < 9.

Totes les branques donen valor a qualificacio, per això es pot mostrar en una sola línia després de la cadena.

👀 Fixa't-hi

L'ordre de les condicions és important. Si posessis primer nota >= 5, un 9.5 donaria "Suficient", perquè és la primera condició certa. Ordena-les de la més restrictiva a la menys restrictiva.

🔁 De PSeInt a Java
PSeIntJava
SiNo + Si cond Entonces (niat)} else if (cond) {
un FinSi per cada Siuna sola } al final de la cadena

Posa-ho tot en pràctica

Aquests dos exercicis fan servir tot el que has vist: les condicions booleanes, l'alternativa simple (if), la doble (if / else) i la múltiple (else if). Escriu-los al projecte AEA1_A2 i compara la sortida amb l'exemple d'execució.

✍️ Ara tu · Exercici 1L'entrada del cinemaBàsic
1 · Llegeix l'algorisme→2 · Escriu-lo en Java→3 · Executa i compara

Al cinema del barri, l'entrada costa 5.5 € per als menors de 14 anys i 8 € per a la resta. El dia de l'espectador totes les entrades tenen 2 € de descompte. Aquest algorisme calcula el preu d'una entrada. Tradueix-lo a Java a la classe Cinema i prova'l també amb edat = 30 i diaEspectador = false.

Algoritmo Cinema Definir edat Como Entero Definir diaEspectador Como Logico Definir preu Como Real edat <- 12 diaEspectador <- Verdadero Escribir "Edat: ", edat, " anys" Si edat < 14 Entonces preu <- 5.5 Escribir "Tarifa infantil" SiNo preu <- 8 Escribir "Tarifa general" FinSi Si diaEspectador Entonces preu <- preu - 2 Escribir "Dia de l'espectador: 2 € de descompte" FinSi Escribir "Preu de l'entrada: ", preu, " €" FinAlgoritmo
  • Logico → boolean i Verdadero → true. Una variable boolean ja és una condició: if (diaEspectador).
  • Si … SiNo … FinSi → if (…) { … } else { … }; el segon Si no té SiNo: és un if simple.
  • Guarda el descompte en una constant final per evitar números màgics.
🖥️ Exemple d'execució
Edat: 12 anys
Tarifa infantil
Dia de l'espectador: 2 € de descompte
Preu de l'entrada: 3.5 €
✅ Solució
// Calcula el preu d'una entrada de cinema segons l'edat i el dia public class Cinema { public static void main(String[] args) { final double DESCOMPTE_ESPECTADOR = 2.0; int edat = 12; boolean diaEspectador = true; double preu; System.out.println("Edat: " + edat + " anys"); // Doble: o tarifa infantil o tarifa general if (edat < 14) { preu = 5.5; System.out.println("Tarifa infantil"); } else { preu = 8.0; System.out.println("Tarifa general"); } // Simple: el descompte només s'aplica el dia de l'espectador if (diaEspectador) { preu = preu - DESCOMPTE_ESPECTADOR; System.out.println("Dia de l'espectador: 2 € de descompte"); } System.out.println("Preu de l'entrada: " + preu + " €"); } }
✔ Què es valora
  • La tarifa es tria amb un if / else: sempre s'aplica una de les dues, i només una.
  • El descompte és un if simple, independent del primer, que s'aplica sobre el preu ja calculat.
  • Totes les condicions van entre parèntesis i tots els blocs porten claus.
  • El programa funciona bé si canvies l'edat i el dia (prova-ho amb 30 anys i sense descompte: 8.0 €).

Un aparcament cobra segons els minuts d'estada: la primera mitja hora és gratuïta, fins a 2 hores es paga una tarifa fixa de 3 € i, a partir de les 2 hores, cada minut extra costa 0.1 €. Si el temps és negatiu, és un error. Aquest algorisme fa servir Si niats dins de SiNo: tradueix-lo a Java a la classe Aparcament amb una cadena else if.

Algoritmo Aparcament Definir minuts Como Entero Definir preu Como Real minuts <- 135 Escribir "Temps d'estada: ", minuts, " min" Si minuts < 0 Entonces preu <- 0 Escribir "Temps incorrecte" SiNo Si minuts <= 30 Entonces preu <- 0 Escribir "Primera mitja hora gratuïta" SiNo Si minuts <= 120 Entonces preu <- 3 Escribir "Tarifa curta (fins a 2 hores)" SiNo preu <- 3 + (minuts - 120) * 0.1 Escribir "Tarifa llarga: 0.1 € per minut extra" FinSi FinSi FinSi Escribir "Import: ", preu, " €" FinAlgoritmo
  • Cada SiNo amb un Si a dins → } else if (…) {. Al final només cal una }, no tres FinSi.
  • Guarda la tarifa fixa (3 €) i el preu del minut extra (0.1 €) en constants final.
  • Prova-ho també amb minuts = 20, 90 i -5 i comprova que cada valor entra a la branca que toca.
🖥️ Exemple d'execució
Temps d'estada: 135 min
Tarifa llarga: 0.1 € per minut extra
Import: 4.5 €
✅ Solució
// Calcula el preu d'un aparcament segons els minuts d'estada public class Aparcament { public static void main(String[] args) { final double TARIFA_CURTA = 3.0; final double PREU_MINUT_EXTRA = 0.1; int minuts = 135; double preu; System.out.println("Temps d'estada: " + minuts + " min"); // Primer descartem els valors impossibles; després, del tram més curt al més llarg if (minuts < 0) { preu = 0; System.out.println("Temps incorrecte"); } else if (minuts <= 30) { preu = 0; System.out.println("Primera mitja hora gratuïta"); } else if (minuts <= 120) { preu = TARIFA_CURTA; System.out.println("Tarifa curta (fins a 2 hores)"); } else { preu = TARIFA_CURTA + (minuts - 120) * PREU_MINUT_EXTRA; System.out.println("Tarifa llarga: 0.1 € per minut extra"); } System.out.println("Import: " + preu + " €"); } }
✔ Què es valora
  • Els Si niats s'han aplanat en una sola cadena if / else if / else.
  • Les condicions van en ordre: primer el valor impossible i després del tram més curt al més llarg, sense repetir el límit inferior (minuts > 30 && minuts <= 120 no cal).
  • Totes les branques donen valor a preu, i l'import es mostra un sol cop després de la cadena.
  • Només es paguen els minuts que passen de 120: (minuts - 120) * 0.1.
