Java: JDK, JRE i JVM

Les peces que necessitem per programar i executar

Java és un llenguatge de programació d'alt nivell i d'ús general creat el 1995 per James Gosling a Sun Microsystems. El seu lema és «Escriu una vegada, executa a qualsevol lloc»: el codi compilat funciona a qualsevol sistema que tingui una màquina virtual Java instal·lada. Per treballar-hi fan falta tres peces, una dins de l'altra:

JVMJava Virtual MachineMàquina virtual que executa el bytecode traduint-lo a instruccions del sistema operatiu.

Com funciona

Escrivim el programa en un fitxer .java, que és text. El compilador javac comprova que estigui ben escrit i, si no hi ha errors, genera un fitxer .class amb el bytecode, un codi intermedi que no depèn de cap sistema operatiu. La JVM llegeix aquest bytecode i l'executa a l'ordinador concret.

Per això el mateix .class funciona a Windows, macOS i Linux: cada sistema té la seva JVM. A NetBeans tot el procés es fa amb un sol clic (Run File).

👀 Fixa't-hi

Per programar necessites el JDK (que ja porta el JRE i la JVM a dins). Per executar un programa que t'han passat, n'hi ha prou amb el JRE. Al curs fem servir el JDK 21, una versió LTS (de suport a llarg termini).

Instal·lació del JDK 21 i NetBeans

L'entorn de treball del curs

Necessitem dues coses: el JDK 21, que compila i executa, i un entorn de desenvolupament (IDE), Apache NetBeans, on escriurem el codi. Tens tots els passos amb captures a la guia en PDF.

1Descarregar el JDK 21Des de la web d'Oracle (oracle.com/java/technologies/downloads) o d'Eclipse Adoptium, tria l'instal·lador del teu sistema operatiu.
2Instal·lar i verificarExecuta l'instal·lador amb les opcions per defecte. Obre una terminal i escriu java -version: ha d'aparèixer la versió 21.
3Instal·lar Apache NetBeansDescarrega la darrera versió des de netbeans.apache.org i instal·la-la. Detectarà automàticament el JDK i ja porta Maven integrat: no cal instal·lar-lo a part.
4Configuració opcionalTools → Options → Appearance → Look and Feel → FlatLaf Dark per a un tema fosc, i Fonts & Colors per augmentar la mida de la lletra.
PDFGuia pas a pas 📄Instal·lació de l'entorn de treball (JDK 21 i NetBeans) explicada pas a pas. Obre la guia →
BàsicComprovar la instal·lació des de la terminal
java -version javac -version
Com funciona

La primera ordre pregunta quina versió de Java (la JVM) hi ha instal·lada; la segona, quina versió del compilador. Totes dues han de començar per 21 (per exemple java version "21.0.5" o openjdk version "21.0.5"; els darrers números depenen de l'actualització que hagis instal·lat).

Si java respon però javac no es reconeix, tens només el JRE: cal instal·lar el JDK.

⚠️ Errors típics
  • «java» no es reconeix com una ordre: el JDK no està instal·lat o la terminal es va obrir abans d'instal·lar-lo. Tanca-la i torna-la a obrir.
  • Surt una versió antiga (8, 11, 17…): tens més d'un JDK. A NetBeans, comprova a Tools → Java Platforms que el projecte fa servir el JDK 21.

Primer projecte Maven: Hola Món

Crear el projecte, la classe i executar-la

Crear projectes és el primer pas per desenvolupar qualsevol aplicació. Segueix aquests passos a NetBeans:

1Crear el projecteFile → New Project → Java with Maven → Java Application. Project Name: IntroduccioJava. Group Id: cat.lamerce. El paquet es crea sol: cat.lamerce.introducciojava.
2Crear la classeDins de Source Packages, clic dret al paquet cat.lamerce.introducciojava → New → Java Class. Nom: HolaMon. NetBeans crea HolaMon.java amb la línia package ja escrita. (Pots esborrar la classe IntroduccioJava que genera l'assistent.)
3Escriure el codiCopia l'exemple de sota sense la línia package i enganxa'l a sota de la que ja ha escrit NetBeans. Fixa't en l'estructura: paquet, classe, mètode main i instruccions.
4ExecutarClic dret sobre HolaMon.java → Run File (Maj+F6). El resultat apareix a la finestra Output, envoltat de les línies de Maven (Building IntroduccioJava…, BUILD SUCCESS).

Què és un projecte Maven?

Maven és l'eina estàndard per construir projectes Java. Organitza sempre els fitxers de la mateixa manera i guarda la configuració del projecte en un fitxer anomenat pom.xml. Qualsevol IDE (NetBeans, IntelliJ, VS Code) o la terminal saben obrir i executar un projecte Maven sense canviar res.

IntroduccioJava/ ├── pom.xml ← configuració del projecte (JDK 21…) └── src/main/java/ └── cat/lamerce/introducciojava/ ← el paquet són carpetes └── HolaMon.java
BàsicEl primer programa
package cat.lamerce.introducciojava; public class HolaMon { public static void main(String[] args) { // Mostra dos missatges per pantalla System.out.println("Hola Món amb Java"); System.out.println("Benvinguts al curs!"); } }

Com funciona

La primera línia, package cat.lamerce.introducciojava;, diu a quin paquet pertany la classe; el paquet correspon a les carpetes cat/lamerce/introducciojava dins de src/main/java. Després ve la classe HolaMon (el fitxer s'ha de dir HolaMon.java) i, a dins, el mètode main, que és on comença l'execució.

Cada System.out.println escriu un text i salta de línia. A la finestra Output de NetBeans veuràs aquestes dues línies entre els missatges de Maven.

✅ Bon costum

Un projecte per activitat, una classe per exemple. No cal crear un projecte nou per a cada exemple: a Source Packages, clic dret al paquet → New → Java Class, posa-li el nom de l'exemple i enganxa el codi a sota de la línia package. Un projecte pot tenir tantes classes amb main com vulguis: Run File (Maj+F6) executa només la que tries.

👀 Fixa't-hi

A les subpàgines següents els exemples no porten la línia package, per fer-los més curts. Quan els copiïs a NetBeans, deixa la línia package …; que ja té el fitxer i enganxa el codi a sota.

No hi ha paquets.package cat.lamerce.introducciojava; organitza les classes en carpetes.

L'error «Incorrect package»

El primer error que et trobaràs (i com evitar-lo)

Quan copiem exemples d'una pàgina web a NetBeans és fàcil trepitjar la línia package. Aquest és el resultat:

BàsicFitxer HolaMon.java dins del paquet cat.lamerce.aea1_a1
package cat.lamerce.introducciojava; // ✘ no és el paquet on és el fitxer public class HolaMon { // ... }
Com funciona

NetBeans mostra una bombeta vermella a la línia 1 amb el missatge Incorrect package: la línia package diu cat.lamerce.introducciojava, però el fitxer és a la carpeta del paquet cat.lamerce.aea1_a1. Totes dues coses han de coincidir.

⚠️ Errors típics

Error Incorrect package (bombeta vermella a la línia 1). Apareix quan la línia package no coincideix amb el paquet on és el fitxer. Sol passar en enganxar un exemple i esborrar o canviar la línia package que havia escrit NetBeans.

Solució: mira el nom del paquet a Source Packages (per exemple lamerce.estructura) i escriu-lo a la primera línia: package lamerce.estructura;. També pots clicar la bombeta i triar Change package declaration to …. No triïs Move class to correct folder: mouria el fitxer a una carpeta nova.

Per evitar-ho: copia els exemples a partir de la línia import (o de public class si no n'hi ha) i enganxa'ls a sota del package que ja hi ha.
