1

L'operador ternari

Triar entre dos valors

L'operador condició ? valorSiCert : valorSiFals és una forma abreujada d'if / else per a un cas molt concret: quan només volem triar entre dos valors per guardar-los en una variable o mostrar-los.

PSeInt no té operador ternari. Quan un Si … SiNo només fa una assignació a cada branca, a Java es pot escriure en una línia:

Si a > b Entonces major <- a SiNo major <- b FinSi
BàsicTriar un valor amb el ternari
public class Ternari { public static void main(String[] args) { int a = 12; int b = 30; int major = (a > b) ? a : b; System.out.println("El major és " + major); double nota = 4.5; String resultat = (nota >= 5) ? "Aprovat" : "Suspès"; System.out.println(resultat); } }
🖥️ Sortida per consola
El major és 30
Suspès
Com funciona

(a > b) ? a : b es llegeix "si a > b, llavors a; si no, b". El resultat es guarda a major. Els dos valors han de ser del mateix tipus que la variable.

✅ Bones pràctiques

Fes servir el ternari només per a casos senzills. Si has de fer diverses instruccions o encadenar condicions, un if / else és molt més llegible.

🔁 De PSeInt a Java
PSeIntJava
Si c Entonces x <- v1 SiNo x <- v2 FinSix = c ? v1 : v2;
2

La sentència switch

Una variable, molts valors

switch compara una sola expressió amb una llista de valors concrets (case) i executa el codi del que coincideix. Funciona amb int, char, String i altres tipus, però no amb double ni boolean. El default recull els valors que no coincideixen amb cap cas.

És l'equivalent del Segun de PSeInt:

Segun dia Hacer 1: Escribir "Dilluns" 2: Escribir "Dimarts" 6, 7: Escribir "Cap de setmana" De Otro Modo: Escribir "Dia no vàlid" FinSegun
Dia de la setmana i torn de treball
public class DiaSetmana { public static void main(String[] args) { int dia = 3; char torn = 'T'; // 'M' = matí, 'T' = tarda // switch clàssic: cada case acaba amb break switch (dia) { case 1: System.out.println("Dilluns"); break; case 2: System.out.println("Dimarts"); break; case 3: System.out.println("Dimecres"); break; case 4: System.out.println("Dijous"); break; case 5: System.out.println("Divendres"); break; case 6: case 7: System.out.println("Cap de setmana"); break; default: System.out.println("Dia no vàlid"); } // switch amb fletxa sobre un char: retorna un valor i no cal break String horari = switch (torn) { case 'M', 'm' -> "Torn de matí: de 9 a 14 h"; case 'T', 't' -> { String text = "Torn de tarda: de 16 a 20 h"; if (dia == 5) { text = "Divendres tarda: tancat"; } yield text; // yield retorna el valor del bloc { } } default -> "Torn desconegut: " + torn; }; System.out.println(horari); } }
🖥️ Sortida per consola
Dimecres
Torn de tarda: de 16 a 20 h
Com funciona

El primer switch és el clàssic: compara dia amb cada case; amb 3 mostra "Dimecres" i el break en surt. Els casos 6 i 7 estan apilats sense break entre ells, de manera que tots dos executen el mateix codi.

El segon fa servir la fletxa -> i retorna un valor, que es guarda a horari: no cal break, i diversos valors al mateix cas se separen amb comes ('T', 't'). Treballa amb un char, que s'escriu entre cometes simples; amb un String funciona igual (case "cafè", "tallat" ->). Si torn no coincideix amb cap cas, s'aplica el default.

Quan un cas necessita més d'una instrucció, s'escriu un bloc { } i el valor es retorna amb yield. Dins del bloc hi pot haver qualsevol instrucció, també un if: aquí la tarda del divendres té un missatge propi. Fixa't en el ; final, després de la clau: tota la instrucció és una assignació.

⚠️ Errors típics

No oblidis el break. Sense break, Java continua executant els case següents sense comprovar-los (fall-through). Només l'ometem a propòsit per agrupar casos, com el 6 i el 7 de l'exemple.

Clàssic o amb fletxa? (Java 14+)

Des de Java 14 hi ha una sintaxi més curta amb ->. Té dos avantatges: no cal break (no hi ha fall-through) i el switch pot retornar un valor que guardem en una variable. S'assembla més al Segun de PSeInt, que també permet 1, 2, 3:.

8 % 2 és 0: la condició és certa i es tria el primer valor.

La pantalla d'un ascensor mostra què hi ha a cada planta. Les plantes 1 i 2 són totes dues d'oficines. L'algorisme demana per teclat a quina planta vas i mostra què hi ha. Tradueix el Segun a un switch clàssic (amb case i break). Classe Ascensor.

✅ Solució
import java.util.Scanner; public class Ascensor { public static void main(String[] args) { // Dada d'entrada: la planta, llegida del teclat Scanner sc = new Scanner(System.in); System.out.print("A quina planta vas? "); int planta = sc.nextInt(); System.out.println(); System.out.print("Planta " + planta + ": "); switch (planta) { case -1: System.out.println("Pàrquing"); break; case 0: System.out.println("Recepció"); break; case 1: case 2: System.out.println("Oficines"); break; case 3: System.out.println("Menjador"); break; default: System.out.println("aquesta planta no existeix"); } sc.close(); } }
✔ Què es valora
  • Hi ha un break a cada case que no s'agrupa amb el següent.
  • Les plantes 1 i 2 comparteixen el mateix codi.
  • El default recull les plantes que no existeixen.
  • La planta es llegeix del teclat amb Scanner, amb un missatge que la demana.
  • La sortida coincideix amb l'exemple: print per a la primera part de la línia.

1 · Llegeix l'algorisme→2 · Escriu-lo en Java→3 · Executa i compara

Volem saber quants dies té un mes. El febrer en té 29 si l'any és de traspàs i 28 si no ho és. L'algorisme demana per teclat el número del mes i l'any, i calcula si l'any és de traspàs: ho és si és divisible per 4 però no per 100, o si és divisible per 400 (2024 i 2000 ho són; 2025 i 1900, no). Cada branca del Segun només assigna un valor a dies: a Java, escriu-ho amb un switch amb fletxa que retorna el valor i fes servir un operador ternari per al febrer. Classe DiesMes.

Algoritmo DiesMes Definir mes, any, dies Como Entero Definir esTraspas Como Logico Escribir Sin Saltar "Mes (1-12)? " Leer mes Escribir Sin Saltar "Any? " Leer any Escribir "" esTraspas <- (any MOD 4 = 0 Y any MOD 100 <> 0) O any MOD 400 = 0 Segun mes Hacer 1, 3, 5, 7, 8, 10, 12: dies <- 31 4, 6, 9, 11: dies <- 30 2: Si esTraspas Entonces dies <- 29 SiNo dies <- 28 FinSi De Otro Modo: dies <- 0 FinSegun Si dies = 0 Entonces Escribir "Mes no vàlid: ", mes SiNo Escribir "El mes ", mes, " té ", dies, " dies." FinSi FinAlgoritmo
  • Declara i assigna alhora: int dies = switch (mes) { … }; No cal cap break.
  • El Si … SiNo del cas 2 només tria un valor: escriu-lo com esTraspas ? 29 : 28.
  • Llegeix el mes i l'any amb sc.nextInt().
  • La condició de traspàs: MOD → %, Y → &&, O → ||, <> → !=. Guarda-la en un boolean esTraspas.
  • Prova amb el mes 2 dels anys 2024, 2025, 2000 i 1900, i amb els mesos 4, 12 i 13.
🖥️ Exemple d'execució
Mes (1-12)? 2
Any? 2024

El mes 2 té 29 dies.
✅ Solució
import java.util.Scanner; public class DiesMes { public static void main(String[] args) { // Dades d'entrada: el mes i l'any, llegits del teclat Scanner sc = new Scanner(System.in); System.out.print("Mes (1-12)? "); int mes = sc.nextInt(); System.out.print("Any? "); int any = sc.nextInt(); System.out.println(); // Traspàs: divisible per 4 i no per 100, o divisible per 400 boolean esTraspas = (any % 4 == 0 && any % 100 != 0) || any % 400 == 0; // El switch retorna directament els dies (0 si el mes no existeix) int dies = switch (mes) { case 1, 3, 5, 7, 8, 10, 12 -> 31; case 4, 6, 9, 11 -> 30; case 2 -> esTraspas ? 29 : 28; default -> 0; }; if (dies == 0) { System.out.println("Mes no vàlid: " + mes); } else { System.out.println("El mes " + mes + " té " + dies + " dies."); } sc.close(); } }
✔ Què es valora
  • El switch és una expressió que retorna el valor, acabada en ;.
  • Els mesos s'agrupen amb comes en lloc de repetir un cas per mes.
  • El febrer es resol amb un ternari, no amb un if de diverses línies.
  • Hi ha default i es comprova el mes no vàlid.
  • El mes i l'any es llegeixen del teclat amb Scanner i cada lectura té el seu missatge.
  • La condició de traspàs combina %, && i ||, i encerta el 2000 (sí) i el 1900 (no).
