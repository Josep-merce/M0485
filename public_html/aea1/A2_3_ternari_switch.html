1

L'operador ternari

Triar entre dos valors

L'operador condició ? valorSiCert : valorSiFals és una forma abreujada d'if / else per a un cas molt concret: quan només volem triar entre dos valors per guardar-los en una variable o mostrar-los.

PSeInt no té operador ternari. Quan un Si … SiNo només fa una assignació a cada branca, a Java es pot escriure en una línia:

Si a > b Entonces major <- a SiNo major <- b FinSi
BàsicTriar un valor amb el ternari
public class Ternari { public static void main(String[] args) { int a = 12; int b = 30; int major = (a > b) ? a : b; System.out.println("El major és " + major); double nota = 4.5; String resultat = (nota >= 5) ? "Aprovat" : "Suspès"; System.out.println(resultat); } }
🖥️ Sortida per consola
El major és 30
Suspès
Com funciona

(a > b) ? a : b es llegeix "si a > b, llavors a; si no, b". El resultat es guarda a major. Els dos valors han de ser del mateix tipus que la variable.

✅ Bones pràctiques

Fes servir el ternari només per a casos senzills. Si has de fer diverses instruccions o encadenar condicions, un if / else és molt més llegible.

🔁 De PSeInt a Java
PSeIntJava
Si c Entonces x <- v1 SiNo x <- v2 FinSix = c ? v1 : v2;

2

La sentència switch

Una variable, molts valors

switch compara una sola expressió amb una llista de valors concrets (case) i executa el codi del que coincideix. Funciona amb int, char, String i altres tipus, però no amb double ni boolean. El default recull els valors que no coincideixen amb cap cas.

És l'equivalent del Segun de PSeInt:

Segun dia Hacer 1: Escribir "Dilluns" 2: Escribir "Dimarts" 6, 7: Escribir "Cap de setmana" De Otro Modo: Escribir "Dia no vàlid" FinSegun
BàsicNom del dia de la setmana
public class DiaSetmana { public static void main(String[] args) { int dia = 3; switch (dia) { case 1: System.out.println("Dilluns"); break; case 2: System.out.println("Dimarts"); break; case 3: System.out.println("Dimecres"); break; case 4: System.out.println("Dijous"); break; case 5: System.out.println("Divendres"); break; case 6: case 7: System.out.println("Cap de setmana"); break; default: System.out.println("Dia no vàlid"); } } }
🖥️ Sortida per consola
Dimecres
⚠️ Errors típics

No oblidis el break. Sense break, Java continua executant els case següents sense comprovar-los (fall-through). Només l'ometem a propòsit per agrupar casos, com el 6 i el 7 de l'exemple.

MitjàCalculadora amb switch sobre un char
public class Calculadora { public static void main(String[] args) { double a = 10.0; double b = 4.0; char operador = '/'; switch (operador) { case '+': System.out.println(a + " + " + b + " = " + (a + b)); break; case '-': System.out.println(a + " - " + b + " = " + (a - b)); break; case '*': System.out.println(a + " * " + b + " = " + (a * b)); break; case '/': if (b != 0) { System.out.println(a + " / " + b + " = " + (a / b)); } else { System.out.println("Error: divisió per zero"); } break; default: System.out.println("Operador desconegut: " + operador); } } }
🖥️ Sortida per consola
10.0 / 4.0 = 2.5
Com funciona

Els valors char s'escriuen entre cometes simples ('+'). Dins d'un case hi pot haver qualsevol instrucció, també un if: aquí evitem la divisió per zero.

public class MenuCaixer { public static void main(String[] args) { int opcio = 3; double saldo = 250; switch (opcio) { case 1: System.out.println("Saldo disponible: " + saldo + " €"); break; case 2: System.out.println("Introdueix els bitllets a la ranura."); break; case 3: System.out.println("Quants diners vols retirar?"); break; case 4: System.out.println("Gràcies per utilitzar el caixer."); break; default: System.out.println("Opció no vàlida: " + opcio); } } }

3

switch amb fletxa (Java 14+)

Més curt i sense break

Des de Java 14 hi ha una sintaxi més curta amb ->. Té dos avantatges: no cal break (no hi ha fall-through) i el switch pot retornar un valor que guardem en una variable. S'assembla més al Segun de PSeInt, que també permet 1, 2, 3:.

MitjàEstació de l'any amb switch com a expressió
public class EstacioAny { public static void main(String[] args) { int mes = 7; String estacio = switch (mes) { case 12, 1, 2 -> "Hivern"; case 3, 4, 5 -> "Primavera"; case 6, 7, 8 -> "Estiu"; case 9, 10, 11 -> "Tardor"; default -> "Mes no vàlid"; }; System.out.println("Mes " + mes + ": " + estacio); } }
🖥️ Sortida per consola
Mes 7: Estiu
Com funciona

El resultat del switch es guarda directament a estacio. Diversos valors al mateix case se separen amb comes. Fixa't en el ; final, després de la clau: tota la línia és una assignació.

Mitjàswitch amb String i blocs d'instruccions
public class MenuCafeteria { public static void main(String[] args) { String producte = "entrepà"; int quantitat = 2; double preu = switch (producte) { case "cafè" -> 1.30; case "suc" -> 2.10; case "entrepà" -> { System.out.println("(Entrepà del dia: truita)"); yield 3.50; // yield retorna el valor quan el cas té un bloc { } } default -> 0.0; }; if (preu == 0.0) { System.out.println("Producte no disponible: " + producte); } else { System.out.println(quantitat + " x " + producte + " = " + (quantitat * preu) + " €"); } } }
🖥️ Sortida per consola
(Entrepà del dia: truita)
2 x entrepà = 7.0 €
Com funciona

Quan un cas necessita més d'una instrucció, s'escriu un bloc { } i el valor es retorna amb yield.

Cada branca del Segun només assigna un valor a trimestre. A Java, escriu-ho amb un switch amb fletxa que retorna el valor. Classe Trimestre.

Algoritmo Trimestre Definir mes, trimestre Como Entero mes <- 8 Segun mes Hacer 1, 2, 3: trimestre <- 1 4, 5, 6: trimestre <- 2 7, 8, 9: trimestre <- 3 10, 11, 12: trimestre <- 4 De Otro Modo: trimestre <- 0 FinSegun Si trimestre = 0 Entonces Escribir "Mes no vàlid: ", mes SiNo Escribir "El mes ", mes, " és del trimestre ", trimestre FinSi FinAlgoritmo
✅ Solució
public class Trimestre { public static void main(String[] args) { int mes = 8; // El switch retorna directament el trimestre (0 si el mes no existeix) int trimestre = switch (mes) { case 1, 2, 3 -> 1; case 4, 5, 6 -> 2; case 7, 8, 9 -> 3; case 10, 11, 12 -> 4; default -> 0; }; if (trimestre == 0) { System.out.println("Mes no vàlid: " + mes); } else { System.out.println("El mes " + mes + " és del trimestre " + trimestre); } } }
✔ Què es valora
  • El switch és una expressió que retorna el valor.
  • Els mesos s'agrupen amb comes en lloc de repetir 12 casos.
  • Hi ha default i es comprova el mes no vàlid.
  • Declara i assigna alhora: int trimestre = switch (mes) { … };
  • No cal cap break.
  • Prova els mesos 1, 12 i 13.
💡 Pista
No oblidis el ; després de la clau de tancament del switch: és el final de la instrucció int trimestre = …;.

Dos exercicis ràpids per repassar tota la subpàgina

Comprova que saps llegir un ternari i un switch, i que saps quan convé fer servir switch i quan if.

Demo 1Quina sortida?Mitjà

Llegeix el codi i tria què es mostra per pantalla.

1. int x = 8; System.out.print((x % 2 == 0) ? "parell" : "senar");
8 % 2 és 0: la condició és certa i es tria el primer valor.
2. int d = 1; switch (d) { case 1: System.out.print("A"); case 2: System.out.print("B"); break; default: System.out.print("C"); }
El case 1 no té break: continua al case 2 (fall-through) i s'atura al seu break.
3. El mateix switch amb int d = 5;
Cap case coincideix: s'executa el default.
4. String s = switch (3) { case 1, 2 -> "X"; case 3 -> "Y"; default -> "Z"; };
Amb fletxa no hi ha fall-through: només s'agafa el valor del cas que coincideix.
