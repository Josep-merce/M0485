Tipus de dades

Quina mena de valor guarda cada variable

Java és un llenguatge fortament tipat: cada variable té un tipus que determina quins valors pot guardar i quines operacions s'hi poden fer. Hi ha dos grans grups: els tipus primitius (valors simples) i els tipus de referència (objectes, com String). PSeInt només té quatre tipus; Java en té més, perquè distingeix la mida dels números i un caràcter sol d'un text.

public class LimitsTipus { public static void main(String[] args) { System.out.println("int màxim: " + Integer.MAX_VALUE); System.out.println("int mínim: " + Integer.MIN_VALUE); System.out.println("long màxim: " + Long.MAX_VALUE); System.out.println("byte màxim: " + Byte.MAX_VALUE); } }

Com funciona

Cada tipus primitiu té una classe associada (Integer, Long, Byte…) que guarda, entre altres coses, els seus límits: MAX_VALUE i MIN_VALUE. El programa només els mostra.

Fixa't en la diferència de mida: un byte arriba a 127, un int a uns 2.100 milions i un long a més de 9 trilions. Aquestes classes s'expliquen a A1.4.

✅ Bones pràctiques

Quin triar? Per a enters, usa int (i long si el número és molt gran). Per a decimals, usa double. Els altres tipus numèrics es fan servir en casos molt concrets.

👀 Fixa't-hi

El tipus String guarda text: String nom = "Anna";. S'escriu amb majúscula perquè no és un tipus primitiu sinó una classe. És el tipus que fem servir per als textos que a PSeInt eren Caracter o Cadena. Treballarem les classes i els objectes a l'AEA2.

Literals

Valors escrits directament al codi

Un literal és un valor escrit directament al codi: 42, 3.14, 'A', true o "Hola". El tipus del literal depèn de com l'escrivim.

public class Literals { public static void main(String[] args) { int vides = 3; long habitants = 8_000_000_000L; double preu = 19.99; char inicial = 'J'; boolean obert = true; String botiga = "La Mercè Market"; System.out.println(vides); System.out.println(habitants); System.out.println(preu); System.out.println(inicial); System.out.println(obert); System.out.println(botiga); } }

Com funciona

Cada variable rep un literal del seu tipus. El long porta la L final perquè 8.000 milions no cap en un int, i els guions baixos _ no es mostren: només fan el número més fàcil de llegir al codi.

En mostrar-los, les cometes desapareixen: 'J' surt com a J i "La Mercè Market" sense cometes. Les cometes només indiquen al compilador on comença i acaba el valor.

⚠️ Errors típics

Trampes freqüents: float f = 3.14; no compila (cal 3.14f); boolean b = True; tampoc (és true); i char c = "A"; és un error perquè les cometes dobles són per a String.

3

Variables

Espais de memòria amb nom

Una variable és un espai de memòria amb un nom on guardem un valor que pot canviar durant l'execució. Té tres elements: tipus, nom i valor.

Sintaxi
tipus nom; → declaració
tipus nom = valor; → declaració i inicialització
nom = nouValor; → assignació d'un nou valor (sense repetir el tipus)
Declarar, inicialitzar i modificar variables
public class ReservaVol { public static void main(String[] args) { // Declaració i inicialització alhora String desti = "Barcelona - Tòquio"; int numPassatgers = 2; double preuPerPersona = 874.50; boolean esDirecte = true; // Declaració i inicialització per separat char classe; classe = 'E'; // E = econòmica, B = business double totalReserva = numPassatgers * preuPerPersona; System.out.println("Destinació: " + desti + " (directe: " + esDirecte + ")"); System.out.println(numPassatgers + " passatgers, classe " + classe + ": " + totalReserva + " €"); // Modifiquem el valor (sense tornar a escriure el tipus) numPassatgers = 3; totalReserva = numPassatgers * preuPerPersona; System.out.println(numPassatgers + " passatgers, classe " + classe + ": " + totalReserva + " €"); } }
🖥️ Sortida per consola
Destinació: Barcelona - Tòquio (directe: true)
2 passatgers, classe E: 1749.0 €
3 passatgers, classe E: 2623.5 €

Fixa't que 1749.0 surt amb un decimal: en un double Java sempre en mostra almenys un.

Com funciona

Cada dada té el tipus que li correspon: text, enter, decimal, booleà i caràcter. La majoria es declaren i s'inicialitzen en una sola línia. classe es fa en dos passos: primer es declara (es reserva l'espai) i després s'hi guarda 'E'.

Quan canviem numPassatgers a 3 no tornem a escriure int: la variable ja existeix i només en modifiquem el valor. Fixa't que totalReserva no s'actualitza sola: l'hem de tornar a calcular perquè agafi el nou nombre de passatgers.

⚠️ Errors típics

Una variable local s'ha d'inicialitzar abans d'usar-la. Si declares int total; i després fas System.out.println(total); sense haver-li donat cap valor, el compilador mostra l'error variable total might not have been initialized.

📚 Per saber-ne més · inferència de tipus amb var

Des de Java 10 podem escriure var en lloc del tipus i el compilador el dedueix del valor inicial. El tipus queda fixat: no és una variable "sense tipus".

MitjàÚs de var
public class TipusVar { public static void main(String[] args) { var nom = "Laia"; // String var edat = 22; // int var preu = 9.99; // double // var x; → error: sense valor inicial no es pot deduir el tipus // edat = "vint"; → error: edat és int i no pot guardar text System.out.println(nom + " (" + edat + ") ha pagat " + preu + " €"); } }
🖥️ Sortida per consola
Laia (22) ha pagat 9.99 €
Com funciona

El compilador mira el valor de la dreta: "Laia" és un String, 22 un int i 9.99 un double. Per això var necessita sempre un valor inicial. Al curs escriurem el tipus explícitament: és més clar mentre aprenem.

Constants

Valors que no canvien

Una constant és un valor que no pot canviar un cop assignat. Es declara amb la paraula clau final i, per convenció, el nom s'escriu en MAJÚSCULES separant les paraules amb guió baix.

CaracterísticaVariableConstantPSeInt
Paraula clau—final— (no hi ha constants: tot són variables)
Pot canviar de valor✔ Sí✘ No (error de compilació)✔ Sempre: iva <- 0.21 es pot tornar a canviar
NomenclaturapreuFinalIVA_GENERALiva, com qualsevol variable
Exemplesedat, comptador, totalIVA, dies de la setmana, nota mínima per aprovar—
Constants per a una botiga en línia
public class Botiga { public static void main(String[] args) { // Constants: valors fixos del negoci final double IVA = 0.21; final double DESCOMPTE_SOCI = 0.10; final int DIES_DEVOLUCIO = 30; // Variables: valors d'aquesta compra double preuBase = 80.0; int diesRestants = DIES_DEVOLUCIO; // comença amb el valor de la constant double preuSoci = preuBase - preuBase * DESCOMPTE_SOCI; // 72.0 double preuFinal = preuSoci * (1 + IVA); // 87.12 // Han passat 12 dies des de la compra diesRestants = diesRestants - 12; System.out.println("Preu final: " + preuFinal + " €"); System.out.println("Dies per retornar-lo: " + diesRestants + " de " + DIES_DEVOLUCIO); // IVA = 0.18; → error de compilació: no es pot reassignar una constant } }
🖥️ Sortida per consola
Preu final: 87.12 €
Dies per retornar-lo: 18 de 30
Com funciona

Les constants agrupen les regles del negoci (IVA, descompte de soci, dies de devolució) a l'inici del programa; les variables guarden les dades d'aquesta compra concreta. El càlcul fa servir els noms, no els números.

Una constant també pot donar el valor inicial d'una variable: diesRestants comença valent DIES_DEVOLUCIO i després canvia, mentre que la constant continua valent 30.

La darrera línia està comentada perquè no compilaria: un cop una variable final té valor, no se'n pot assignar un altre.

✅ Bones pràctiques

Per què usar constants? Si l'IVA canvia, només cal modificar-lo en un lloc. A més, preu * IVA s'entén molt millor que preu * 0.21 (un "número màgic" sense explicació).

Una videoteca guarda unes quantes dades de cada pel·lícula: el títol, l'any, la durada, la valoració, la versió (O original o D doblada) i si té subtítols. Tradueix l'algorisme a Java a la classe Pelicula triant el tipus adequat per a cada dada.

Algoritmo Pelicula Definir titol, versio Como Caracter Definir any, durada Como Entero Definir valoracio Como Real Definir subtitulada Como Logico titol <- "La vida és bella" versio <- "O" any <- 1997 durada <- 116 valoracio <- 8.6 subtitulada <- Verdadero Escribir "Títol: ", titol, " (", any, ")" Escribir "Durada: ", durada, " min" Escribir "Valoració: ", valoracio Escribir "Versió: ", versio, " · Subtitulada: ", subtitulada FinAlgoritmo
  • Entero → int, Real → double, Logico → boolean.
  • Caracter pot ser un text (String, cometes dobles) o una sola lletra (char, cometes simples). Mira quin valor guarda cada variable.
  • Verdadero → true, en minúscula. Declara i inicialitza cada variable en una sola línia.

Títol: La vida és bella (1997)
Durada: 116 min
Valoració: 8.6

✅ Solució
// Mostra la fitxa d'una pel·lícula de la videoteca public class Pelicula { public static void main(String[] args) { String titol = "La vida és bella"; // text: cometes dobles char versio = 'O'; // una sola lletra (O = original, D = doblada) int any = 1997; // enter int durada = 116; // minuts double valoracio = 8.6; // decimal: punt, no coma boolean subtitulada = true; // en minúscula System.out.println("Títol: " + titol + " (" + any + ")"); System.out.println("Durada: " + durada + " min"); System.out.println("Valoració: " + valoracio); System.out.println("Versió: " + versio + " · Subtitulada: " + subtitulada); } }
✔ Què es valora
  • titol és String i versio és char amb cometes simples: 'O'.
  • any i durada són int; valoracio és double i s'escriu amb punt decimal.
  • subtitulada és boolean i val true, en minúscula.
  • La sortida coincideix amb l'exemple, espais i parèntesis inclosos.

✍️ Ara tu · Exercici 2El viatge en taxiMitjà
1 · Llegeix l'algorisme→2 · Escriu-lo en Java→3 · Executa i compara

Un taxi cobra una baixada de bandera de 2,5 € i 1,25 € per quilòmetre. Aquest algorisme calcula el preu d'un trajecte de 5 km i, quan el client demana anar 3 km més lluny, el torna a calcular. Tradueix-lo a Java a la classe Taxi. A PSeInt tot són variables: a Java, decideix quines dades han de ser constants.

Algoritmo Taxi Definir baixadaBandera, preuKm, preuViatge Como Real Definir matricula Como Caracter Definir km Como Entero baixadaBandera <- 2.5 preuKm <- 1.25 matricula <- "4821 KLM" km <- 5 preuViatge <- baixadaBandera + km * preuKm Escribir "Taxi ", matricula Escribir "Trajecte: ", km, " km → ", preuViatge, " €" // El client demana anar 3 km més lluny km <- km + 3 preuViatge <- baixadaBandera + km * preuKm Escribir "Trajecte: ", km, " km → ", preuViatge, " €" FinAlgoritmo
  • La baixada de bandera i el preu per km són la tarifa del taxi: no canvien d'un viatge a l'altre. Declara-les amb final i en MAJÚSCULES (BAIXADA_BANDERA, PREU_KM).
  • km <- km + 3 → km = km + 3;, sense tornar a escriure int: la variable ja existeix.
  • preuViatge no s'actualitza sol quan canvia km: l'has de tornar a calcular.
🖥️ Exemple d'execució
Taxi 4821 KLM
Trajecte: 5 km → 8.75 €
Trajecte: 8 km → 12.5 €
✅ Solució
// Calcula el preu d'un viatge en taxi abans i després d'allargar el trajecte public class Taxi { public static void main(String[] args) { // Constants: la tarifa del taxi no canvia d'un viatge a l'altre final double BAIXADA_BANDERA = 2.5; // euros final double PREU_KM = 1.25; // euros per km // Variables: dades d'aquest viatge String matricula = "4821 KLM"; int km = 5; double preuViatge = BAIXADA_BANDERA + km * PREU_KM; System.out.println("Taxi " + matricula); System.out.println("Trajecte: " + km + " km → " + preuViatge + " €"); // El client demana anar 3 km més lluny km = km + 3; preuViatge = BAIXADA_BANDERA + km * PREU_KM; // cal tornar-lo a calcular System.out.println("Trajecte: " + km + " km → " + preuViatge + " €"); } }
✔ Què es valora
  • BAIXADA_BANDERA i PREU_KM són final double i segueixen la convenció de noms.
  • km, matricula i preuViatge són variables amb el tipus adequat (int, String i double).
  • La modificació és km = km + 3;, sense int al davant, i el preu es recalcula.
  • Els càlculs fan servir el nom de les constants, no els números 2.5 i 1.25.
