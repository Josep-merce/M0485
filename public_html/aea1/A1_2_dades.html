Tipus de dades

Quina mena de valor guarda cada variable

Java és un llenguatge fortament tipat: cada variable té un tipus que determina quins valors pot guardar i quines operacions s'hi poden fer. Hi ha dos grans grups: els tipus primitius (valors simples) i els tipus de referència (objectes, com String).

Com funciona

Cada tipus primitiu té una classe associada (Integer, Long, Byte…) que guarda, entre altres coses, els seus límits: MAX_VALUE i MIN_VALUE. El programa només els mostra.

Fixa't en la diferència de mida: un byte arriba a 127, un int a uns 2.100 milions i un long a més de 9 trilions. Aquestes classes s'expliquen a A1.4.

✅ Bones pràctiques

Quin triar? Per a enters, usa int (i long si el número és molt gran). Per a decimals, usa double. Els altres tipus numèrics es fan servir en casos molt concrets.

👀 Fixa't-hi

El tipus String guarda text: String nom = "Anna";. S'escriu amb majúscula perquè no és un tipus primitiu sinó una classe. Treballarem les classes i els objectes a l'AEA2.

Literals

Valors escrits directament al codi

Un literal és un valor escrit directament al codi: 42, 3.14, 'A', true o "Hola". El tipus del literal depèn de com l'escrivim.

Com funciona

Cada variable rep un literal del seu tipus. El long porta la L final perquè 8.000 milions no cap en un int, i els guions baixos _ no es mostren: només fan el número més fàcil de llegir al codi.

En mostrar-los, les cometes desapareixen: 'J' surt com a J i "La Mercè Market" sense cometes. Les cometes només indiquen al compilador on comença i acaba el valor.

⚠️ Errors típics

Trampes freqüents: float f = 3.14; no compila (cal 3.14f); boolean b = True; tampoc (és true); i char c = "A"; és un error perquè les cometes dobles són per a String.

Variables

Espais de memòria amb nom

Una variable és un espai de memòria amb un nom on guardem un valor que pot canviar durant l'execució. Té tres elements: tipus, nom i valor.

Sintaxi
tipus nom; → declaració
tipus nom = valor; → declaració i inicialització
nom = nouValor; → assignació d'un nou valor (sense repetir el tipus)
Declarar, inicialitzar i modificar variables
public class ReservaVol { public static void main(String[] args) { // Declaració i inicialització alhora String desti = "Barcelona - Tòquio"; int numPassatgers = 2; double preuPerPersona = 874.50; boolean esDirecte = true; // Declaració i inicialització per separat char classe; classe = 'E'; // E = econòmica, B = business double totalReserva = numPassatgers * preuPerPersona; System.out.println("Destinació: " + desti + " (directe: " + esDirecte + ")"); System.out.println(numPassatgers + " passatgers, classe " + classe + ": " + totalReserva + " €"); // Modifiquem el valor (sense tornar a escriure el tipus) numPassatgers = 3; totalReserva = numPassatgers * preuPerPersona; System.out.println(numPassatgers + " passatgers, classe " + classe + ": " + totalReserva + " €"); } }
🖥️ Sortida per consola
Destinació: Barcelona - Tòquio (directe: true)
2 passatgers, classe E: 1749.0 €
3 passatgers, classe E: 2623.5 €

Fixa't que 1749.0 surt amb un decimal: en un double Java sempre en mostra almenys un.

Com funciona

Cada dada té el tipus que li correspon: text, enter, decimal, booleà i caràcter. La majoria es declaren i s'inicialitzen en una sola línia. classe es fa en dos passos: primer es declara (es reserva l'espai) i després s'hi guarda 'E'.

Quan canviem numPassatgers a 3 no tornem a escriure int: la variable ja existeix i només en modifiquem el valor. Fixa't que totalReserva no s'actualitza sola: l'hem de tornar a calcular perquè agafi el nou nombre de passatgers.

⚠️ Errors típics

Una variable local s'ha d'inicialitzar abans d'usar-la. Si declares int total; i després fas System.out.println(total); sense haver-li donat cap valor, el compilador mostra l'error variable total might not have been initialized.

📚 Per saber-ne més · inferència de tipus amb var

Des de Java 10 podem escriure var en lloc del tipus i el compilador el dedueix del valor inicial. El tipus queda fixat: no és una variable "sense tipus".

MitjàÚs de var
public class TipusVar { public static void main(String[] args) { var nom = "Laia"; // String var edat = 22; // int var preu = 9.99; // double // var x; → error: sense valor inicial no es pot deduir el tipus // edat = "vint"; → error: edat és int i no pot guardar text System.out.println(nom + " (" + edat + ") ha pagat " + preu + " €"); } }

Com funciona

El compilador mira el valor de la dreta: "Laia" és un String, 22 un int i 9.99 un double. Per això var necessita sempre un valor inicial. Al curs escriurem el tipus explícitament: és més clar mentre aprenem.

Constants

Valors que no canvien

Una constant és un valor que no pot canviar un cop assignat. Es declara amb la paraula clau final i, per convenció, el nom s'escriu en MAJÚSCULES separant les paraules amb guió baix.

CaracterísticaVariableConstant
Paraula clau—final
Pot canviar de valor✔ Sí✘ No (error de compilació)
NomenclaturapreuFinalIVA_GENERAL
Exemplesedat, comptador, totalIVA, dies de la setmana, nota mínima per aprovar
Constants per a una botiga en línia
public class Botiga { public static void main(String[] args) { // Constants: valors fixos del negoci final double IVA = 0.21; final double DESCOMPTE_SOCI = 0.10; final int DIES_DEVOLUCIO = 30; // Variables: valors d'aquesta compra double preuBase = 80.0; int diesRestants = DIES_DEVOLUCIO; // comença amb el valor de la constant double preuSoci = preuBase - preuBase * DESCOMPTE_SOCI; // 72.0 double preuFinal = preuSoci * (1 + IVA); // 87.12 // Han passat 12 dies des de la compra diesRestants = diesRestants - 12; System.out.println("Preu final: " + preuFinal + " €"); System.out.println("Dies per retornar-lo: " + diesRestants + " de " + DIES_DEVOLUCIO); // IVA = 0.18; → error de compilació: no es pot reassignar una constant } }
🖥️ Sortida per consola
Preu final: 87.12 €
Dies per retornar-lo: 18 de 30
Com funciona

Les constants agrupen les regles del negoci (IVA, descompte de soci, dies de devolució) a l'inici del programa; les variables guarden les dades d'aquesta compra concreta. El càlcul fa servir els noms, no els números.

Una constant també pot donar el valor inicial d'una variable: diesRestants comença valent DIES_DEVOLUCIO i després canvia, mentre que la constant continua valent 30.

La darrera línia està comentada perquè no compilaria: un cop una variable final té valor, no se'n pot assignar un altre.

✅ Bones pràctiques

Per què usar constants? Si l'IVA canvia, només cal modificar-lo en un lloc. A més, preu * IVA s'entén molt millor que preu * 0.21 (un "número màgic" sense explicació).

// Calcula l'import d'unes entrades de cinema amb el descompte del carnet jove public class Cinema { public static void main(String[] args) { // Constants: regles del cinema, no canvien en tot el programa final double PREU_ENTRADA = 8.0; final double DESCOMPTE_JOVE = 0.25; // Variables: dades d'aquesta compra int entrades = 3; double importBase = entrades * PREU_ENTRADA; double descompte = importBase * DESCOMPTE_JOVE; double total = importBase - descompte; System.out.println("Entrades: " + entrades); System.out.println("Import: " + importBase + " €"); System.out.println("Descompte: " + descompte + " €"); System.out.println("Total: " + total + " €"); // PREU_ENTRADA = 9.0; // error: cannot assign a value to final variable PREU_ENTRADA } }
✔ Què es valora
  • PREU_ENTRADA i DESCOMPTE_JOVE són final i segueixen la convenció de noms.
  • entrades continua sent una variable: depèn de cada compra.
  • Els càlculs fan servir el nom de les constants, no els números 8 i 0.25.
  • 24.0: el resultat és double perquè la constant és double, i un double sempre es mostra amb decimal.
  • El preu de l'entrada i el descompte del carnet jove són regles del cinema: no canvien d'una compra a l'altra. Declara'ls amb final.
  • Posa el nom de les constants en MAJÚSCULES, separant les paraules amb _.
  • Agrupa les constants al principi del main, amb un comentari, i separa-les de les variables de la compra.

total s'ha declarat però no té cap valor. Una variable local s'ha d'inicialitzar abans d'usar-la.

Missatge del compilador:
Total.java:5: error: variable total might not have been initialized

✅ Versió corregida
public class Total { public static void main(String[] args) { int total = 0; System.out.println(total); } }

c) Volem aplicar un IVA reduït.
public class IvaReduit { public static void main(String[] args) { final double IVA = 0.21; IVA = 0.10; System.out.println(IVA); } }
🔎 L'error
IVA és una constant (final): no se li pot assignar un altre valor. Si necessitem dos tipus d'IVA, fem dues constants.

Missatge del compilador:
IvaReduit.java:5: error: cannot assign a value to final variable IVA

✅ Versió corregida
public class IvaReduit { public static void main(String[] args) { final double IVA_GENERAL = 0.21; final double IVA_REDUIT = 0.10; System.out.println(IVA_REDUIT); } }
🖥️ Sortida per consola

d) Volem guardar un preu.
public class Preu { public static void main(String[] args) { int preu = 9.95; System.out.println(preu); } }
🔎 L'error
9.95 té decimals, però preu és int. Java no deixa perdre els decimals sense avisar: el tipus correcte és double.

Missatge del compilador:
Preu.java:4: error: incompatible types: possible lossy conversion from double to int

✅ Versió corregida
public class Preu { public static void main(String[] args) { double preu = 9.95; System.out.println(preu); } }

9.95
