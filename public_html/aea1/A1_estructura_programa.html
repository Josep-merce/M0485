1. Com es construeix un programa

Un programa és una seqüència d'instruccions que un ordinador executa per resoldre un problema. Abans d'escriure codi cal entendre bé el problema i dissenyar-ne la solució: primer es pensa, després es programa.

1AnàlisiQuè ens demanen? Quines dades tenim (entrada) i quin resultat volem (sortida)?
2Disseny de l'algorismeEscrivim els passos en pseudocodi o amb un diagrama, amb paper i llapis, sense pensar encara en Java.
3CodificacióTraduïm l'algorisme al llenguatge de programació (Java) dins de l'entorn de desenvolupament.
4CompilacióEl compilador revisa que el codi estigui ben escrit i el tradueix a un format executable.
5Prova i depuracióExecutem el programa amb diferents valors i comprovem que el resultat és correcte. Si no ho és, busquem l'error.
Exemple: calcular l'àrea i el perímetre d'un rectangle

Primer escrivim l'algorisme en pseudocodi (llenguatge natural estructurat) amb PSeInt:

Algoritmo Rectangle // Declaració de variables Definir base, altura, area, perimetre Como Entero // Dades d'entrada base <- 8 altura <- 5 // Càlculs area <- base * altura perimetre <- 2 * (base + altura) // Sortida Escribir "Àrea: ", area Escribir "Perímetre: ", perimetre FinAlgoritmo

Després el traduïm a Java. Aquest tipus d'algorisme, en què les instruccions s'executen una rere l'altra de dalt a baix, s'anomena composició seqüencial.

BàsicDe l'algorisme al codi Java
// public: la classe és accessible des de qualsevol lloc // class: declara una classe, el "contenidor" del programa // El nom (Rectangle) ha de coincidir amb el del fitxer (Rectangle.java) public class Rectangle { // main: mètode principal, punt d'entrada; és el primer que s'executa en arrencar el programa // public: es pot cridar des de fora; així Java el pot trobar i executar // static: s'executa directament, sense haver de preparar res abans // void: no retorna cap resultat, només fa les instruccions que conté // String[] args: llista (array) de textos amb els arguments que es poden passar al programa en executar-lo public static void main(String[] args) { // Dades d'entrada int base = 8; int altura = 5; // Càlculs int area = base * altura; int perimetre = 2 * (base + altura); // Sortida System.out.println("Àrea: " + area); System.out.println("Perímetre: " + perimetre); } }

2. Java: JDK, JRE i JVM

Java és un llenguatge de programació d'alt nivell i d'ús general creat el 1995 per James Gosling a Sun Microsystems. El seu lema és "Escriu una vegada, executa a qualsevol lloc": el codi compilat funciona a qualsevol sistema que tingui una màquina virtual Java instal·lada.

CaracterísticaDescripció
PortabilitatEl mateix programa compilat s'executa a Windows, macOS i Linux sense canvis.
Orientat a objectesEls programes s'organitzen en classes i objectes (ho treballarem a partir de l'AEA2).
Gestió automàtica de memòriaEl Garbage Collector allibera la memòria que ja no s'usa.
Àmplia comunitatUn dels llenguatges més demandats al mercat laboral, amb molts frameworks i llibreries.
Versió del cursJDK 21 (LTS): versió de suport a llarg termini, estable i recomanada.
ComponentNom completPer a què serveix
JDKJava Development KitEines per desenvolupar: compilador (javac), JRE i eines de depuració.
JREJava Runtime EnvironmentEntorn per executar programes Java. Inclou la JVM i les llibreries estàndard.
JVMJava Virtual MachineMàquina virtual que executa el bytecode traduint-lo a instruccions del sistema operatiu.
📌 Procés de compilació i execució:
Codi font (Rectangle.java) → javac (compilador) → Bytecode (Rectangle.class) → JVM → Execució

5. Estructura d'un programa Java

Tot programa Java està format per uns blocs que sempre apareixen en el mateix ordre. Identificar-los és el primer pas per llegir i entendre qualsevol codi.

MitjàEls blocs d'un programa, comentats
// ① Importacions: classes d'altres paquets que farem servir (opcional) import java.time.LocalDate; // ② Declaració de la classe: el nom ha de coincidir amb el del fitxer public class Estructura { // ③ Mètode main: punt d'entrada. L'execució sempre comença aquí public static void main(String[] args) { // ④ Declaració de variables String nom = "Laia"; int any = LocalDate.now().getYear(); // ⑤ Instruccions: cadascuna acaba amb punt i coma System.out.println("Hola, " + nom + "!"); System.out.println("Som a l'any " + any); } // ← fi del mètode main } // ← fi de la classe

7. Comentaris

Els comentaris són text que el compilador ignora. Serveixen per explicar el codi a les persones: companys, professorat o tu mateix d'aquí a uns mesos. Un bon comentari explica el per què, no el que ja es veu llegint el codi.

TipusSintaxiQuan usar-lo
Una línia// textNotes curtes sobre una instrucció.
Diverses línies/* text */Explicar un bloc de codi o desactivar codi temporalment.
Javadoc/** text */Documentar classes i mètodes. L'eina javadoc genera pàgines web a partir d'aquests comentaris.
BàsicComentari de línia i de final de línia
// Programa que saluda l'usuari per pantalla public class Salutacio { public static void main(String[] args) { System.out.println("Hola, món!"); // missatge de benvinguda } }
MitjàComentari de bloc per explicar un càlcul
public class CalcularPreu { public static void main(String[] args) { /* Calculem el preu final d'un article: primer apliquem un descompte del 10 % i després hi afegim el 21 % d'IVA */ double preuBase = 40.0; double descompte = preuBase * 0.10; double preuFinal = (preuBase - descompte) * 1.21; System.out.println("Preu final: " + preuFinal + " €"); // 43.56 } }
AvançatComentari Javadoc per documentar una classe
/** * Mostra per pantalla la fitxa d'un alumne del cicle DAW. * * @author Laia Puig * @version 1.0 */ public class FitxaAlumne { /** * Punt d'entrada del programa. * * @param args arguments de la línia d'ordres (no s'utilitzen) */ public static void main(String[] args) { String nom = "Laia Puig"; int curs = 1; System.out.println(nom + " - " + curs + "r DAW"); } }
💡 Bon comentari vs mal comentari: // multipliquem per 1.8 no aporta res (ja es veu al codi). // convertim de Celsius a Fahrenheit sí que ajuda. A NetBeans, Ctrl+/ comenta o descomenta les línies seleccionades.

8. Tipus de dades

Java és un llenguatge fortament tipat: cada variable té un tipus que determina quins valors pot guardar i quines operacions s'hi poden fer. Hi ha dos grans grups: els tipus primitius (valors simples) i els tipus de referència (objectes, com String).

Tipus primitiuMidaValors possiblesExemple
byte8 bits−128 a 127byte b = 100;
short16 bits−32.768 a 32.767short s = 30000;
int32 bits−2.147.483.648 a 2.147.483.647int edat = 25;
long64 bitsaprox. ±9,2 × 1018long poblacio = 8_000_000_000L;
float32 bitsdecimal, uns 7 dígits de precisiófloat alcada = 1.75f;
double64 bitsdecimal, uns 15 dígits de precisiódouble pi = 3.14159;
char16 bitsun caràcter Unicodechar inicial = 'A';
boolean—true o falseboolean aprovat = true;
💡 Quin triar? Per a enters, usa int (i long si el número és molt gran). Per a decimals, usa double. Els altres tipus numèrics es fan servir en casos molt concrets.
📌 El tipus String guarda text: String nom = "Anna";. S'escriu amb majúscula perquè no és un tipus primitiu sinó una classe. Treballarem les classes i els objectes a l'AEA2.
Classes envoltants (wrapper)

Cada tipus primitiu té una classe associada amb utilitats. Ara les farem servir per consultar límits i per convertir text a número.

Un literal és un valor escrit directament al codi: 42, 3.14, 'A', true o "Hola". El tipus del literal depèn de com l'escrivim.

Enter llarglong9_000_000_000LCal la L final si supera el rang d'int.
Decimaldouble3.14 · 1.5e3Punt decimal, mai coma. 1.5e3 = 1500.0
Decimal curtfloat9.99fCal la f final.
Caràcterchar'A' · '7' · '@'Cometes simples i un sol caràcter.
Booleàbooleantrue · falseSempre en minúscula.

public class Literals { public static void main(String[] args) { int vides = 3; long habitants = 8_000_000_000L; double preu = 19.99; char inicial = 'J'; boolean obert = true; String botiga = "La Mercè Market"; System.out.println(vides); System.out.println(habitants); System.out.println(preu); System.out.println(inicial); System.out.println(obert); System.out.println(botiga); } }

10. Variables

Una variable és un espai de memòria amb un nom on guardem un valor que pot canviar durant l'execució. Té tres elements: tipus, nom i valor.

📌 Sintaxi:
tipus nom; → declaració
tipus nom = valor; → declaració i inicialització
nom = nouValor; → assignació d'un nou valor (sense repetir el tipus)
BàsicDeclarar, inicialitzar i modificar variables
public class Variables { public static void main(String[] args) { // Declaració i inicialització alhora int edat = 25; double salari = 1500.50; boolean esActiu = true; String nom = "Anna"; // Declaració i inicialització per separat char grup; grup = 'B'; System.out.println(nom + " té " + edat + " anys"); // Modifiquem el valor (sense tornar a escriure el tipus) edat = 26; System.out.println("Any següent: " + edat + " anys"); System.out.println("Grup " + grup + ", actiu: " + esActiu + ", salari: " + salari); } }
MitjàVariables per a una reserva de vol
public class ReservaVol { public static void main(String[] args) { String desti = "Barcelona - Tòquio"; int numPassatgers = 2; double preuPerPersona = 874.50; char classe = 'E'; // E = econòmica, B = business double totalReserva = numPassatgers * preuPerPersona; System.out.println("Destinació: " + desti); System.out.println("Classe: " + classe); System.out.println("Total: " + totalReserva + " €"); } }

Inferència de tipus amb var

Des de Java 10 podem escriure var en lloc del tipus i el compilador el dedueix del valor inicial. El tipus queda fixat: no és una variable "sense tipus".

MitjàÚs de var
public class TipusVar { public static void main(String[] args) { var nom = "Laia"; // String var edat = 22; // int var preu = 9.99; // double // var x; → error: sense valor inicial no es pot deduir el tipus // edat = "vint"; → error: edat és int i no pot guardar text System.out.println(nom + " (" + edat + ") ha pagat " + preu + " €"); } }
⚠️ Una variable local s'ha d'inicialitzar abans d'usar-la. Si declares int total; i després fas System.out.println(total); sense haver-li donat cap valor, el compilador mostra l'error variable total might not have been initialized.

11. Constants

Una constant és un valor que no pot canviar un cop assignat. Es declara amb la paraula clau final i, per convenció, el nom s'escriu en MAJÚSCULES separant les paraules amb guió baix.

CaracterísticaVariableConstant
Paraula clau—final
Pot canviar de valor✔ Sí✘ No (error de compilació)
NomenclaturapreuFinalIVA_GENERAL
Exemplesedat, comptador, totalIVA, dies de la setmana, nota mínima per aprovar
BàsicConstants per a una botiga en línia
public class Botiga { public static void main(String[] args) { // Constants: valors fixos del negoci final double IVA = 0.21; final double DESCOMPTE_SOCI = 0.10; final int DIES_DEVOLUCIO = 30; // Variables: valors d'aquesta compra double preuBase = 80.0; double preuSoci = preuBase - preuBase * DESCOMPTE_SOCI; // 72.0 double preuFinal = preuSoci * (1 + IVA); // 87.12 System.out.println("Preu final: " + preuFinal + " €"); System.out.println("Termini de devolució: " + DIES_DEVOLUCIO + " dies"); // IVA = 0.18; → error de compilació: no es pot reassignar una constant } }
MitjàConstants per configurar un joc
public class ConfiguracioJoc { public static void main(String[] args) { final String NOM_JOC = "SpaceQuest"; final int VIDES_INICIALS = 3; final int PUNTS_PER_NIVELL = 100; int vides = VIDES_INICIALS; int punts = 0; int nivell = 1; // El jugador supera dos nivells i perd una vida punts = punts + 2 * PUNTS_PER_NIVELL; nivell = nivell + 2; vides = vides - 1; System.out.println(NOM_JOC + " | Nivell: " + nivell + " | Punts: " + punts + " | Vides: " + vides); } }
💡 Per què usar constants? Si l'IVA canvia, només cal modificar-lo en un lloc. A més, preu * IVA s'entén molt millor que preu * 0.21 (un "número màgic" sense explicació).

12. Operadors i expressions

Un operador és un símbol que fa una operació sobre un o més valors (operands). Una expressió és una combinació d'operands i operadors que produeix un resultat.

CategoriaOperadorsExempleResultat
Aritmètics+ - * / %7 % 31
Assignació= += -= *= /= %=a += 5a = a + 5
Increment / decrement++ --a++a = a + 1
Relacionals== != > < >= <=5 > 3true
Lògics&& || !true && falsefalse
Concatenació+ amb String"Nota: " + 8"Nota: 8"
12.1 Operadors aritmètics
⚠️ Divisió entera: si els dos operands són enters, / descarta els decimals: 10 / 3 dona 3. Perquè doni 3.333… cal que almenys un sigui decimal: 10.0 / 3.
BàsicOperadors aritmètics bàsics
public class OperadorsAritmetics { public static void main(String[] args) { int a = 10; int b = 3; System.out.println(a + b); // 13 suma System.out.println(a - b); // 7 resta System.out.println(a * b); // 30 multiplicació System.out.println(a / b); // 3 divisió ENTERA System.out.println(a % b); // 1 residu de 10 / 3 System.out.println(10.0 / b); // 3.3333333333333335 divisió decimal } }
MitjàDivisió entera i residu: minuts a hores
public class ConvertirMinuts { public static void main(String[] args) { int minutsTotals = 137; int hores = minutsTotals / 60; // 2 int minuts = minutsTotals % 60; // 17 System.out.println(minutsTotals + " minuts = " + hores + " h " + minuts + " min"); // El residu també serveix per saber si un número és parell int numero = 14; boolean esParell = numero % 2 == 0; System.out.println(numero + " és parell: " + esParell); } }

12.2 Increment, decrement i assignació composta
BàsicPre-increment i post-increment
public class OperadorsUnaris { public static void main(String[] args) { int a = 5; int resultat; resultat = ++a; // primer incrementa (a = 6), després assigna System.out.println(resultat + " " + a); // 6 6 a = 5; resultat = a++; // primer assigna (5), després incrementa (a = 6) System.out.println(resultat + " " + a); // 5 6 } }

public class AssignacioComposta { public static void main(String[] args) { int punts = 100; punts += 50; // punts = punts + 50 → 150 punts -= 30; // punts = punts - 30 → 120 punts *= 2; // punts = punts * 2 → 240 punts /= 4; // punts = punts / 4 → 60 punts %= 7; // punts = punts % 7 → 4 System.out.println("Punts finals: " + punts); } }
12.3 Operadors relacionals

Comparen dos valors i sempre retornen un boolean. Són la base de les decisions que prendrem a l'A2.

BàsicComparar valors
public class Comparacions { public static void main(String[] args) { int edat = 17; double nota = 4.8; System.out.println(edat >= 18); // false System.out.println(nota < 5.0); // true System.out.println(nota == 5.0); // false System.out.println(edat != 18); // true } }
⚠️ No confonguis == amb =: edat == 18 pregunta si val 18 i retorna true o false. edat = 18 assigna el valor 18. Per comparar textos (String) no s'usa == sinó .equals(), com veurem a l'A2.
12.4 Operadors lògics
OperadorNomRetorna true quan…
&&I (AND)els dos operands són true
||O (OR)almenys un operand és true
!NO (NOT)l'operand és false (l'inverteix)
MitjàCondicions d'accés a una plataforma
public class AccesPlataforma { public static void main(String[] args) { boolean teCompte = true; boolean contrasenyaOk = false; boolean estaBloquejat = false; int intentsFallits = 2; // Pot entrar si té compte, la contrasenya és correcta i no està bloquejat boolean potEntrar = teCompte && contrasenyaOk && !estaBloquejat; System.out.println("Pot entrar: " + potEntrar); // false // Mostrem un avís si la contrasenya és incorrecta o ja porta 2 intents fallits boolean mostrarAvis = !contrasenyaOk || intentsFallits >= 2; System.out.println("Mostrar avís: " + mostrarAvis); // true } }
AvançatAny de traspàs amb una expressió lògica
public class AnyTraspas { public static void main(String[] args) { // Un any és de traspàs si és divisible per 4 i no per 100, // o bé si és divisible per 400 int any = 1900; boolean esTraspas = (any % 4 == 0 && any % 100 != 0) || any % 400 == 0; System.out.println(any + " és de traspàs: " + esTraspas); // false } }

12.6 La classe Math

14. Composició seqüencial d'instruccions

La composició seqüencial és l'estructura més simple: les instruccions s'executen una rere l'altra, de dalt a baix, cadascuna una sola vegada. Tots els programes que hem fet fins ara són seqüencials. Tenen sempre tres parts: dades d'entrada → procés → sortida.

ALGORISME PreuAmbIva DADES: preu = 25, IVA = 0.21 ← entrada CÀLCUL: total ← preu × (1 + IVA) ← procés ESCRIURE "Total: ", total ← sortida FI ALGORISME
14.1 L'ordre de les instruccions importa

En un algorisme seqüencial, cada instrucció fa servir els valors que han deixat les anteriors. Si canviem l'ordre, el resultat canvia. L'exemple clàssic és intercanviar el valor de dues variables: cal una variable auxiliar.

MitjàIntercanviar dues variables
public class Intercanvi { public static void main(String[] args) { int a = 5; int b = 9; System.out.println("Abans: a = " + a + ", b = " + b); // Malament: a = b; b = a; → les dues acabarien valent 9 int aux = a; // 1. guardem el valor d'a a = b; // 2. a rep el valor de b b = aux; // 3. b rep el valor original d'a System.out.println("Després: a = " + a + ", b = " + b); } }
